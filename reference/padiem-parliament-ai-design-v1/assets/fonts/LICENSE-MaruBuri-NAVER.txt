마루 부리(MaruBuri) 글꼴 사용 고지
================================

이 저장소에 들어간 MaruBuri-Regular.woff2 / MaruBuri-Bold.woff2 의 원본은
네이버가 제작·배포하는 "네이버 글꼴"입니다.

출처 (공식 배포처)
  원본 TTF:
    https://hangeul.pstatic.net/hangeul_static/webfont/MaruBuri/MaruBuri-Regular.ttf
    https://hangeul.pstatic.net/hangeul_static/webfont/MaruBuri/MaruBuri-Bold.ttf
  안내 페이지:
    https://hangeul.naver.com/font

저작권 표기 (글꼴 파일 내부 name 레코드에서 직접 추출한 값)
  Notice   : © NAVER Corp. © NAVER Cultural Foundation Corp.
  Author   : AG Typography Institute (Noh Eunyou, Noheul Lee, Ku Moa)
  Publisher: http://www.agfont.com
  Family   : MaruBuri / Regular(usWeightClass 400), Bold(usWeightClass 700)

라이선스 요지 (2026-10-28 공식 페이지에서 확인한 문구)
  - 네이버에서 제작한 나눔 글꼴과 마루 부리 글꼴, 클로바 나눔손글씨의 지적 재산권은
    네이버와 네이버 문화재단에 있습니다.
  - 개인 및 기업 사용자를 포함한 모든 사용자에게 무료로 제공되며,
    글꼴 자체를 유료로 판매하는 것을 제외한 상업적인 사용이 가능합니다.
  - 본 저작권 안내와 라이선스 전문을 포함해서 다른 소프트웨어와 번들하거나
    재배포 또는 판매가 가능하며, 자유롭게 수정·재배포할 수 있습니다.
  - 라이선스 전문을 포함하기 어려울 경우 출처 표기를 권장합니다.
  전체 문구는 위 안내 페이지의 "폰트 사용시 안내사항 / 네이버 글꼴 저작권 안내"에 게시되어 있습니다.

이 저장소에서 가한 변경
  - TTF → WOFF2 컨테이너 변환만 적용했습니다. 글리프·cmap·이름 레코드는 변경 전과
    동일함을 fontTools로 대조 확인했습니다:
      glyphs 12466 / cmap 12398 / family 'MaruBuri' / style Regular|Bold / unitsPerEm 동일
      Regular 3.12 MB → 0.41 MB,  Bold 3.20 MB → 0.43 MB
  - 글자 모양·간격·히스토그램을 수정하지 않았고, 서브셋으로 잘라내지 않았습니다.
    따라서 이름과 고지를 그대로 유지합니다.
  - 재배포 조건에 따라 이 파일(저작권 안내 + 라이선스 요지 + 출처 URL)을 글꼴 파일과
    같은 디렉터리에 동봉합니다.

Pretendard와의 관계
