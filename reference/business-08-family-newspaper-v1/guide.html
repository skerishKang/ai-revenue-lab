30초 사용법이번 호기사편집 노트

GUIDE · 30 SECONDS / DOMESTIC PRESSROOM

가족의 작은 기록을한 주의 한 호로 엮습니다.

사진 한 장, 짧은 메모, 가족 일정처럼 흩어진 기록이 1면·가족 소식·사진 특집·일정으로 정리됩니다. 핵심은 자동 공개가 아니라 가족이 읽고 확인한 뒤 다음 호로 이어가는 것입니다.

신문 체험 시작이번 호 먼저 보기
01Collect기록 모으기
02Edit한 호로 편집
03Read면을 넘겨 읽기
04Review만든 과정 확인
05Return다음 호로 이어가기
01

COLLECT

이번 주에 기억할 작은 재료를 모읍니다.

사진, 메모, 일정처럼 가족이 남긴 작은 기록이 재료입니다. 현재 데모에서는 실제 가족 자료 대신 합성 장면을 사용합니다.

합성 예시 보기
INPUT / THIS WEEK사진 12
메모 7
일정 3가족 기록 재료
02

EDIT

가장 중요한 장면은 1면으로, 나머지는 각 면으로 편집합니다.

자동 공개가 아니라 편집 제안을 만드는 단계입니다. 이번 주의 중심 장면, 짧은 소식, 사진과 일정을 한 호의 리듬으로 배치합니다.

1면 보기
EDITORIAL ORDER1면 → 소식 → 사진 → 일정편집 제안
03

READ

실제 디지털 신문처럼 면을 넘겨 읽습니다.

1면에서 가족 소식, 사진 특집, 일정 순으로 이동합니다. 현재 위치는 상단 면 메뉴에 고정되어 길을 잃지 않습니다.

가족 소식 읽기
ISSUE 18FRONT
NEWS
PHOTO
CALENDAR한 호 안에서 이동
04

REVIEW

무엇이 들어왔고 무엇을 사람이 확인해야 하는지 봅니다.

자료와 편집 제안을 구분하고, 외부 공유나 발행 전에는 가족이 내용을 직접 확인해야 한다는 경계를 보여줍니다.

만든 과정 보기
HUMAN REVIEW자료 → 편집 제안 → 가족 확인자동 공개 없음
05

RETURN

마음에 드는 호를 표시하고 다시 1면으로 돌아옵니다.

현재 데모의 표시는 브라우저 세션 안에서만 유지됩니다. 실제 저장·계정·공유·외부 캘린더 연동은 포함하지 않습니다.

신문 체험 시작하기
SESSION ONLY표시 → 다시 읽기저장·공유 없음

THAT IS ALL

모으고 → 편집하고 → 읽고 → 확인하고 → 다음 호로 돌아옵니다.

현재 검토본은 합성 가족 콘텐츠만 사용하며 실제 업로드, 계정, 공개 발행, 외부 캘린더, 네트워크 저장 기능을 사용하지 않습니다.
