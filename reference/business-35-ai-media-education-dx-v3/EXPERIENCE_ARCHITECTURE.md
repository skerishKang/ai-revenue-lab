# V3 Experience Architecture

## Narrative

`현장 장면 → 병목 인식 → 전환안 생성 → 운영 산출물 → 전후 비교 → 프로그램 → 다음 행동`

## Sections

1. **Commercial hero** — 고객, 문제, 6주 결과를 한 문장과 현장 이미지로 전달.
2. **Problem scenes** — 생산·검토·전환을 full-bleed 장면으로 설명.
3. **Transformation Studio** — 입력 기반의 진단·워크플로·파일럿 결과 생성.
4. **Operating-system artifacts** — 요청서·정책·검토지도·KPI를 실물형 산출물로 표현.
5. **Before / After** — 같은 팀에서 운영 방식만 바뀐다는 점을 비교.
6. **Program architecture** — A 진단, B 6주 파일럿, C 운영 자문.
7. **Conversion** — 사용자 입력을 요약한 전환안을 복사해 상담 준비.

## Interaction rules

- 제출과 저장 없음.
- 입력 변경은 브라우저 안에서만 결과를 재구성.
- 결과 탭은 진단 / 업무 흐름 / 파일럿으로 구분.
- reduced motion에서는 즉시 최종 상태 제공.
