# V3 Visual System

## Direction

**Korean editorial production studio + operational product interface**

- 현장 사진을 큰 화면 단위로 사용한다.
- 카드 벽 대신 sticky scene, full-bleed image, overlapping physical artifact를 사용한다.
- 밝은 종이 질감과 검은 제작 스튜디오를 교차해 서비스와 제품의 이중성을 표현한다.
- signal orange, acid lime, cobalt blue를 상태·전환·승인 신호로 사용한다.
- 내부 상태 마커와 합성 고지는 페이지 경험을 지배하지 않고 footer와 필요한 위치에만 둔다.

## Typography

- 한글 대제목은 짧고 강한 문장으로 구성한다.
- 영문은 운영 신호와 제품 레이어에만 사용한다.
- 본문은 60–75자 너비와 1.6 이상의 행간을 유지한다.

## Image treatment

- 하나의 가상 팀과 파일럿 이야기처럼 보이도록 저채도·고대비 처리한다.
- 사진 위에 수치, workflow, approval artifact를 합성해 단순 stock image 느낌을 줄인다.
