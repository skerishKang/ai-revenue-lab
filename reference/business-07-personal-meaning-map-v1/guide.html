01
Select · 기억 조각

지금 마음에 걸리는 장면 두 개부터 고릅니다.

새벽 산책, 혼자 간 전시, 친구와의 짧은 통화처럼 완성된 이야기가 아닌 작은 장면이면 됩니다. 데모에서는 합성 기록을 눌러 선택 상태를 확인할 수 있습니다.

02
Inspect · 의미 노드

각 장면에 붙은 의미와 근거를 읽습니다.

회복, 호기심, 관계, 성장 같은 단어는 자동 진단 결과가 아니라 편집용 제안입니다. 노드를 누르면 왜 그 의미가 붙었는지 설명을 확인할 수 있습니다.

의미 노드 확인 →
MEANING NODE회복“다시 시작한 행동”이라는 근거
03
Connect · 연결

서로 떨어져 있던 장면을 하나의 묶음으로 연결합니다.

두 개 이상 선택하면 ‘선택한 기억 연결하기’가 활성화됩니다. 연결은 기록을 바꾸는 것이 아니라, 지금의 관점에서 함께 보고 싶은 장면을 임시로 묶는 동작입니다.

연결 직접 해보기 →
THREAD / USER ACTION산책 + 공부
→ 다시 움직이기사용자가 직접 연결
04
Review · 제안 검토

시스템이 제안한 공통 의미를 그대로 믿지 말고 읽어봅니다.

예를 들어 여러 장면이 “멈춰 있던 것을 작게 다시 시작했다”는 흐름으로 묶일 수 있습니다. 이 문장은 확정된 해석이 아니라 사용자가 검토할 수 있는 편집 제안입니다.

지도책 시각 상태 보기 →
EDITORIAL PROPOSAL다시 움직이기진단 아님 · 검토 가능한 제안
05
Undo · 통제권

마음에 들지 않으면 취소하고 처음부터 다시 고릅니다.

마지막 연결 취소와 전체 초기화를 지원합니다. 의미 지도는 사용자의 기억을 대신 정의하는 것이 아니라, 여러 장면을 다른 각도에서 다시 볼 수 있게 하는 도구입니다.
