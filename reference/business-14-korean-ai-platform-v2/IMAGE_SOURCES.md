# Image Sources

This operational-product reference uses no photography, third-party screenshots, hotlinked images, external fonts or competitor brand assets at runtime.

## Runtime visual assets

- CSS-drawn route lines and nodes — original, repository source
- inline text glyphs and semantic initials — original
- no remote icon library
- no runtime hotlink
- no base64 image payload
- no generated image
