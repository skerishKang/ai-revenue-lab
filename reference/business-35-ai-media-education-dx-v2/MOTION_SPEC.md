# Motion Spec

Signature motion: MEDIA WORKFLOW TRANSFORMATION

Sequence (desktop + mobile, deterministic):
1. BEFORE track: 초안·재작업 병목 강조(red hot)
2. 중간 배지: 교육 개입 · 검토 지점 배치 · AI-assisted 연결
3. AFTER track: AI-assisted 단계(brass) → 사람 검토(green/ink gate) → 게시·학습 루프(done)
4. 도장: HUMAN-APPROVED AI MEDIA OPERATING SYSTEM

Rules:
- motion은 개념(병목 → 교육/검토 → 사람 승인 체계)을 설명한다
- prefers-reduced-motion: 동일 정보를 최종 상태로 즉시 표시
- transitions ≤ 0.4s · scroll-behavior smooth(auto on reduced)
