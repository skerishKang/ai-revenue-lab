운영 현황은 실제 단지 이름으로,
체험 흐름은 합성으로.

방림명지로드힐아파트 운영 화면의 시각 정체성은 그대로 두고, 문서·회의·안건·공개 확인 같은 상호작용은 별도의 합성 sandbox에서 연습하는 구조입니다.

01 · STATUS

운영 현황 보기

단지 기본 정보와 현재 운영 항목을 한 화면에서 읽습니다.

02 · DOCUMENTS

문서·공개자료 확인

합성 sandbox에서 규정, 공지, 첨부자료와 공개 상태를 확인합니다.

03 · MEETING

회의 흐름 살펴보기

합성 회의의 안건, 정족수, 진행 상태와 회의록 초안을 검토합니다.

04 · DECISION LOG

결정 기록 확인

무엇이 결정됐는지와 아직 공개 전인지 구분해서 봅니다.

05 · SANDBOX

합성 운영 체험

주민·위원회 화면 전환과 공개 확인을 연습하되 실제 단지 기록을 바꾸지 않습니다.

REAL IDENTITY / SYNTHETIC UX BOUNDARY

두 층을
의도적으로 분리합니다.

실제 단지 정체성

승인된 UI에는 방림명지로드힐아파트 · 101동·102동 · 192세대 · 제5기 입주자대표회의의 제품 정체성이 표시됩니다.

합성 운영 sandbox

솔빛마루 2단지, 회의·안건·문서·정족수·공개승인 값은 UX 검증용 합성 fixture입니다. 실제 방림명지로드힐 운영기록이 아닙니다.

이 체험에서 하지 않는 것

전자투표, 계약·결제, 법률 판단, 실제 주민 개인정보 처리, 실제 문서 공개나 운영 결정 확정은 수행하지 않습니다.

Guide에서 실제 단지 화면을 먼저 보고, 필요하면 별도 sandbox로 이동해 운영 흐름만 체험하세요. 두 화면의 데이터 의미는 서로 다릅니다.
