# B66 · Padiem Quote — 데모 운영 가이드 (DEMO GUIDE)

대상: 고객에게 견적 데모를 시연하는 운영자
제품: Padiem Quote / 파디엠 견적 (B66 · Issue #3136 · PR #3137)
이 문서는 **현재 버전의 실제 동작 기준**으로 작성되었습니다. 아직 동작하지 않는 기능은 단계별로 명시합니다.

---

## 1. 실행 방법

방법 A — 로컬 서버 (권장):

```bash
cd reference/business-66-padiem-quote-v1
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173/` 접속.

방법 B — 바로 열기: `index.html`을 더블클릭 (서버·설치·자격증명 불필요).

- 포트 충돌 시: `4174` 등 다른 포트 사용 (`python -m http.server 4174`).
- 권장 화면: 데스크톱 1280px 이상 (좌측 입력 / 우측 견적서 미리보기 2단 배치).

## 2. 5분 데모 시나리오 (권장 순서)

1. **발신자 확인** — "1. 보내는 사람"에서 프리셋(파디엠 데모 / 직접 입력) 선택.
   - 실제 회사 정보를 입력한 뒤 **"이 발신자 저장"**을 누르면 이 브라우저에 저장됩니다.
   - ※ 저장 후에도 페이지를 새로고침하면 프리셋이 "파디엠 데모"로 돌아가므로, **"직접 입력"을 다시 선택**해야 저장된 발신자가 불러와집니다. (현재 버전 제한 — 아래 4절)
2. **받는 사람과 날짜** — 고객사/담당자 입력. 견적일은 오늘 날짜가 자동 입력되고, 견적번호는 `PQ-YYYYMMDD-001` 형식으로 자동 생성됩니다.
3. **품목 입력** — 2~3개 입력. 수량×단가가 즉시 금액으로 계산되고 우측 미리보기에 실시간 반영됩니다.
   - ※ 단가 입력 시 **콤마 없이 숫자만** 입력하세요 (예: `1500000`). 콤마를 넣으면 값이 지워집니다. (현재 버전 제한 — 아래 4절)
4. **부가세 토글** — "부가가치세 10% 적용" 체크 on/off로 공급가액 대비 10%가 계산됩니다 (결정론적 코드 계산, AI 아님).
5. **미리보기 → PDF 저장** — 우측 A4 미리보기를 확인한 뒤 **"PDF로 저장 / 인쇄"** 클릭. 아래 3절 주의사항을 먼저 확인하세요.

## 3. PDF 저장 시 주의사항 (중요)

인쇄 대화상자(Chrome/Edge 기준)에서:

1. **대상: "PDF로 저장"** 선택.
2. **추가 설정 → 옵션에서 "머리글 및 바닥글" 체크 해제** — 해제하지 않으면 문서 상단에 날짜·페이지 제목, 하단에 URL·페이지 번호가 인쇄되어 견적서가 지저분해집니다.
3. 여백은 "기본", 배율은 100% 유지 (@page 규격으로 A4 10mm 여백이 지정되어 있습니다).
4. **알려진 이슈**: 현재 버전은 문서 끝에 **빈 페이지 1장이 추가로 생성**됩니다. PDF 저장 후 마지막 빈 페이지를 삭제하고 전달하면 됩니다 (다음 수정에서 제거 예정).
5. 인쇄에는 견적서 종이(우측 미리보기)만 나옵니다 — 입력 화면은 인쇄되지 않도록 설계되어 있습니다.

## 4. 현재 알려진 제한 (데모 전 필독)

| 항목 | 현재 동작 | 데모 시 대처 |
| --- | --- | --- |
| 단가 콤마 입력 | `1,500,000` 입력 시 값이 지워짐 | 콤마 없이 입력 |
| 새로고침 | 입력한 견적 내용 전부 사라짐 | 새로고침하지 말 것 (발신자 저장만 유지됨) |
| 저장된 발신자 | 기동 시 자동 적용 안 됨 | "직접 입력" 재선택으로 불러오기 |
| 파일 올리기 / 채팅 만들기 | 버튼만 있고 동작하지 않음 | "다음 단계" 안내 문구로 의도를 설명 |
| 이메일 보내기 | 동작하지 않음 | 동일 |
| 모바일 | 열람은 가능하나 품목 행의 단가 입력란이 좁음 | 품목 편집은 데스크톱에서 시연 권장 |

## 5. 이 데모가 하지 않는 것

- 파일 업로드/외부 전송 없음 (업로드 버튼은 파일을 전송하지 않는다는 문구를 표시)
- 이메일 발송 없음
- 서버 저장·인증·테넌트 데이터 없음 (모든 데이터는 이 브라우저의 localStorage에만 존재)
- 자격증명·API 키 불필요

## 6. 문제 해결

- **저장된 발신자 초기화**: 브라우저 개발자 도구 → Application → Local Storage → `padiemQuote.sender` 삭제.
- **인쇄 미리보기가 비정상**하게 나오면: 인쇄 대화상자에서 "배율 100%", "여백 기본" 확인.
- **화면이 이상하면**: 새로고침 후 처음부터 다시 입력 (입력값은 유지되지 않음).

## 7. 다음 단계 개발 연결점

```text
직접 입력 / 파일 업로드+OCR / 채팅  →  QuoteDraft(하나의 정규화 객체)
  → 검증 + 결정론적 계산(수량×단가·공급가액·VAT·총액)
  → 미리보기  →  PDF  →  (선택) 이메일
```

금액 계산의 최종 authority는 AI가 아니라 `app.js`의 결정론적 코드입니다.
세부 계획은 README.md와 Issue #3136 참조.
