# Business 27 · Evidence Studio / 사건 기록실

Phase 1 `UI_ONLY` static visual reference for Issue #231.

## Product promise

녹음, 메시지, 사진, 문서와 메모를 출처·시간·관련 주장에 연결해, 사건의 흐름과 쟁점·모순·누락을 사람이 검토할 수 있는 증거 중심 기록물로 정리한다.

## Fixture

All people, organizations, locations, records and images are fictional repository-local synthetic fixtures. The case concerns a custom display cabinet found damaged after delivery, with conflicting accounts about when the damage occurred.

## Review states

`case`, `intake`, `chronology`, `claims`, `contradiction`, `folio`, `mobile`

## Run

Open `index.html` in a browser. State switching and Chronology Lock replay are visual-review controls only.

## Boundary

No upload, storage, OCR, transcription, AI analysis, legal advice, authentication, database, export, filing, deployment, UX acceptance or backend is implemented.
