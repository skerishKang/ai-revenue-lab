# Padiem Chat Phase 1 reference notes

## Primary benchmark — Wrtn

Observed product pattern to adopt:

- ordinary-language home prompt;
- current-information/search mode available without provider knowledge;
- sources visible under web-backed answers;
- file/photo attachment via the composer;
- prior-chat return path;
- common actions surfaced without turning the first screen into a tool dashboard.

Patterns intentionally not copied:

- Wrtn branding or character identity;
- trending-content strategy;
- content/benefit tabs unrelated to Padiem's product goal;
- any proprietary visual composition.

## Continuity benchmark — ChatGPT Projects

Planned later, not Phase 1 blocking:

```text
Project
├─ chats
├─ files
├─ instructions
└─ project context / memory
```

The Phase 1 shell keeps the sidebar and content hierarchy compatible with a future Projects surface without showing it as already available.

## Padiem translation

The visual and interaction rule is:

```text
advanced infrastructure behind the product
simple language in front of the user
```

The composer is the dominant object. Model/provider names are secondary and represented as `자동 추천` by default.

## Parent-generation usability translation

- 16px base body text;
- prominent 32–48px first-screen headline;
- 40–48px interactive controls;
- text labels alongside ambiguous icons;
- no hover-only required information;
- one obvious send action;
- plain-language failure and retry state;
- mobile drawer rather than a compressed desktop sidebar.

## Visual direction

Calm Korean-first utility rather than a cinematic or technical visual identity.

Material choices:

- warm cool-white background;
- muted neutral sidebar;
- one restrained violet Padiem accent;
- high-contrast black/charcoal text;
- soft borders rather than heavy glass/neon effects;
- no external runtime fonts or image assets.

The point is not visual novelty. The point is immediate comprehension and confidence.
