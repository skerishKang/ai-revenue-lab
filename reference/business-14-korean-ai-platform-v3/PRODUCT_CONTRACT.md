# Product contract

## Positioning

A Korean personal AI model gateway that is understandable before it becomes technical.

## Difficulty

```text
Beginner-first
Progressive disclosure
Developer depth preserved
```

## Primary journey

```text
Korean task
→ plain-language preference
→ recommended model and KRW estimate
→ free credit or top-up
→ first result
→ optional API/BYOK/advanced routing
```

## Commercial architecture

- Model inference: prepaid credits and pay as you go.
- Subscription: optional convenience features and included credit, never falsely unlimited inference.
- Future TUI: Business 54 consumes the same balance, model catalog and Router Core.

## Pricing truth

Every price must expose source state, date, input/output unit, currency conversion, platform fee and unknown states. Unsourced domestic prices are forbidden.
