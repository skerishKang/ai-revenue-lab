# Business 14 Visual Reference v3.2

Authority: Issue #385.

## Visual diagnosis

The previous shell was functional but visually resembled a marketing landing page and generic SaaS pricing template. v3.2 shifts the product toward a daily-use personal developer workspace.

## Reference synthesis

### OpenRouter

Adopt model discovery density, filters, sorting, price/context visibility, and route-result centrality. Keep the Korean beginner entry simpler than the expert catalog.

### Vercel AI Gateway

Adopt restrained technical styling, persistent product navigation, compact controls, and a precise model table. Do not inherit organization-first assumptions.

### Requesty and Portkey

Adopt the operational relationship between balance, model library, routing, API keys, BYOK, and usage. Do not expose enterprise observability as the personal first screen.

### Stripe Billing

Adopt calm credit, fee, rate-card, budget, and usage presentation. Do not turn the product into a finance dashboard.

## v3.2 decisions

```text
persistent desktop sidebar
compact request workspace
live route preview focal card
navy + indigo technical palette
sticky dense model toolbar
PAYG wallet-first pricing
mobile topbar + bottom navigation
```

No external visual assets, fonts, screenshots, or copied brand components are used at runtime.
