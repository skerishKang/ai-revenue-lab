# Proposed Business 18 — Personal Audio Channel

Phase 1 visual UI reference for **Personal Audio Channel / 나의 오디오 채널**.

## Visual concept

**Listening Letter / 듣는 편지** — selected synthetic notes, articles, travel fragments, schedules and book excerpts are arranged as a quiet personal audio edition for one listening moment.

## Scope

- seven representative visual states;
- Korean-first synthetic product copy;
- repository-local original SVG artwork;
- minimal review-only state switching;
- 680ms `Chapter Pulse` signature motion;
- desktop, tablet and mobile responsive composition;
- reduced-motion support.

## Non-implementation

No TTS, voice cloning, audio generation, recording, upload, streaming, podcast publishing, authentication, persistence, payment, analytics, live AI call, accepted UX or backend is included.

All sources, voices and listening records shown in the reference are fictional and synthetic.

## Review

Open `index.html?state=today`. The seven state keys are:

`today`, `listening`, `sources`, `script`, `letter`, `archive`, `mobile`.

Static asset versions are pinned through `styles.css?v=20260727.1` and `app.js?v=20260727.1`.
