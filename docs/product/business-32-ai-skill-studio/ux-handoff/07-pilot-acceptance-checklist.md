# 07 — Pilot Acceptance Checklist

파일럿 시작 전에 확인할 항목 목록입니다. 아직 고객 또는 실제 조직을 삽입하지
않았습니다. 실제 파일럿 대상이 결정되면 이 체크리스트를 기준으로 승인합니다.

## 체크리스트

- [ ] 업무 1개로 제한 — 파일럿은 합성 구매 견적 비교 업무 1개만 실행
- [ ] 실행자·검토자 지정 — operator/reviewer 역할 소유자 지정
- [ ] 허용·금지 업무 합의 — scope와 prohibited 가정 문서화
- [ ] 입력자료 목록 — 필수 입력과 확인 주체 정의
- [ ] 증거 출처 정의 — SOURCE EVIDENCE 대상과 합성 여부 명시
- [ ] 누락·충돌 처리 — MISSING/CONFLICTING 처리 규칙 합의
- [ ] 승인 책임 — HUMAN-APPROVED 담당 검토자 지정
- [ ] 버전 owner — 스킬 버전 담당자 지정
- [ ] 다음 검토일 — next review date 설정
- [ ] rollback — 파일럿 중단/복귀 절차
- [ ] 지원 연락 방식 — 문제 발생 시 연락 채널

## 파일럿 경계

```text
합성 데이터만 사용
실제 구매·계약·조직 데이터 금지
브라우저 메모리 저장만 사용 (서버 저장 금지)
실제 AI 모델 호출 금지
```

이 체크리스트만으로 파일럿이 승인되는 것은 아니며, 실제 파일럿 승인은 별도
결정이 필요합니다.
