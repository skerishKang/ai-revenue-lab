## Cross-source findings

1. **Operational engineering rules versus private company/business policy.** Canonical minimum-sufficient testing, evidence, design asset versions, separate UI/UX/backend/production axes and role-based validation are public technical operating contracts. They do not decide customer pricing, product market priority or legal claims. Separate owner-specific local-Docker avoidance and multi-machine worktree preferences are internal operational owner records rather than a public customer promise. Historic workstation identifiers/path samples in source are not reproduced here.
2. **Portfolio console has explicit business-decision seams.** Owner-facing portfolio facts, product phases and observed cost/revenue may include actual business strategy. Automated GitHub/CI/production synchronization is engineering/public; Owner product promises, financial outcomes, customer data and private portfolio authority require private review. Public repository documentation must not become a cross-product customer-account dashboard.
3. **No superfluous restrictions on models but protect real resources.** 2026-10-12 source #4445 and native capacity handoff distinguish model first-response/stream idle from command execution, OAuth/session TTL, app input and memory protection, request/response bytes, user cancellation and provider quotas. Historical Phase2/3 BYOK pilot 30-second timers and pilot model rosters do not override newer native-source handling. Never equate model-context limits with authentication, abuse, pricing or compute budget protections.
4. **B14 old pilot is not the current Product plan.** Phase2/3 routing and browser ephemeral BYOK-key security are historical engineering records; they are not current supplier authorization, enabled Free/Plus/Pro/Max tier, permanent 30s timeout, security certification or live Cloudflare credentials. Contemporary code and exact registered model Owner registry are separate proof.
5. **B13 Personal Video Archive is a distinct static UX study.** External public YouTube links may identify real creators and need current rights/usage checks before commercialization. Deterministic synthetic local fixtures, no-saved-data preview and historical worktree handoff do not imply actual user ingestion, ownership of public media, or released revenue service.
6. **B02 Living Travel source boundaries.** Mock provider and approved summaries are separate from a live AI provider; HTTPS/local loopback restrictions, PII minimization, no auto-publication, isolated Modal/Neon staging and versioned rollback remain engineering contracts. A staging recipe is not a live deployment, a travel booking authority or a current client data-sharing agreement.
7. **Original source and authority chronology matter.** #4445's static code match-count cannot prove dynamic Cloudflare env overrides or the absence of other timers; the 2026-09 CTO audit measures then-current PR/review gaps, not 2026-10 readiness; old Cloudflare temporary credential instructions must not be followed without fresh least-privilege readback. The `AGENT_TASK` and `AGENT_CONTINUATION` contracts merely add bounded trusted state projections, not permission to run arbitrary self-directing agents.
8. **No secret or private path recycling.** The public report deliberately omits workstation usernames/directories, token names/values, customer identifiers, commercial figures or proprietary contract terms. Keep canonical technical source intact while later owner review decides genuinely private business-Governance extraction.
