# B64 인증·회원 경계와 GitHub 상태 정합화 (2026-10-29)

> 기술 사실과 이슈의 권위 있는 색인. 사업방침 원문은 COM1 비공개 Governance에만 존재한다.

## 결정된 기술 원칙

- 인증 공통 기능과 기존 검증 코드를 **재사용**한다. 전면 재구축하거나 새로운 인증 엔진을 작성하지 않는다.
- B64와 PADIEM Chat은 **계정 네임스페이스, OAuth 클라이언트/리디렉트, 세션/쿠키, 관리자 권한, 회원/수익 D1 데이터**를 분리한다.
- 공통 코드 재사용은 **서로 다른 제품 사용자가 같은 계정이라는 뜻이 아니다**. PADIEM Chat의 `padiem_session`을 B64에 공유하거나 Chat `product_id=b62`를 B64 ID로 취급하면 안 된다.
- 정상 가동 중인 B64 계정·세션·D1을 보존한다. 별도 전환 계획이나 검증 없이 DB를 삭제하거나 인증체계를 교체하지 않는다.
