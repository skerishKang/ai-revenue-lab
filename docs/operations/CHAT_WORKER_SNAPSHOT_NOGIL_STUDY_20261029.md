# Chat Python Worker snapshot and NoGil investigation — draft

Cloudflare deploy-time snapshots capture top-level imports; see https://developers.cloudflare.com/workers/languages/python/how-python-workers-work/ . CPython's prior 150 ms cumulative app_factory import includes transitive module imports and must not be described as measured app creation time. Actual deployed snapshot contents, 503 cause and before/after edge CPU remain UNKNOWN.

- Existing app.main import creates a default app using Settings.from_env; the Worker later builds its own app with binding-derived settings. This draft imports create_app directly from app_factory and precomputes the static Route objects; per-app route and method containers are copied. StaticFiles, feature-gated route additions, app state, secrets and service bindings remain in create_app or the Worker request composition.
- Route objects contain wrapped Python endpoints and compiled path data. The tests check direct route attributes for Settings, request-context fields and Pyodide/JS-typed objects and verify per-app route and method sets are independent. They do not prove the complete transitive object graph is free of secrets, callbacks or PyProxy, nor prove the Cloudflare snapshot serializes it. This is NOT_READY pending runtime validation and full regression.
- Existing _worker_app is module-global and stores binding-derived settings, D1, services, clients, transport objects and self.env in app state for reuse. The Worker assigns it before later asynchronous secret-resolution awaits. A concurrent request may see partially configured state; no specific outage is attributed without reproduction. Do not equate this race with the Pyodide GIL race.
- WorkerJsFetchTransport awaits JS fetch using request-scoped JS request-init and response/stream objects, and a signal may live across await. The telemetry scheduler uses a ContextVar scoped to the request and creates a proxy for waitUntil; reset occurs in finally. The JS module handle is retained by httpx_compat but js global attributes are resolved at request time. Proxy lifecycle, task context and concurrent isolate behavior require runtime investigation. The draft adds no intentionally cached JS callback or binding; it does cache Python Route/app wrapper objects. Absence of new NoGil failures is unproven.
- CTO-supplied morning observation attributes the nine 1101s to poll; raw records and Astra2's current 503 tail are not yet available here. Earlier incident notes also report authentication-path NoGil failures on the Python 3.13 runtime. A universal route or cause cannot be concluded from either alone.
