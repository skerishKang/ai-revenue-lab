# PC 파일 검색 어댑터: 범위와 이어보기

이 코드는 어댑터 수준이다. 라이브 라우트 연결, 색인 생성, 운영 PC 검색은 포함하지 않는다. 서버가 확인한 허용 폴더와 라벨을 입력받고, 읽기 요청에는 기존 `라벨/상대경로` 계약을 사용한다.

검색 조건에서 보호 경로를 제외하고 검색 결과의 원래 경로와 해석된 경로를 다시 검사한다. 숨김과 시스템 속성이 모두 붙은 항목 또는 그 하위는 반환 전에 제외한다. 실제 Everything 프로세스와 운영 색인에서의 검색 조건 호환성은 아직 검증하지 않았다.

커서는 `label`과 해당 폴더에서 검색기가 처리한 원시 행의 `offset`이다. 요청 제한 또는 시간 초과는 `complete=false`, 각각 `reason=limit` 또는 `reason=timeout`과 커서를 반환한다. timeout 때 이미 완성된 줄만 보존한다.

**색인이 페이지 사이에 바뀌면 offset 결과가 밀려 중복·누락이 생길 수 있다.** 색인 세대 식별자가 없어 변동 여부를 증명할 수 없으므로 이어보기 후 끝에 도달해도 `complete=false`, `reason=index_unverified`로 표시한다. `index_may_change_between_pages=true`는 모든 결과에 포함된다.
