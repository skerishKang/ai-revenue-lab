## 2. 방침 (10-29~30 결정)

1. **먼저 고치고 옮긴다.** Cloudflare 무료 플랜을 유지한다. Chat 본체의 컴2 이전은 보류하고(초안·리허설 보관), 고장은 제자리에서 고친다: ① PC 작업 대기열 컴2 이전 ② 로그인을 Python Chat Worker에서 JS 인증 Worker로 분리 ③ Chat Worker 경량화. 그래도 오류가 남으면 본체 이전을 다시 판단한다.
2. **로그인 표준**: 인증은 `padiem-auth` 한 곳(Cloudflare JS Worker). 서비스는 ES256 로그인 표를 공개키로 검증만 한다. 공통 계정은 Google `sub`(원문 대신 HMAC 지문 저장, 이메일 병합 금지). 인증 경로에서 Python 호출 금지(처음 보는 계정의 첫 로그인 1회만 옛 identity authority 조회 = 지연 이관). 표 15분, 유지 30일, refresh 회전 + 30초 유예.
3. **잔재 제거**: 운영에서 만들거나 결정하지 않은 옵션·모드·플래그·빈 약속 문구·임의 상한을 제거한다. B14 자동 선택(`b14/auto`)은 폐지 상태 유지(#4844). Chat 요청 `mode` 항목 제거(#6234). 씽킹 모드는 필요 시 "사용자가 고른 정확한 모델의 생각하기 on/off"로 별도 설계한다.
