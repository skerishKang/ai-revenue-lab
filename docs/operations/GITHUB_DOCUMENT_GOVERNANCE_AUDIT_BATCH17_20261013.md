## Core boundaries

1. **B45 content generation is not factual verification or publication.** The hypothetical brief→transform→review→production-kit workflow shows explicit source rights, unsupported-claim hold, no living-writer style imitation and NOT PUBLISHED. A synthetic approval animation does not authorize real customer content distribution, autonomous CMS publication or a model provider account.
2. **B46 personalization needs real consent and data governance.** User-editable preferences, temporary context, explanations, override and reset are valid product design research; synthetic preference SVGs do not prove compliant tracking, production personal data usage, a live recommendation model or agreed retention. Third-party privacy-law references are not legal advice or a completed privacy notice.
3. **B48 verifier separates worker self-check, independent validation and human release.** Artifact version, evaluator verdict, stale/skipped/missing evidence and residual conditions cannot be collapsed into a generic success check. Even the animated HUMAN-APPROVED record does not grant broad certification or production deployment. Preserve existing technical owner and exact-head test authority, not a new duplicated platform.
4. **B51 marketplace listings are not installable/runnable paid workflows.** An independent historical Chromium matrix did verify the bounded visual reference; this did not certify package rights, publisher authority, user installation, account access, runtime provider calls or payments. The implementer's self-check and detached validator are distinct and must stay so.
5. **B55 local AI model fleet planning is not B54 Claw routing or execution.** Synthetic device inventories, quarantine, resource/energy and duplicate-run policies communicate a proposed operations plan. It does not provision physical devices, execute jobs, automatically scale, import cloud provider keys or override existing P01/Control Plane identity. Old Draft/DO_NOT_MERGE wording applies to its original feature-development gate, not to the scope of this new audit-only PR.
6. **B57 original literary work versus edition/translation rights is a genuine mixed legal-business seam.** Public-domain status of an old original text is insufficient to clear a modern translation, a derivative work, edition-specific transcription, digitized cover or redistribution. The comparison UI demonstrates source traceability and human judgment; current territory-specific publication, model corpus and commercial translation licenses require separate owner/legal verification.
7. **B52 scheduling is still a nonexecuting reference.** Planned schedule, idempotency, human checkpoint, exception and notification constraints differ from B51 marketplace promotion; documentation alone grants no recurring automation, workflow payment or completed delivery.
