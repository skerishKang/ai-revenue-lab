## Findings requiring deliberate separation

1. **WEB-FIRST sequencing is a dated Owner direction, not proof that all UI is live.** The 2026-10-11 source notes explicitly supersede the former forced Resident-first path: authenticated B62 browser upload/authorized Drive READ → canonical P01 → supported server-side XLSX edit/summary PDF → owner preview/download first. Windows Excel/Resident is reserved as an optional expressly selected local-file or fidelity fallback, with separate security/license/release gates. This may require refreshed current-priority review but not wholesale business-platform duplication.
2. **READ selection, approval, editing and export are separate user actions and technical authorities.** Owner-selectable XLSX metadata and P01 original READ intent ≠ independent Core/Engine WRITE consent to an exact proposed edit digest ≠ actual revised file creation ≠ genuine Office/summary PDF export. Unknown P01 outcome is one-shot and requires GET/reconciliation, not blind POST retry. Neither model text nor browser metadata can mint first-party P01/Engine approval, or arbitrary path/DB identity.
3. **A standard summary PDF is not an Excel-identical rendering.** The 2026-10-11 supported server PDF profile is intentionally a bounded one-page standard quote summary generated from a tightly constrained single-sheet template, not exact Excel print recreation. Customer marketing promises, supported input formats and special Excel-dependent fidelity require product Owner decision and separate technical proof. Historic PDF-looking fixtures and local Excel synthetic runs do not certify arbitrary customer documents.
4. **D1/Drive artifacts must prove actual provenance.** Immutable SHA-256, user + conversation + workspace + completed originating run, distinct PDF/XLSX upload receipts and explicit provider READ/WRITE grants control file registration and later downloads. Successful local fake transport/D1 tests do not prove an active Google Drive WRITE/READ grant, file bytes, Office license, live rendered PDF or a complete same-/next-conversation followup.
5. **Source-stage release and historical 409 are not present-day outage assertions.** The source-pinned Cloudflare comparison documented missing B62/Engine bindings/migrations and no Production activation. A separate 2026-10-11 live HTTP 409 P01 start was traced to an Engine **service app allowlist** check before tool continuation and fixed in source, without weakening P01 checks. No current Production status was re-read in this *document audit*; do not silently label the live failure fixed or still open today.
6. **Reuse canonical authorities rather than cloning a second platform.** IP-CONTROL session/entitlement and connector scopes, IP-CORE Tool/Approval/Evidence, AI Engine durable tool/continuation, B62 first-party owner session, B54 Claw workspace/artifact UX and optional Windows Resident are already differentiated.
