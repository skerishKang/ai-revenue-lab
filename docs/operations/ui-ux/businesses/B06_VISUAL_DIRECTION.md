This document records B06's product-specific territory so later portfolio redesigns do not accidentally duplicate it.

It does not modify owner approval state.

---

## 1. Product job

World Feed helps one user discover a finite, edited mix of world culture, nearby places and durable personal-interest signals, understand why an item appeared, adjust preference direction and return to a visibly changed feed.

It is not primarily:

- a general breaking-news site;
- a social feed;
- a research database;
- a city guide;
- a dashboard of recommendation scores.

---

## 2. Core transformation

```text
SIGNAL → OPEN → WHY → ADJUST → RETURN
```

This is both the UX journey and the visual grammar.

- `SIGNAL` — scan a finite personal dispatch;
- `OPEN` — enter one story/place/cultural context;
- `WHY` — understand the ordinary preference/context signals that caused it to appear;
- `ADJUST` — change one preference direction;
- `RETURN` — see the feed order materially change while context is preserved.

---

## 3. Visual world

B06 occupies the portfolio's **Personal World Signal Room / Editorial Dispatch** territory.

Target qualities:

```text
alive
worldly
current
exploratory
source-aware
signal-dense but readable
```

Current later visual reset uses a dark signal environment because that material supports active information flow and layered scanning.

This is a B06-specific solution, not a portfolio standard.

---

## 4. Core object

The core visual object is not a globe or map illustration.

It is the **edited feed signal** represented through:

- one dominant lead story;
- compact signal/source metadata;
- nearby/world/personal-interest distinctions;
- a rail of secondary signals;
- a discovery mosaic;
- visible preference change.

---

## 5. Information density

```text
mid-high
```

Reason: the user should feel that multiple cultural/place signals are available, but not face an endless undifferentiated feed.

Hierarchy must remain stronger than quantity.

---

## 6. Motion grammar

Allowed B06-specific motion:

```text
signal arrival
stream / shift
story open / return continuity
preference reorder
horizon change
```

Motion should preserve orientation and provenance.

Do not export radar/orbit/signal motion to unrelated Businesses.

---

## 7. Reference translation discipline

Historical B06 reference work is the methodological model:

- Cosmos — image-first discovery / restrained controls;
- Are.na — calm interest adjacency;
- Flipboard — magazine grouping / local / more-less preference language;
- Tapestry — mixed sources with coherent identity;
- Ground News — visible provenance and explainable personalization;
- editorial web/print references — scale contrast and nonuniform editorial rhythm.

The important rule is that each reference was paired with:

```text
ADOPT
REJECT
WORLD FEED DIFFERENCE
```

Future B06 audits should extend this into the full standard:

```text
REFERENCE
OBSERVE
ADOPT
REJECT
TRANSLATE
SURFACE
VERIFY
```

---

## 8. Key surfaces

### Feed

Must communicate the product within seconds through:

- lead story;
- visible world/near/interest signals;
- source/time context;
- finite but varied discovery.

### Story

Must stay inside the same product world and not become a generic article page.

### Why

Must explain personalization in plain language without exposing meaningless model internals.

### Adjust

Must make the preference action simple and reversible.

### Return

Must visibly show that the feed changed and preserve original exploration context.

### Guide

Because B06 has several non-obvious states, the compact `30초 사용법` path is appropriate and should remain product-styled rather than documentation-styled.

---

## 9. Portfolio anti-copy rule

Reserve the following combination for B06 unless another Business has an unusually strong reason:

```text
dark active signal field
+ cool cyan/blue information accents
+ warm orange active signal accent
+ high scanning density
+ lead-story / signal-rail relationship
+ world/near/you language
+ stream/shift motion
```

Other Businesses should not inherit this combination merely because it looked stronger than their current UI.

---

## 10. New-standard future review criteria

When B06 is formally re-audited under the new full portfolio pass, verify:

1. first viewport still reads as World Feed, not generic dark dashboard;
2. lead story remains stronger than decorative CSS scenes;
3. signal rail supports rather than competes with the main story;
4. `WHY` remains visually understandable;
5. adjustment produces an obvious visible result;
6. Guide explains actual user actions;
7. Korean typography is controlled on Desktop/Mobile;
8. Mobile chrome does not crowd the real feed;
9. current visual system does not overuse generic control-room tropes;
10. the resulting territory remains clearly distinct from B14/B42/B43/B52/B55.
