## Product thesis

Heterogeneous personal source files become recognizable volumes on a spatial shelf, while exact reading/search/bookmark/note work remains in a precise 2D reader at the same source position.

```text
SHELF → 3D VOLUME → SAME-POSITION 2D READER → SEARCH / NOTE → RETURN TO SAME VOLUME
```

Core object: **the volume identity and synchronized source anchor across 3D and 2D**.

## Reserved visual territory

**Spatial Living Library / Hybrid Reader**

- book spines/volumes as spatial recognition
- bounded 3D preview, not decorative metaverse
- 2D precision reader as authoritative reading mode
- source/page anchor visibly synchronized
- shelf composition and volume identity
- notes/bookmarks attached to source, not to unstable 3D coordinates

Avoid B01 luxury private Edition styling, B19 binding/provenance desk, generic file-browser folders, game-like 3D room and 3D-only reading.

## Preserve

- direct shelf → 2D access
- 3D → 2D → same-position return
- source-relative anchor authority
- search/bookmark/note contracts
- reduced-motion route that bypasses spatial animation
- mobile priority on 2D precision reader
- local-first/no-upload boundaries in the MVP

## Focused future polish allowed

- improve book material/lighting/depth while keeping restraint;
- make selected volume and reading position more legible;
- improve transition continuity between shelf and reader;
- refine Mobile volume chooser without forcing desktop 3D composition.

## Differentiation

- B01 = a new authored personal publication; B59 = library for existing heterogeneous records.
- B19 = memory provenance/binding; B59 = source-faithful reading/navigation.
- B13 = media viewing records; B59 = document/source library.

## Acceptance criteria

1. spatial shelf remains instantly recognizable;
2. 3D is useful for identity/orientation, never a gate to reading;
3. 2D reader remains authoritative for text/search/notes;
4. exact source position survives mode transitions;
5. Mobile prioritizes precision reading;
6. source/user/derived layers remain distinct;
7. visual polish does not turn B59 into B01/B19-style publication aesthetics.
