## Product thesis

A set of memories becomes a dated, compared and provenance-marked memory volume whose uncertainty and source relationship remain visible.

```text
GATHER → DATE → COMPARE → MARK → BIND
```

Core object: **the provenance-marked memory page / evidence binding table**, not a collectible magazine cover.

**Memory Provenance Table / Binding Desk**

- light neutral archival work surface

- side-by-side memory comparison

## Reference translation

Adopt archival practices that preserve source/date/context:
- chronology is visible
- conflicts/uncertainty remain visible
- marks explain why a memory was included/qualified

Reject:
- sentimental scrapbook collage
- polished magazine cover as the main payoff
- decorative vintage papers

Translate:
- memory pages behave like carefully prepared provenance sheets that can be bound only after comparison/marking.

## Key surfaces

- Gather: source/date fragments visible.
- Date: chronology and uncertain dates differentiated.
- Compare: competing versions/source context side-by-side.
- Mark: provenance marks are the core interaction.
- Bind: final book emerges from marked sheets.
- Read/history: volume retains dates and source cues.
