## Product thesis

The user describes a situation, reviews bounded options, chooses their own safety plan and confirms it. The product does not decide that a person/place is safe or dangerous.

```text
SITUATION → OPTIONS → MY PLAN → REVIEW
```

Core object: **the user-owned safety plan**.

## Reserved territory — Personal Safety Plan Board

- calm, non-alarmist personal plan surface
- selected check-in/contact/route/action steps arranged as a plan
- clear user choice and reversibility
- evidence/uncertainty stated plainly
- trusted-contact/check-in objects only when in contract

Avoid red danger dashboards, threat scores, fear imagery, surveillance maps and autonomous recommendations.

## Acceptance criteria

1. user's selected plan is visually central;
2. options remain choices, not safety verdicts;
3. uncertainty/limits are visible;
4. generic white-card template is gone;
5. Mobile keeps situation→choice→plan clear;
6. current human-control/safety boundaries remain unchanged.
