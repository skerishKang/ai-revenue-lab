## Product thesis

One creator turns one source idea into materially different editorial outputs while preserving one voice and source lineage.

```text
SOURCE IDEA → ARTICLE → NEWSLETTER → SHORT FORM → VIDEO SCRIPT → REVIEW
```

Core object: **the editorial desk with one source relayed into several formats**.

## Reserved visual territory

**Solo Editorial Desk**

- warm physical work surface
- proof red / editing blue
- source slip as stable origin
- overlapping article/newsletter/social/script sheets with different proportions
- crop marks, page numbers, underlines and proof marks
- creator voice/lineage visible across every output

Avoid black poster shell, CMS/admin dashboard, kanban, scheduler, analytics, platform-logo wall, AI chat and generic equal cards.

## Key surfaces

- Desk overview: source + outputs visible as one production family.
- Article proof: long-form page with proof marks.
- Newsletter: issue/subject-line rhythm.
- Short form: compact crop/card, but not social-platform imitation.
- Video script: scene/voice beat board without playback/editor chrome.
- Format Relay: preserve desk orientation while source becomes each output.

## Acceptance criteria

1. warm physical editorial desk visible immediately;
2. one source and multiple format objects are spatially related;
3. each format has a materially different proportion/rhythm;
4. source/voice lineage remains legible;
5. Format Relay visually changes crop/type/proof grammar;
6. no dark giant-title + tiny abstract-art default;
7. Mobile prioritizes source + current format rather than stacking decorative panels;
8. no CMS/scheduler/analytics drift.
