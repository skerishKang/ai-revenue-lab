## Product thesis

A learner receives one personally edited reading issue where target-language text stays primary and phrase-level support appears in context.

```text
READ → NOTICE → MARGIN ECHO → REVISE → FEEDBACK → NEXT ISSUE
```

Core object: **the annotated reading spread**.

## Reserved visual territory

**Bilingual Field Journal**

- warm paper
- black editorial ink
- one vivid language accent
- restrained annotation blue
- English feature type balanced by Korean UI/support
- underlines, margin notes, vocabulary in context
- issue/date/level/page identity

Avoid flashcard dashboards, XP/streaks, school worksheets, AI tutor chat, always-on translation columns and dark poster openings.
