## Product thesis

Personal memories remain identifiable as sources while the user explores narrative point of view, compares drafts and makes an explicit authorial choice.

```text
SOURCE → POV → DRAFT → COMPARE → AUTHOR
```

Core object: **the working manuscript with source-to-narrative trace**.

## Reserved visual territory

**Narrative Draft Room**

- split source/manuscript workspace
- source facts/timestamps in a restrained evidence rail
- POV lens clearly changes narrative treatment
- paragraph-level draft comparison
- author decision and revision marks
- contemporary writer's room, not archival luxury publication

Avoid B01 collectible cover language, B19 provenance binding sheet, sepia manuscript nostalgia and generic word-processor UI.

## Reference translation

Adopt from manuscript/editing environments:
- source and interpretation stay distinguishable
- alternate POV/draft treatments can be compared line by line
- author decision has final visual authority

Reject:
- AI chat/generation bubbles
- magical “write novel” button
- decorative old-paper/typewriter cosplay

Translate:
- factual memory fragments remain pinned beside a live manuscript whose narrative voice changes visibly with POV selection.

## Key surfaces

- Source: factual memory anchors.
- POV: lens/control with a visible narrative consequence.
- Draft: manuscript is dominant reading/editing object.
- Compare: two versions with changed sentences highlighted.
- Author: user chooses/edits final direction; AI is not author authority.

## Differentiation

- B01 = edited personal publication from heterogeneous fragments.
- B19 = provenance/date/mark/bind memory book.
- B20 = narrative interpretation and explicit authorial choice.

## Acceptance criteria

1. source and manuscript are simultaneously understandable;
2. POV selection visibly alters narrative treatment;
3. compare screen makes differences legible at sentence/paragraph level;
4. author choice remains explicit;
5. no generic dark paper-poster first viewport;
6. Mobile retains source context while reading/choosing draft;
7. source/author safety contracts remain unchanged.
