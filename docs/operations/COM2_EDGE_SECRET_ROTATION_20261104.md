# COM2 edge 증명 비밀 — 교체 절차 (2026-11-04)

COM2의 edge 증명 비밀은 이 호스트의 두 서비스가 함께 읽는다.

| 읽는 쪽 | 파일 | 소유·모드 |
|---|---|---|
| Chat edge 미들웨어 | 기존 edge 비밀 파일 | 원래 소유자, 0600 |
| P01 로컬 Chat 서비스 바인딩 | P01 전용 사본 | P01 서비스 사용자, 0600 |

**edge 비밀은 Chat과 P01 두 파일을 같이 바꾼다.** 한쪽만 바꾸면 P01에서
Chat으로 넘어가는 호출이 edge에서 전부 거절되고, P01 기동 로그에
`p01_local_chat_edge_unconfigured`가 남거나 증명이 거부된다.

## 절차

1. 새 값을 두 파일에 같은 바이트로 준비한다. 두 파일 모두 소유자 전용
   0600을 유지한다. P01 판독기는 group/world 비트가 있는 파일을 거부하므로
   공유 그룹이나 ACL로 권한을 넓히지 않는다.
2. P01과 Chat 유닛을 재기동해 두 서비스가 새 값을 읽게 한다. P01은 기동할
   때 바인딩을 구성하고, Chat edge 미들웨어도 기동할 때 파일을 읽는다.
3. 확인: 두 유닛 active, 두 `/health` 정상, P01 기동 로그에
   `p01_local_chat_edge_unconfigured`가 없음.
4. 롤백: 교체 전 두 파일을 되돌리고 같은 유닛을 재기동한다.

비밀 값은 로그·티켓·보고에 남기지 않는다. 세 번째 사본을 만들지 않는다 —
Chat 원본과 P01 사본 두 파일만 유지한다.
