## History

Previous Free primary was Beam Free, with LongCat 2.5 Preview Free, Gemini 3.1 Flash Lite, and Gemma 4 26B fallback choices. The shared tier declaration formerly embedded non-executable Plus/Pro/Max historical HOLD/retired routes for Beam, Space Bunny, Agnes, Poolside, Qwen, GLM, Kilo MiniMax and related providers. Their history remains available in Git commits preceding this change. Non-executable history is no longer embedded in the live `PRODUCT_TIER_ROUTES` projection.

## Acceptance boundary

This change updates the shared route declaration and B14's static Free recovery path: model selection, ordered fallback candidates, and credential preloading. The Google Free path is scoped to the Free tier; Plus/Pro/Max retain their existing Muse selection. Existing B14 model registrations and applied administrator route overrides may still determine deployed production routing. The deployed B14 version, Chat/Claw/B66 consumers, provider bindings, administrator route ledger, required CI, and real API response must be verified before claiming operational activation. No credentials are included in this document.
