## Parallel-Worker runner cold npm cache diagnosis
- Current-main parallel probe run on PR #4061 [38003090422](https://github.com/skerishKang/ai-revenue-lab/actions/runs/38003090422) failed at the parallel Worker probe after Chat/Core and fixed-configuration tests passed. Logs showed concurrent `npx --yes wrangler@4.130.0 dev` cold installs hitting the same `~/.npm/_npx/...` path and `EEXIST` for `wrangler2`/`esbuild` symlinks; all four probes reported failure. The step is not safe to run cold in parallel.
- Main now owns the fix in `.github/scripts/b62_worker_probe_parallel.sh`: a single pinned `npx --yes wrangler@4.130.0 --version` prewarm occurs inside the runner before the four concurrent probes. This PR does not add a second prewarm or alter those scripts. Static-only skips the entire parallel runner; all other scopes retain prewarming and all four probes. The PR integration must pass exact-head Ubuntu CI.
