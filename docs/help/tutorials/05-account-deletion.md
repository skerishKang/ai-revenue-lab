# ⑤ 계정 탈퇴

> 이 문서는 시나리오 대본 `docs/qa/scenarios/05-account-deletion.md`에서 자동으로 만들어집니다. 화면 문구를 바꾸려면 대본을 고친 뒤 `python tools/tutorial/build_tutorials.py`를 다시 실행하세요.

**이런 분께:** 탈퇴 기능이 병합된 뒤 확인 단계와 안내 범위를 대본화합니다.

**준비물:** 계정이 필요합니다. 시험 계정이 확정되기 전까지는 화면 자리를 비워 두었습니다.

**도움말 함께 보기:** 사용 안내(help.html)의 계정 탈퇴 절(#account)과 같은 내용입니다.

## 단계

### 1단계 · 계정 설정에서 탈퇴 안내를 확인해요.

**이렇게 해요:** 배포된 계정 설정에서 탈퇴 안내 열기

**이렇게 보여요:** 실제 확인 화면 표시

**화면에서 확인하는 것:** 화면 경로·응답 여부·걸린 시간

![계정 설정에서 탈퇴 안내를 확인해요.](asset://chat-tutorial/05-account-deletion/step-01.png)

### 2단계 · 삭제 전에 안내 내용을 꼼꼼히 읽어요.

**이렇게 해요:** 확인 단계와 삭제 범위 읽기

**이렇게 보여요:** 화면에 표시된 범위 확인

**화면에서 확인하는 것:** 문구 캡처·걸린 시간

![삭제 전에 안내 내용을 꼼꼼히 읽어요.](asset://chat-tutorial/05-account-deletion/step-02.png)

### 3단계 · 탈퇴를 실행해요.

> [화면 준비 중 — 시험 계정 확정 후 촬영]

**이렇게 해요:** 탈퇴를 실행해요

**이렇게 보여요:** 탈퇴 완료 화면 표시

**화면에서 확인하는 것:** 탈퇴 요청·재로그인 거부
