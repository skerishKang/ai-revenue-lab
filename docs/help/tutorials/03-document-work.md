# ③ 문서 작업

> 이 문서는 시나리오 대본 `docs/qa/scenarios/03-document-work.md`에서 자동으로 만들어집니다. 화면 문구를 바꾸려면 대본을 고친 뒤 `python tools/tutorial/build_tutorials.py`를 다시 실행하세요.

**이런 분께:** 민감정보가 없는 합성 문서를 올리고 요약한 뒤 내려받습니다.

**준비물:** 계정이 필요합니다. 시험 계정이 확정되기 전까지는 화면 자리를 비워 두었습니다.

## 단계

### 1단계 · 합성 문서를 대화에 첨부해요.

> [화면 준비 중 — 시험 계정 확정 후 촬영]

**이렇게 해요:** 첨부 버튼에서 합성 문서 선택

**이렇게 보여요:** 첨부가 대화에 표시

**화면에서 확인하는 것:** 업로드 상태·걸린 시간, 시간 초과 여부

### 2단계 · 문서에서 필요한 내용을 요약해요.

> [화면 준비 중 — 시험 계정 확정 후 촬영]

**이렇게 해요:** “이 문서를 요약해 줘” 요청

**이렇게 보여요:** 시험 마커가 반영된 요약 표시

**화면에서 확인하는 것:** 응답 상태·완료 걸린 시간·시간 초과 여부

### 3단계 · 결과를 파일로 내려받아요.

> [화면 준비 중 — 시험 계정 확정 후 촬영]

**이렇게 해요:** 결과의 다운로드 버튼 누르기

**이렇게 보여요:** 결과 파일 내려받기

**화면에서 확인하는 것:** 다운로드 상태·걸린 시간

## 영상과 자막

아직 촬영하지 않았습니다 — 이 시나리오는 계정 단계로만 이루어져 있습니다.
시험 계정이 확정되면 `asset://chat-tutorial/03-document-work/video.webm`과 `captions.vtt`로 촬영합니다.
