## 1. 적용 범위와 총칙

이 방침은 공통 계정으로 이용하는 서비스 전체에 공통으로 적용됩니다. 각 서비스가 모으는
항목·보관 위치·보관 기간의 세부 사항은 해당 서비스의 부속 문서(`services/` 폴더)에 적습니다.
서비스 목록은 README와 부속 문서 파일 이름으로 관리하며, 새 서비스는 부속 문서 하나를
추가하는 것으로 이 방침 체계에 들어옵니다.

## 3. 공통 계정 정보

서비스는 공통 로그인 계정을 통해 다음을 확인하고 저장합니다.

| 항목 | 내용 | 목적 |
|---|---|---|
| 로그인 제공자의 식별자 | 구글 로그인이 주는 고유 식별자 | 계정 구분 |
| 이메일 주소 | 로그인 제공자 계정의 이메일 | 로그인·안내 발송 |
| 표시 이름 | 로그인 제공자 계정의 이름 | 화면 표시 |
| 프로필 사진 주소 | 로그인 제공자 계정의 사진 주소 | 화면 표시 |

이 항목들은 서비스를 로그인 상태로 제공하기 위한 최소 범위에서만 사용합니다.

## 4. 수집·이용의 원칙

서비스는 이용자가 맡긴 일을 처리하기 위해 필요한 범위 안에서만 정보를 모읍니다. 각 서비스가
모으는 항목(대화·파일·기록·주문 등)은 해당 서비스의 부속 문서에 적습니다. 이 방침과 부속
문서에 없는 목적으로는 정보를 쓰지 않습니다.

## 5. 보관 기간의 원칙

보관 기간은 다음 원칙에 따릅니다. 항목별 기간은 각 서비스 부속 문서의 보관 기간 표에 적습니다.

1. 이용자가 만들거나 올린 데이터는 이용자가 삭제할 때까지 둡니다(삭제 기능이 있는 데이터).
2. 만료 시각이 정해진 데이터는 그 시각까지 둡니다.
3. 기간이 정해지지 않은 로그·기록은 [대표 결정: 보관 기간] 칸으로 남겨두고, 결정 전에는
   임의로 무기한이라고 쓰지 않습니다.

## 6. 처리 위탁

서비스 운영을 위해 아래 외부 서비스를 사용합니다. 어떤 서비스가 무엇을 보내는지는 각 서비스
부속 문서에 적습니다.

| 구분 | 역할 |
|---|---|
| Cloudflare | 웹 요청 앞단 처리, 로그인 데이터(D1), 파일 객체(R2), 암호화 백업 |
| 외부 AI 모델 공급사 | AI 답변 생성을 위한 대화 내용 전송(해당 서비스만) |
| 데이터베이스 서비스(Neon) | 로그인한 세션의 StoryMemory 원격 메타데이터·어노테이션 동기화 |
| 메일 발송 서비스(Resend) | 안내·재설정 메일 발송(해당 서비스만) |

## 8. 쿠키와 로컬 저장

8.1 로그인 상태는 각 서비스가 자기 도메인의 쿠키로 유지합니다. 쿠키 이름·목적·만료·속성은
각 서비스 부속 문서에 적고, 전체 목록은 README의 점검 결과 표에 정리되어 있습니다.

8.2 광고·추적 쿠키와 외부 분석 스크립트는 어떤 서비스도 사용하지 않습니다. 2026-11-03 코드
전수 점검에서 저장소 안에서 확인되지 않았습니다. Cloudflare 대시보드 설정으로 자동으로
들어가는 기능(Web Analytics 비콘 등)은 저장소 밖 사실이므로 게시 전 점검 항목입니다.

8.3 브라우저 저장소(localStorage·sessionStorage·IndexedDB)에는 서비스 기능에 필요한
데이터(읽기 기록·작업 상태 등)가 저장됩니다. 항목별 내용은 각 서비스 부속 문서에 적습니다.

## 9. 파기

9.1 이용자가 서비스 안에서 삭제한 데이터는 해당 삭제 기능에 따라 지워집니다.

9.2 보관 기간이 끝난 정보나 처리 목적이 끝난 정보는 복구가 어렵도록 지웁니다. 파기 절차·시한의
세부 기준은 [대표 결정: 파기 절차]에서 정합니다.

## 10. 이용자의 권리

이용자는 자신의 개인정보에 대해 다음을 할 수 있습니다.

1. 열람·확인
2. 정정·수정
3. 삭제(서비스별 삭제 기능)
4. 처리 정지(기능별 끄기·일시중지)

권리 행사 창구: [대표 결정: 행사 창구(메일 등)]. 행사 요청은 [대표 결정: 처리 기한] 안에 처리합니다.

## 11. 개인정보의 안전성 확보

- 로그인 콜백의 1회용 인증 코드는 접속 기록에 남지 않도록 걸러 냅니다(요청 경로만 기록).
- 이용자가 등록한 API 키류는 암호화하여 봉인된 상태로 저장하고 화면에는 끝 4자리만 표시합니다.
- 자체 서버 백업은 암호화되어 외부로 나가며, 복호화 키는 백업과 함께 두지 않습니다.
- 비밀번호 재설정 메일 발송 수단이 없을 때는 실패를 솔직히 알리고 가짜 "발송됨" 응답을 만들지 않습니다.

## 12. AI 생성 결과에 대한 고지

서비스가 제공하는 답변·문서·요약 등은 AI 모델이 생성한 결과입니다. 생성 결과는 이용자가
검토한 뒤 사용해야 하며, 전문가의 확인을 대체하지 않습니다.
