## 1. 적용 범위와 총칙

이 방침은 공통 계정으로 이용하는 서비스 전체에 공통으로 적용됩니다. 각 서비스가 모으는
항목·보관 위치·보관 기간의 세부 사항은 해당 서비스의 부속 문서(`services/` 폴더)에 적습니다.
서비스 목록은 README와 부속 문서 파일 이름으로 관리하며, 새 서비스는 부속 문서 하나를
추가하는 것으로 이 방침 체계에 들어옵니다.

## 2. 운영자와 보호책임자

각 서비스의 운영자(상호 등 판매자·운영자 표시 항목)는 해당 서비스 부속 문서에 적습니다.
운영자가 같은 서비스는 같은 값을 적습니다.

- 개인정보 보호책임자: [대표 결정: 성명·연락처]

## 3. 공통 계정 정보

서비스는 공통 로그인 계정을 통해 다음을 확인하고 저장합니다.

| 항목 | 내용 | 목적 |
|---|---|---|
| 로그인 제공자의 식별자 | 구글 로그인이 주는 고유 식별자 | 계정 구분 |
| 이메일 주소 | 로그인 제공자 계정의 이메일 | 로그인·안내 발송 |
| 표시 이름 | 로그인 제공자 계정의 이름 | 화면 표시 |
| 프로필 사진 주소 | 로그인 제공자 계정의 사진 주소 | 화면 표시 |

이 항목들은 서비스를 로그인 상태로 제공하기 위한 최소 범위에서만 사용합니다.

## 4. 수집·이용의 원칙

서비스는 이용자가 맡긴 일을 처리하기 위해 필요한 범위 안에서만 정보를 모읍니다. 각 서비스가
모으는 항목(대화·파일·기록·주문 등)은 해당 서비스의 부속 문서에 적습니다. 이 방침과 부속
문서에 없는 목적으로는 정보를 쓰지 않습니다.

## 5. 보관 기간의 원칙

보관 목적이 끝나거나 보유 기간이 지난 개인정보는 지체 없이 파기합니다. 아래 법정 보관 기록은 다른 이용자 데이터와 분리해 법정 기간 동안 보관합니다. 서비스별 자료와 운영상 미확인 항목은 각 부속 문서와 README의 운영 반영 필요 표에 적습니다.

| 항목 | 보관 기간과 근거 |
|---|---|
| 계정 및 이용자 콘텐츠 | 이용자가 해당 서비스에서 탈퇴하거나 삭제를 요청하면 해당 서비스 원본을 지체 없이 파기합니다. 법정 보관 기록과 백업본은 아래 별도 기준을 따릅니다(「개인정보 보호법」 제21조제1항·제2항). |
| 공통 계정 연결·인증 세션 | 서비스별 탈퇴는 해당 서비스 연결을 끊습니다. 다른 서비스 연결이 남지 않으면 공통 계정을 폐기하고 인증 세션을 무효화합니다. 전체 탈퇴 요청은 연결된 공통 로그인 서비스의 데이터 삭제가 확인된 뒤 공통 계정을 폐기합니다. 관리자 계정은 전체 탈퇴 대상에서 제외합니다. CGI 쇼핑몰은 별도 계정으로 이 절차에 포함되지 않습니다. |
| 전자상거래 거래 기록 | 표시·광고 6개월, 계약·청약철회 5년, 대금결제·재화 공급 5년, 소비자 불만·분쟁 처리 3년(「전자상거래 등에서의 소비자보호에 관한 법률」 제6조 및 같은 법 시행령 제6조). 동의 철회 뒤에도 보관하는 거래 기록·관련 개인정보는 다른 이용자 자료와 분리합니다(같은 법 제6조제2항, 시행령 제6조제2항제3호). |
| 법정 통신사실확인자료에 해당하는 인터넷 로그·접속지 추적자료 | 3개월(「통신비밀보호법」 제2조제11호마목·사목 및 같은 법 시행령 제41조제2항제2호). 이 기간은 해당 법정 자료 범주에만 적용합니다. |
| 그 밖의 로그인·보안 이벤트 | 90일(내부 보관 기준). 위 법정 통신사실확인자료에 해당하지 않는 이벤트에 적용합니다. |
| 서비스 오류·감사 로그 | 확인된 B14 파일 로그는 일일 회전 7세대(최대 7일)입니다. 이외 실제 설정을 확인하지 못한 서버 로그·B14 호출 원장·외부 플랫폼 로그는 90일을 정책상 상한으로 정하며, README 운영 반영 필요 표에 설정 확인·삭제 작업을 적었습니다. |
| 탈퇴 기록 | 개인 식별을 최소화한 계정 식별자 해시와 시각만 1년 보관합니다. 이는 법정 기간이 아니라 내부 기준이며, 필요성·비례성 및 정보주체 권리보다 명백히 우선하는 정당한 이익이 확인되는 범위에서만 처리합니다(「개인정보 보호법」 제15조제1항제6호). |
| 유료 서비스 세무·회계 장부와 증거서류 | 법정 신고 의무가 적용되는 자료는 해당 국세의 법정신고기한이 지난 뒤 일반적으로 5년 보관합니다. 역외거래 등 법정 예외는 그 기간을 따릅니다(「국세기본법」 제85조의3제2항). |
| 서비스 백업 | COM2 로컬 Chat·큐 스냅샷은 코드 기준 일일 7세대, R2 외부 백업은 운영 설정 기준 일일 7세대와 주간 4세대입니다. 원본 삭제 뒤 남은 서버 백업 사본은 순환 삭제되어 최대 28일 안에 사라집니다. Chat 로컬 백업 작업의 실제 설치 상태는 README에 미확인으로 기록합니다. |
| 이용자 PC의 `.padiem-backup` 및 내보낸 백업 파일 | 이용자가 직접 관리하며 삭제할 때까지 기기에 남습니다. 서비스 운영자는 해당 기기 사본의 삭제 시점을 통제하지 않습니다. |
| 만료 시각이 정해진 임시 데이터 | 각 데이터의 `expires_at` 시각까지 보관하고 만료 뒤 지체 없이 파기합니다. 일부 데이터의 자동 삭제 실행 경로는 확인되지 않아 README 운영 반영 필요 표에 남깁니다. |

위 기간은 서비스 데이터별 표에 구체화합니다. 백업본에 남은 탈퇴·삭제 데이터는 정상 서비스 이용에 제공하지 않으며, 정해진 순환 기간 안에 자연 소멸합니다.

## 8. 쿠키와 로컬 저장

8.1 로그인 상태는 각 서비스가 자기 도메인의 쿠키로 유지합니다. 쿠키 이름·목적·만료·속성은
각 서비스 부속 문서에 적고, 전체 목록은 README의 점검 결과 표에 정리되어 있습니다.

8.2 광고·추적 쿠키와 외부 분석 스크립트는 어떤 서비스도 사용하지 않습니다. 2026-11-03 코드
전수 점검에서 저장소 안에서 확인되지 않았습니다. Cloudflare 대시보드 설정으로 자동으로
들어가는 기능(Web Analytics 비콘 등)은 저장소 밖 사실이므로 게시 전 점검 항목입니다.

8.3 브라우저 저장소(localStorage·sessionStorage·IndexedDB)에는 서비스 기능에 필요한
데이터(읽기 기록·작업 상태 등)가 저장됩니다. 항목별 내용은 각 서비스 부속 문서에 적습니다.

## 9. 파기

9.1 이용자가 서비스 안에서 삭제한 데이터는 해당 삭제 기능에 따라 지워집니다.

9.2 보유 기간이 끝나거나 처리 목적이 끝난 개인정보는 지체 없이 복구할 수 없도록 파기합니다(「개인정보 보호법」 제21조제1항부터 제3항까지). 법령에 따라 더 보관해야 하는 자료는 다른 개인정보와 분리해 해당 기간 동안 보관합니다. 서버 백업에 남은 삭제·탈퇴 데이터는 정상 서비스에서 이용하지 않고 백업 순환으로 최대 28일 안에 삭제합니다. 이용자 PC의 `.padiem-backup` 사본은 이용자가 직접 삭제합니다.

## 10. 이용자의 권리

이용자는 자신의 개인정보에 대해 다음을 할 수 있습니다.

1. 열람·확인
2. 정정·수정
3. 삭제(서비스별 삭제 기능)
4. 처리 정지(기능별 끄기·일시중지)

권리 행사 창구: [대표 결정: 행사 창구(메일 등)]. 행사 요청은 [대표 결정: 처리 기한] 안에 처리합니다.

## 11. 개인정보의 안전성 확보

- 로그인 콜백의 1회용 인증 코드는 접속 기록에 남지 않도록 걸러 냅니다(요청 경로만 기록).
- 이용자가 등록한 API 키류는 암호화하여 봉인된 상태로 저장하고 화면에는 끝 4자리만 표시합니다.
- 자체 서버 백업은 암호화되어 외부로 나가며, 복호화 키는 백업과 함께 두지 않습니다.
- 비밀번호 재설정 메일 발송 수단이 없을 때는 실패를 솔직히 알리고 가짜 "발송됨" 응답을 만들지 않습니다.

## 12. AI 생성 결과에 대한 고지

서비스가 제공하는 답변·문서·요약 등은 AI 모델이 생성한 결과입니다. 생성 결과는 이용자가
검토한 뒤 사용해야 하며, 전문가의 확인을 대체하지 않습니다.
