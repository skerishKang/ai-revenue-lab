## 1. 서비스의 범위

PADIEM(이하 "서비스")은 다음 기능을 제공하는 웹 기반 AI 업무 서비스입니다.

1. 대화형 AI 상담·문서 작성·견적 지원
2. 파일·문서 업로드와 프로젝트 파일 관리
3. 이용자가 사전에 위임한 범위에서의 PC 작업 수행(제2조)
4. 북AI 등 부가 기능
5. 메일·텔레그램·디스코드 알림

## 2. 사전 위임 방식의 PC 작업과 컴퓨터 사용

서비스는 이용자가 사전에 맡긴 범위에서 이용자의 PC 작업을 자동 실행합니다. 권한의 기본 원칙은 다음과 같습니다.

> 사용자가 사전에 맡긴 범위에서 PC 작업을 자동 실행하며 기본은 최대 권한, 비밀번호 입력·계정 권한 변경·되돌릴 수 없는 삭제·외부 발송만 실행 전 확인, 끄기·일시중지·연결 해제·제거는 언제든 가능.

2.1 실행 전 확인이 필요한 작업(비밀번호 입력, 계정 권한 변경, 되돌릴 수 없는 삭제, 외부 발송)은 서비스가 이용자의 확인을 받은 뒤에 실행합니다.

2.2 PC 작업 기록은 내용이 없는 처리 건수 형태로만 남습니다. 파일 경로·명령 인수·출력 내용은 기록에 포함되지 않습니다.

2.3 컴퓨터 사용 입력값은 해당 동작에 1회 전달되며 재사용되지 않고, 세션 재개 시 이전 폼 입력을 되살리는 기능은 제공하지 않습니다.

2.4 파일을 변경하는 PC 작업은 변경 전 원본을 이용자 PC의 숨김 폴더(`.padiem-backup`)에 복사한 뒤 진행됩니다. 이 백업 사본은 이용자 PC에 남습니다.

2.5 PC 화면 캡처는 이용자 PC에 저장되고, 캡처를 요청한 계정의 세션으로만 조회할 수 있습니다.

2.6 이용자는 언제든 PC 작업을 끄거나 일시중지할 수 있고, 연결 해제·에이전트 제거도 언제든 할 수 있습니다.

## 3. AI 생성 결과에 대한 고지

서비스가 제공하는 답변·문서·견적·요약 등은 AI 모델이 생성한 결과입니다. 생성 결과에는 오류·누락·부정확한 내용이 포함될 수 있으므로, 이용자는 결과를 업무에 사용하기 전에 스스로 검토해야 합니다. AI 생성 결과는 전문가(법률·세무·의료 등)의 확인을 대체하지 않습니다.

## 4. 계정과 이용자의 책임

4.1 계정은 서비스 공통 로그인으로 발급됩니다. 로그인 방식과 계정 정보의 처리는 개인정보처리방침 초안(`privacy_policy_ko.md`)에 따릅니다.

4.2 이용자는 자신의 계정·비밀번호·세션을 직접 관리하고, 자신의 계정에서 일어난 활동에 대한 책임을 부담합니다.

4.3 이용자가 직접 등록한 외부 AI 공급사 API 키(BYOK)는 암호화하여 봉인된 형태로만 보관되며, 서비스 화면에는 키 끝 4자리만 표시됩니다. 이용자는 자신이 발급한 키의 유효성과 해당 공급사 이용약관 준수를 스스로 책임집니다.

4.4 PC 작업 권한은 이용자가 등록한 자신의 PC에만 적용됩니다. 타인의 PC·계정·데이터에 접근해서는 안 됩니다.

## 5. 이용 제한

다음 각 호에 해당하는 경우 서비스 이용을 제한하거나 중단할 수 있습니다.

1. 법령 또는 타인의 권리를 침해하는 목적으로의 이용
2. 타인의 계정·PC·데이터에 대한 무단 접근
3. 서비스의 보안·요금·자원 구조를 무너뜨리는 비정상 이용
4. 서비스의 정상 운영을 방해하는 행위

## 8. 면책

8.1 AI 생성 결과에 대해서는 제3조의 고지를 적용합니다.

8.2 PC 작업은 제2조의 확인 절차와 쓰기 전 백업 절차를 거쳐 실행됩니다. 이용자가 사전 위임 범위 밖의 작업을 요청하거나, 확인 절차에서 이용자가 직접 승인한 작업의 결과에 대해서는 [대표 결정: 면책 범위]에서 정한 바에 따릅니다.
