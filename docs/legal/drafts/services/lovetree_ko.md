## 1. 서비스의 범위

러브트리는 이용자의 순간을 트리로 남기고 공유하는 웹 서비스입니다. 로그인은 공통 계정으로
합니다(`auth.padiem.net`를 로그인 공급자로 사용).

## 2. 이 서비스가 모으는 항목

| 수집 항목 | 내용 | 목적 | 근거 |
|---|---|---|---|
| 워크스페이스 문서 | 이용자가 만든 트리·순간 기록(문서 JSON) | 내 기록 저장·이어 보기 | `server/db/schema.sql:5-12` |
| 공유 | 내 트리의 공유 주소(공개·비공개) | 트리 공유 | `server/db/schema.sql:61-79` |
| 커뮤니티 활동 | 즐겨찾기·감정 표시·댓글(1,000자 이내)·신고(500자 이내) | 커뮤니티 기능 | `server/db/schema.sql:83-131` |
| 로그인 상태 | 로그인 state 해시와 만료 시각(원본은 남기지 않음) | 로그인 보호 | `server/db/schema.sql:28-33` |
| 관리자 역할 | 관리자 지정과 부여·회수 이력 | 운영 관리 | `server/db/schema.sql:36-59` |

이메일·전화번호·주소 같은 연락처 항목은 이 서비스의 저장소 스키마에 없습니다. 신원은 공통
계정의 주제 식별자로만 둡니다.

## 3. 보관 위치

- 데이터베이스: PostgreSQL(운영 저장 주소는 배포 설정으로 지정)
- 앞단: Cloudflare Pages Functions(프록시)
- 이용자 기기: localStorage `lovetree.track64.handoff` 1키(디자인 뷰에서 "책으로 보기" 이동을 돕는 진행 상태)

## 4. 쿠키

로그인 관련 쿠키 4종을 사용합니다. 모두 인증·상태 보호 목적입니다.

| 쿠키 | 목적 | 만료 |
|---|---|---|
| `__Host-lovetree-access` | 접근 토큰 | 15분 |
| `lovetree_refresh` | 재발급 토큰(공통 인증 경로로만 전송) | 30일 |
| `__Host-lovetree-shared` | 화면 표시용 힌트(값 '1') | 30일 |
| `lovetree_auth_state` | 로그인 state 보호 | 600초 |

근거: `functions/_lib/shared-auth.mjs:55-59,73`. 모두 HttpOnly·SameSite=Lax이고 Secure는 배포가 정합니다.

## 5. 삭제

5.1 이용자가 직접 지울 수 있는 것: 댓글·즐겨찾기·감정 표시·공유·개인 미디어(각 항목의 삭제
기능이 확인되어 있습니다).

5.2 확인되지 않은 것: 워크스페이스 문서(내 기록)의 삭제 기능과 계정 탈퇴 라우트가 코드에서
확인되지 않았습니다. 삭제 절차는 [대표 결정: 워크스페이스·계정 삭제 절차]에서 정합니다.

## 6. 외부 콘텐츠와 추적

- 이용자가 순간에 넣은 영상은 YouTube 임베드로 재생됩니다. 임베드는 영상이 있는 화면에서만 읽히고, YouTube가 그 맥락에서 수집하는 것은 YouTube의 정책을 따릅니다.
- 광고·추적 쿠키와 외부 분석 스크립트는 사용하지 않습니다(2026-11-03 코드 전수 점검).
- 화면 폰트는 서비스 안에서 직접 제공합니다(외부 폰트 호출 없음).

## 7. AI 기능

러브트리 화면이 외부 AI 모델 공급사로 내용을 보내는 경로는 저장소 안에서 확인되지 않았습니다.
AI 기능을 넣을 때는 공통 방침의 처리 위탁·국외 이전 표를 갱신합니다.
