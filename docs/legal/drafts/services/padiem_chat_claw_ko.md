## 1. 서비스의 범위

PADIEM Chat·Claw는 대화형 AI 상담·문서 작성·견적 지원, 파일·문서 업로드와 프로젝트 파일
관리, 이용자가 사전에 위임한 범위에서의 PC 작업 수행, 메일·텔레그램·디스코드 알림을
제공하는 웹 기반 AI 업무 서비스입니다.

## 2. 사전 위임 방식의 PC 작업과 컴퓨터 사용

서비스는 이용자가 사전에 맡긴 범위에서 이용자의 PC 작업을 자동 실행합니다. 권한의 기본 원칙은 다음과 같습니다.

> 사용자가 사전에 맡긴 범위에서 PC 작업을 자동 실행하며 기본은 최대 권한, 비밀번호 입력·계정 권한 변경·되돌릴 수 없는 삭제·외부 발송만 실행 전 확인, 끄기·일시중지·연결 해제·제거는 언제든 가능.

2.1 실행 전 확인이 필요한 작업(비밀번호 입력, 계정 권한 변경, 되돌릴 수 없는 삭제, 외부 발송)은 서비스가 이용자의 확인을 받은 뒤에 실행합니다.

2.2 PC 작업 기록은 내용이 없는 처리 건수 형태로만 남습니다. 파일 경로·명령 인수·출력 내용은 기록에 포함되지 않습니다.

2.3 컴퓨터 사용 입력값은 해당 동작에 1회 전달되며 재사용되지 않고, 세션 재개 시 이전 폼 입력을 되살리는 기능은 제공하지 않습니다.

2.4 파일을 변경하는 PC 작업은 변경 전 원본을 이용자 PC의 숨김 폴더(`.padiem-backup`)에 복사한 뒤 진행됩니다. 이 백업 사본은 이용자 PC에 남습니다.

2.5 PC 화면 캡처는 이용자 PC에 저장되고, 캡처를 요청한 계정의 세션으로만 조회할 수 있습니다.

2.6 이용자는 언제든 PC 작업을 끄거나 일시중지할 수 있고, 연결 해제·에이전트 제거도 언제든 할 수 있습니다.

## 4. 보관 위치

- 자체 서버: 서비스 운영 서버, 파일 원본 처리
- Cloudflare: 웹 요청 앞단, 로그인 데이터(D1), 워크스페이스 파일 객체(R2), 외부 백업
- 외부 AI 모델 공급사: 이용자의 대화 내용을 답변 생성에 사용하기 위해 전송. BYOK 키를 쓸 때는 해당 키가 선택한 공급사로 직접 전송됩니다.
- 메일 발송(Resend): 비밀번호 재설정 안내 등
- 관리자 알림(텔레그램·디스코드): 새 회원가입 접수 같은 운영 알림만 담으며, 고객의 이메일 주소나 문서 내용은 알림 본문에 넣지 않습니다.

| 항목 | 보관 기간 |
|---|---|

| BYOK 키 | 이용자가 삭제하거나 바꿀 때까지(암호화 봉인 상태로 보관) |
| 만료 속성을 둔 임시 데이터(작업 임시 저장·선택값·승인 대기 등) | 데이터마다 정해진 `expires_at` 시각까지. 만료 뒤 지체 없이 파기합니다. 일부 자동 삭제 실행 경로는 확인되지 않았습니다. |
| 로그인 확인 캐시 | 최대 30초 |
| 서버 백업 | COM2 로컬 Chat 스냅샷은 코드 기준 일일 7세대이며 실제 작업 설치 상태는 확인되지 않았습니다. R2 외부 백업은 일일 7세대·주간 4세대입니다. 원본 삭제 뒤 백업 사본은 순환 삭제되어 최대 28일 안에 사라집니다. |
| 이용자 PC 쓰기 전 백업(`.padiem-backup`) | 이용자가 삭제할 때까지 이용자 PC에 남습니다. |
| 접속 기록·호출 원장·오류·감사 로그 | 법정 통신사실확인자료에 해당하는 인터넷 로그·접속지 추적자료는 3개월입니다(공통 방침 5조). 확인되지 않은 서버 로그·B14 호출 원장은 정책상 90일 이내 보관합니다. B14 파일 로그는 현재 일일 회전 7세대입니다. 설정·삭제 구현이 필요한 항목은 README 운영 반영 필요 표에 적었습니다. |

계정 탈퇴 시 데이터 파기 기준은 공통 약관 4.2조와 공통 개인정보처리방침 5·9조를 따릅니다. 코드에 `expires_at` 속성은 있으나 일부 데이터의 자동 삭제 경로는 확인되지 않았으며, 운영 반영 필요 항목으로 남겼습니다.

## 6. 계정 전체 탈퇴

계정 전체 탈퇴는 앱의 설정 > 계정 탈퇴에서 본인 이메일을 다시 입력해 실행합니다(`apps/padiem-chat/app/account_deletion.py`). 대화·프로젝트·파일·PC 연결·MCP 토큰·감사 기록 등 계정 데이터와 계정에 저장된 북AI 기록을 한 트랜잭션에서 지웁니다. PC 명령 중복 실행 방지 기록(`oracle_mesh_dispatch`)은 행만 남기고, 누구의 것인지 알 수 없게 사용자·계정·기기 식별자와 명령 본문을 지웁니다. 기기에만 저장된 북AI 기록, 공통 로그인 계정, 외부 백업은 남으며 외부 백업 사본은 공통 방침의 순환 기간 안에 삭제됩니다.

## 7. 쿠키

이 서비스가 설정하는 쿠키는 8종이고 모두 인증·상태 보호 목적입니다: 로그인 세션(7일), 로그인 state 보호(600초), 깃허브 연동 state(600초), 공통 로그인 state·접근·재발급·표시·비교 쿠키(600초·15분·30일). 모두 HttpOnly·SameSite=Lax이며 Secure는 배포에서 정합니다. 전체 표는 README의 점검 결과 절에 있습니다.
