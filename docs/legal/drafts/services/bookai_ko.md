## 1. 서비스의 범위와 운영 형태

북AI는 읽고, 묻고, 기억하는 책 앱입니다. StoryMemory 1.1에서 분리한 별도 앱이며, 성경을
포함한 모든 책에 적용합니다. StoryMemory와 북AI를 별도 서비스로 나눠 운영할지는
[대표 결정: 서비스 단위(북AI·StoryMemory 별도 운영 여부)]에서 정합니다. 이 문서는 둘을
하나로 묶어 적습니다.

## 2. 기록의 저장 규칙 (기기 저장 + 계정 저장)

2.1 로그인하지 않아도 읽기 기록과 Memory는 이 기기(브라우저)에 저장됩니다. 이 데이터는
이용자의 브라우저에 남고 자동으로 수집되지 않습니다.

- 북AI: localStorage 접두어 키(읽기 위치·Memory·어노테이션·책 순서·이어보기) + IndexedDB `bookai-local-v1`(entries·meta·records·outbox 스토어)
- StoryMemory: localStorage `storymemory.*` 키(읽기 진행·어노테이션·책 순서·표시 설정)

2.2 파디엠 계정(공통 계정)으로 로그인하면 기록이 계정에도 저장되어 다른 기기에서 이어집니다.
계정 기록은 운영 서버의 저장소에 적립됩니다(공개 경로 `chat.padiem.net/api/bookai/records`,
이용자 본인 주제만 접근).

2.3 북AI는 로그인한 이용자의 읽기 위치·어노테이션·메모·저장한 AI 대화를 계정 기록 API(/api/bookai/records)로 동기화합니다(2.2절). 계정 기록은 운영 서버의 저장소에 적립됩니다.

2.4 이용자는 기기의 기록 백업 파일을 내보내고 불러올 수 있습니다. 백업 파일에는 읽기 기록과
메모가 담깁니다.

## 3. 이 서비스가 모으는 항목

| 수집 항목 | 내용 | 목적 |
|---|---|---|
| 읽기 기록 | 읽은 위치·진행·하이라이트·어노테이션 | 이어 보기·기억 기능 |
| Memory·메모 | 이용자가 남긴 메모와 기억 항목 | 기억·질문 답변 |
| AI 대화 기록 | 이용자가 북AI에서 나눈 질문·답변 | 대화 이어 보기 |
| 계정 정보 | 공통 계정(공통 방침 3조) | 로그인·계정 저장·다른 기기 이어 보기 |

## 4. 보관 기간

| 항목 | 보관 기간 |
|---|---|
| 기기 저장 기록(브라우저 저장소) | 이용자가 브라우저 데이터를 지우거나 앱에서 삭제할 때까지 |
| 계정 저장 기록 | 이용자가 삭제할 때까지. 삭제 기능의 범위는 [대표 결정: 삭제 기능·기간] |
| 백업 파일 | 이용자의 기기에 남으며 이용자가 직접 관리합니다 |

## 5. 삭제

5.1 기기의 기록은 브라우저 데이터 삭제 또는 앱 안 삭제 기능으로 지웁니다.

5.2 계정에 저장된 기록의 삭제는 기록 단위 삭제가 확인되어 있습니다(삭제 표시를 남기는 방식).
계정 전체 탈퇴와 전체 기록 삭제의 절차는 [대표 결정: 삭제 절차]에서 정합니다.

## 6. 쿠키와 외부 도메인

- 북AI·StoryMemory 페이지가 스스로 설정하는 쿠키는 저장소 안에서 확인되지 않았습니다. 로그인 상태는 공통 계정의 쿠키로 유지됩니다(README 점검 결과 참조).
- 이용자 브라우저가 닿는 외부 도메인은 웹폰트(`fonts.googleapis.com`, `fonts.gstatic.com`)와 로그인한 세션의 계정 기록 API(`chat.padiem.net/api/bookai/records`)입니다.
- 광고·추적 쿠키와 외부 분석 스크립트는 사용하지 않습니다(공통 방침 8.2).
