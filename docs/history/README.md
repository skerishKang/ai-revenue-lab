# 역사 기록 및 증거 안내

~~~text

SCOPE = NAVIGATION_ONLY
~~~

- 날짜별·이슈별 문서는 해당 시점의 **증거와 결정 기록**으로 보존합니다. 그 안의 과거 모델명이나 라우트가 현재 승인을 뜻하지는 않습니다.
- 현재 문서의 권위 및 우선순위는 [Documentation Authority Model](../governance/DOCUMENTATION_AUTHORITY_MODEL.md)을 따릅니다.
- 현재 사업 기준은 [사업별 안내](../businesses/README.md), 현재 모델 결정과 등록 근거는 [모델 공식 진입점](../models/README.md), 증거 및 승인 요건은 [개발 단계별 안내](../lifecycle/README.md)를 참조합니다.
- 예시 역사 기록: B66 [원본 참고 README](2026-10-08/B66_QUOTE_BETA_REFERENCE_README.snapshot.md) 및 [원본 DEMO GUIDE](2026-10-08/B66_QUOTE_BETA_DEMO_GUIDE.snapshot.md). 이 원문 기록은 현재 제품 사양을 대체하지 않습니다.

**보존 원칙:** 기존 역사 기록은 임의로 삭제하거나 현재 정책에 맞게 다시 쓰지 않습니다. 이동이 꼭 필요하면 링크 검사와 원문 바이트 보존을 별도 검증합니다.
