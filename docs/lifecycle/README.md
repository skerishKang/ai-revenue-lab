# 개발 단계별 문서 안내

~~~text
DOC_STATUS = CANONICAL
SCOPE = NAVIGATION_ONLY
~~~

각 단계는 **진행 방법과 증거 기준**을 연결합니다. 제품의 현재 개발 단계, 배포 SHA 또는 모델 사용 가능 여부를 이 문서에 복사하지 않습니다.

| 단계 | 기준 문서 |
|---|---|
| 1. 사업 등록 및 기술 탐색 | [Business Registry](../portfolio/BUSINESS_REGISTRY.md), [Technology Adoption Policy](../operations/TECHNOLOGY_ADOPTION_POLICY.md) |
| 2. 설계 및 책임 경계 | [AI Development Operating Policy](../operations/AI_DEVELOPMENT_OPERATING_POLICY.md), [UI/UX Backend Phase Gates](../operations/UI_UX_BACKEND_PHASE_GATES.md) |
| 3. 구현 및 로컬 협업 | [Code Structure Policy](../operations/CODE_STRUCTURE_AND_ASSET_VERSIONING_POLICY.md), [Multi-Machine Worktree Policy](../operations/MULTI_MACHINE_LOCAL_WORKTREE_POLICY.md) |
| 4. 테스트 및 검증 | [Test Scope and Delivery Policy](../operations/TEST_SCOPE_AND_DELIVERY_POLICY.md), [Evidence Requirements](../operations/EVIDENCE_REQUIREMENTS.md) |
| 5. 리뷰, 승인 및 배포 | [GitHub Report Handoff Policy](../operations/GITHUB_REPORT_HANDOFF_POLICY.md), [Production Deployment and Rollback Policy](../operations/DIRECT_PRODUCTION_DEPLOYMENT_AND_ROLLBACK_POLICY.md) |
| 6. 운영과 상태 확인 | [Workflow Status Model](../operations/WORKFLOW_STATUS_MODEL.md), [역사 및 증거](../history/README.md) |

**단계는 사업이 아닙니다.** B14·B62·B66 등은 같은 단계 규칙을 참조하지만 제품별 구현과 검증 사실은 별도로 입증해야 합니다. 모델 관련 결정과 등록은 [모델 진입점](../models/README.md)을 따릅니다.
