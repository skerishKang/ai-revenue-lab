# Padiem Chat / Claw 사용자 가이드

## Padiem Chat

Padiem Chat은 질문, 문서, 프로젝트, 검색 기능을 한곳에서 사용하는 Padiem의 기본 AI 작업공간입니다.

### 언어 변경

설정에서 KR / EN을 선택할 수 있습니다.

Chat과 Claw는 같은 언어 설정을 사용합니다. Claw에 별도의 언어 설정은 두지 않습니다.

### 화면 테마

Padiem 제품은 하나의 공통 테마 체계를 사용합니다.

기본 화면은 Padiem 브랜드 테마를 사용하고, 필요에 따라 Light 또는 Dark 모드를 선택할 수 있습니다.

Claw는 Chat과 같은 테마를 그대로 사용합니다.

## Padiem Claw

Padiem Claw는 받은 업무 요청을 정리하고 업무 초안을 준비하는 AI 작업공간입니다.

예를 들어 다음과 같은 요청을 붙여넣어 사용할 수 있습니다.

- 거래처의 견적 요청
- 발주 요청
- 이메일이나 메신저로 받은 문의
- 답장이 필요한 업무 요청
- 여러 항목이 섞인 요청사항 정리

### 기본 사용 흐름

1. Claw를 엽니다.
2. 요청 원문을 입력하거나 붙여넣습니다.
3. 필요한 작업을 선택합니다.
4. 미리보기로 결과 형태를 확인합니다.
5. 실제 실행이 필요한 경우 실행합니다.
6. 지원되는 결과는 문서로 열거나 다운로드합니다.

### 미리보기와 실제 실행

미리보기는 실제 업무 실행이나 저장 없이 결과 형태를 확인하기 위한 기능입니다.

실제 실행은 AI가 서버에서 작업을 처리하는 기능입니다.

두 상태는 화면에서도 명확히 구분되어야 하며, 실패한 요청을 성공으로 표시하지 않습니다.

### 오류가 발생했을 때

오류가 표시되면 입력 내용을 확인한 뒤 다시 시도해 주세요.

연결 오류나 일시적인 서버 오류인 경우 잠시 후 다시 시도할 수 있습니다.

오류가 발생한 경우 사용자가 입력한 원문을 AI가 만든 결과처럼 표시하지 않습니다.

## 문서와 개인정보

Padiem 제품의 저장·문서·연결 서비스 기능은 각 기능 화면에 표시된 현재 지원 범위와 승인 절차를 따릅니다.

준비 중인 기능은 실제로 연결된 기능처럼 표시하지 않습니다.

## 제품 일관성

Padiem Website, Padiem Chat, Padiem Claw는 하나의 제품군입니다.

언어, 테마, 용어와 핵심 상호작용은 가능한 한 동일한 기준을 사용합니다.
