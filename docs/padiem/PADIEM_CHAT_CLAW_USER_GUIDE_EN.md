# Padiem Chat / Claw User Guide

## Padiem Chat

Padiem Chat is Padiem’s general AI workspace for questions, documents, projects, and supported research workflows.

### Language

Choose KR / EN in Settings.

Chat and Claw share the same language preference. Claw does not maintain a separate language setting.

### Appearance

Padiem products use one shared theme system.

The default appearance follows the Padiem brand theme, with Light and Dark available as preference modes.

Claw inherits the active Chat theme.

## Padiem Claw

Padiem Claw is an AI workspace for turning incoming business requests into structured work and drafts.

Typical inputs include:

- quote requests;
- purchase-order requests;
- email or messenger inquiries;
- requests that need a reply;
- mixed business instructions that need to be organized.

### Basic workflow

1. Open Claw.
2. Enter or paste the original request.
3. Choose the task when needed.
4. Use Preview to check the expected result.
5. Use Real run when actual AI execution is required.
6. Open or download supported document results.

### Preview and Real run

Preview lets you inspect the expected result without performing the real workflow or saving an artifact.

Real run sends the task through the supported server-side AI execution path.

The interface must keep these states distinct and must never display a failed request as a successful run.

### Errors

If an error appears, check the input and try again.

For connection or temporary server errors, retry after a short interval.

When a request fails, the interface must not present the user’s original input as if it were an AI-generated result.

## Documents and connected services

Storage, document, and connector behavior follows the capability currently shown by the product and any required approval step.

Features that are still in preparation must not be presented as active.

## Product consistency

Padiem Website, Padiem Chat, and Padiem Claw are one product family.

Language, appearance, terminology, and primary interaction rules should follow one shared product standard.
