# ① 처음 온 사람

**목적:** 첫 화면에서 로그인 경로를 찾고 첫 질문과 답변까지 확인합니다.  
**사전 조건:** 첫 화면은 게스트로 확인합니다. 질문은 준비된 로그인 세션이 필요하며 실제 인증은 수행하지 않습니다.  
**튜토리얼 공개 범위:** 게스트 1–3; 로그인 4–6

| 단계 | 사용자 동작 → 기대 화면·응답 | 확인 지표 | 튜토리얼 캡션 |
|---|---|---|---|
| 1 | https://chat.padiem.net/ 열기 → “안녕하세요.”와 “무엇을 도와드릴까요?” 표시 | GET 상태, 로드 ms, 504 여부 | 첫 화면에서 무엇을 물어볼지 시작해요. |
| 2 | 로그인 없이 게스트 상태 확인 → authenticated=false 표시 | 상태 코드, 단계 ms | 게스트 상태를 확인해요. |
| 3 | 로그인 없이 대화 목록 요청 → 401 “로그인이 필요합니다.” 안내 | 상태 코드, 단계 ms | 로그인이 필요한 항목은 로그인 안내로 안전하게 막아요. |
| 4 | 준비된 세션으로 Chat을 열고 로그인 상태 확인 → 계정으로 이어짐 | 상태 코드, 단계 ms | 준비한 계정으로 로그인 상태를 확인해요. |
| 5 | 질문을 입력해 보내기 → 대화에 질문 표시 | 응답 상태, 완료 ms, 504 여부 | 궁금한 점을 질문으로 보내요. |
| 6 | 답변 확인 → 답변 표시, 요청이 504가 아님 | HTTP 상태, 완료 ms, 504 여부 | 답변을 읽고 필요한 내용을 확인해요. |

세션 파일이 없으면 4–6단계 자동 시험은 test_account_missing으로 건너뜁니다. 이번 실행은 첫 화면, 게스트 상태, 로그인 차단 GET만 확인합니다.
