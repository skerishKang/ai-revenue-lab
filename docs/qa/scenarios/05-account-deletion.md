# ⑤ 계정 탈퇴

**목적:** 탈퇴 기능이 병합된 뒤 확인 단계와 안내 범위를 대본화합니다.  
**사전 조건:** 기능이 병합·활성화되고 시험 계정이 준비되기 전까지 실행하지 않습니다.  
**튜토리얼 공개 범위:** 로그인 1–3

| 단계 | 사용자 동작 → 기대 화면·응답 | 확인 지표 | 튜토리얼 캡션 |
|---|---|---|---|
| 1 | 배포된 계정 설정에서 탈퇴 안내 열기 → 실제 확인 화면 표시 | 화면 경로·상태 코드·ms | 계정 설정에서 탈퇴 안내를 확인해요. |
| 2 | 확인 단계와 삭제 범위 읽기 → 화면에 표시된 범위 확인 | 문구 캡처·ms | 삭제 전에 안내 내용을 꼼꼼히 읽어요. |
| 3 | 탈퇴는 실행하지 않고 취소하기 → 시험 계정 유지 | 탈퇴 요청 0건 | 이번 확인에서는 탈퇴를 실행하지 않아요. |

기능 활성화 전에는 화면 문구와 경로를 추측하지 않습니다. 이 대본은 자리만 마련하며 자동 시험은 후속 검토 전까지 실행하지 않습니다.
