# ② PC 연결

**목적:** 설치 안내에서 PC 연결 승인 뒤 자연어 파일 검색까지 확인합니다.  
**사전 조건:** 로그인, 시험 PC 등록·온라인 상태, Owner가 허용한 연결 승인이 필요합니다. 계정이 준비된 뒤에만 승인 단계를 실행합니다.

| 단계 | 사용자 동작 → 기대 화면·응답 | 확인 지표 | 튜토리얼 캡션 |
|---|---|---|---|
| 1 | 설치 안내 열기 → “컴퓨터 연결 프로그램 설치 안내”와 “이 PC 연결하기” 표시 | GET 상태, 로드 ms | 내 컴퓨터를 연결할 설치 안내를 살펴봐요. |
| 2 | 설치 파일 안내 보기 → 현재 배포 상태에 맞는 안내 표시; 파일을 자동 실행하지 않음 | 상태 코드·문구, ms | 안내를 확인하고 설치 파일을 준비해요. |
| 3 | 시험 PC 연결 승인 요청 확인·승인 → 연결된 PC 상태 표시 | 승인 응답 상태·ms, 504 여부 | 준비된 시험 PC 연결을 승인해요. |
| 4 | “내 컴퓨터에서 xlsx 찾아줘” 요청 → 검색 결과 표시 | 상태 코드·총 ms·504 여부·결과 표시 | 자연어로 컴퓨터의 파일을 찾아봐요. |
| 5 | 결과 확인 | 완료 상태·ms | 검색 결과를 확인해요. |

첫 실행에는 로그인 계정과 시험 PC가 없어 test_account_missing으로 건너뜁니다. 승인과 PC 명령을 실행하지 않습니다.
