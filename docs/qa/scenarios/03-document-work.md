# ③ 문서 작업

**목적:** 민감정보가 없는 합성 문서를 올리고 요약한 뒤 내려받습니다.  
**사전 조건:** 준비된 로그인 세션과 합성 시험 문서가 필요합니다. 운영 파일은 사용하지 않습니다.  
**튜토리얼 공개 범위:** 로그인 1–3

| 단계 | 사용자 동작 → 기대 화면·응답 | 확인 지표 | 튜토리얼 캡션 |
|---|---|---|---|
| 1 | 첨부 버튼에서 합성 문서 선택 → 첨부가 대화에 표시 | 업로드 상태·ms, 504 여부 | 합성 문서를 대화에 첨부해요. |
| 2 | “이 문서를 요약해 줘” 요청 → 시험 마커가 반영된 요약 표시 | 응답 상태·완료 ms·504 여부 | 문서에서 필요한 내용을 요약해요. |
| 3 | 결과의 다운로드 버튼 누르기 → 결과 파일 내려받기 | 다운로드 상태·ms | 결과를 파일로 내려받아요. |

세션 파일이 없으면 test_account_missing으로 건너뜁니다. 자동화에는 합성 파일만 사용합니다.
