# ④ 북AI

**목적:** 게스트 기기 저장과 로그인 뒤 다른 기기에서 이어 보기를 확인합니다.  
**사전 조건:** 북AI 화면은 게스트로 열 수 있습니다. 계정 동기화에는 로그인 세션과 별도 기기가 필요합니다.  
**튜토리얼 공개 범위:** 게스트 1, 3; 로그인 2, 4

| 단계 | 사용자 동작 → 기대 화면·응답 | 확인 지표 | 튜토리얼 캡션 |
|---|---|---|---|
| 1 | https://bookai.padiem.net/ 열기 → 서가와 “책 열기” 버튼 표시 | GET 상태·로드 ms | 북AI에서 읽기 기록을 남겨요. |
| 2 | 오른쪽 위 TODAY를 열고(데스크톱은 서가에 마우스를 올려야 보임) “이어 읽기”를 눌러요 → 읽기 화면이 열리고 진행 위치가 저장돼요. | 화면 상태·저장 레코드·동기화 상태·ms | 읽은 위치와 기록을 이어서 남겨요. |
| 3 | Chat 사용 안내에서 게스트 저장 문구 확인 → 기기에 저장된다는 안내와 로그인 후 다른 기기에서 잇는 문구 표시 | 안내 표시·ms | 로그인하면 다른 기기에서도 이어서 볼 수 있어요. |
| 4 | 같은 계정 세션으로 새 브라우저 프로필(다른 기기)에서 다시 열기 → 계정에서 내려받은 진행 위치로 “정확한 위치에서 이어 읽기” 표시 | 두 기기 화면·응답 ms·동기화 상태 | 다른 기기에서 읽던 내용을 이어 봐요. |

게스트 첫 화면은 GET으로 확인합니다. 계정 동기화는 세션 파일이 없거나 북AI 세션이 없으면 test_account_missing으로 건너뜁니다. 두 번째 기기는 같은 storage-state로 만든 빈 프로필이며, 계정 동기화가 synced가 되지 않으면 실패로 기록합니다.
