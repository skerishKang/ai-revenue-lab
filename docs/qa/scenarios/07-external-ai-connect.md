# ⑦ 외부 AI 연결

**목적:** ChatGPT·Claude 같은 외부 AI 앱의 커넥터에 이 채팅의 MCP 주소를 넣고 로그인·승인해 PC 작업을 맡기는 흐름을 확인합니다.  
**사전 조건:** 로그인 세션과 등록·온라인 상태의 PC가 필요합니다. 호스트 배포 전에는 실제 연결을 실행하지 않습니다.  
**튜토리얼 공개 범위:** 로그인 1–4

| 단계 | 사용자 동작 → 기대 화면·응답 | 확인 지표 | 튜토리얼 캡션 |
|---|---|---|---|
| 1 | 외부 AI 앱의 커넥터 메뉴에 연결 주소를 넣고 연결 시작 → 이 채팅 로그인 화면으로 이동 | 이동 주소·ms | 쓰던 AI 앱에 이 채팅의 연결 주소를 넣어요. |
| 2 | 로그인 뒤 "외부 AI 연결 승인" 화면 → 요청한 AI 이름·돌아갈 곳·허용 범위·연결할 PC 표시 | 화면 문구·ms | 로그인하면 승인 화면에서 범위와 PC를 확인해요. |
| 3 | 연결할 PC를 고르고 "승인하고 연결" → AI 앱으로 돌아가 도구 목록 표시 | 도구 목록·ms | 승인하면 그 AI가 고른 PC에서 작업할 수 있어요. |
| 4 | 설정의 외부 AI 연결에서 발급한 연결 확인 → 폐기 버튼이 보임(누르지 않음) | 목록·폐기 버튼 존재 | 설정에서 언제든 연결을 폐기할 수 있어요. |

실제 연결은 호스트 배포 뒤 시험 계정으로 한 번만 확인합니다. 그 전까지 이 대본은 로그인 단계만 다루고, 파일·명령·브라우저 도구를 실행하지 않습니다.
