# B66 — PADIEM CLAW 기반 견적 전문 AI 통합 (2026-10-15)

**상태:** Owner 제품 방향 확정 · 단일 구현 추적 [#4803](https://github.com/skerishKang/ai-revenue-lab/issues/4803) · 운영 수용은 기존 [#4316](https://github.com/skerishKang/ai-revenue-lab/issues/4316)에만 기록.

## 제품 정의
B66은 **PADIEM CLAW의 업무 실행 경험을 견적서 작성에 특화한 제품**이다. Chat과 Claw의 대화 경험을 재사용하며, 사용자 지시를 실제 견적 초안·수정·검증된 PDF 파일까지 완수한다. B66 별도 범용 AI 엔진/별도 파일 권한 시스템을 만들지 않는다.

## 공통 실행과 B66의 경계
- 공통: PADIEM 단일 인증, 허용된 사용자 등급/선택 모델·B14 라우팅, 서버 검증 대화/실행 상태, 정직한 오류, 파일 결과·후속 대화 UI 패턴. Claw/P01 코드는 적절한 실행 권한이 검증될 때만 재사용하고, 타 제품 tenant/PC/Drive 권한을 자동 확장하지 않는다.
- B66 전용: 고객 회사정보, QuoteDraft, QuoteCore 공급가액·세액·합계, 승인 Saved Quote Skill, **기존 인증된 CGI Sol PDF** 및 이력·저장. 모델은 내용 이해·필드 추출을 수행하나 총액·견적 발급·서버 WRITE 권한을 획득하지 않는다.
- 템플릿 분석/인증은 최초 1회, 반복 견적 렌더는 결정적으로 처리. CGI Sol 이외 임의 CLAW PDF/HTML 렌더러로 대체하지 않는다.
- 사용자 입력 → 서버 모델의 일반/견적 의도 판단 → 다중 턴 부족 정보 확인 → 사용자 확인된 견적 필드 → QuoteCore → 승인 렌더러/실제 PDF → 같은 대화 내 수정.

## 최신 소스 기준 사실과 접합
1. **이미 구현:** #4466/#4412 PR #4658, `apps/padiem-chat/app/b66_ai_conversation_routes.py` GET/POST, 서버 소유 state/intent/다중 턴/승인 후 `draft` projection. **모델의 일반 자유문장 출력은 구조화 대화 계약을 따름.**
2. **미연결이던 곳:** 기존 Pages `_worker.js`가 이 경로를 프록시하지 않고 `padiem-account.js`·`easy-mode.js`가 사용하지 않음. 일반 채팅 `/api/b66/ai/chat`은 견적을 발급하지 않는다.
3. **첫 구현 (#4803):** 승인된 이 서버 대화 경로만 Pages에서 연결하고, 기존 B66 단일 입력창에서 일반 대화→견적 의도→반영 action을 처리한다. 초안은 기존 `App.replaceDraft`가 QuoteCore로 정규화한 뒤 오른쪽 미리보기를 갱신한다. PDF는 기존 `printPdf` 버튼의 검증/인증 렌더 경로만 실행하며, 성공 전 파일 생성 완료 표시를 하지 않는다.
4. **운영 배포 전 필수 확인:** `041_b66_ai_conversation.sql`의 실제 Production D1 적용, B14 해당 라우트 Runtime/모델 가용성, 연결된 UI, 동일 owner/tenant의 회귀와 실제 PDF 파일. 미확인은 `NOT_PROVEN`으로 표시. 코드 병합/CI ≠ 실서비스 완료.

## 사용자 흐름 수용
- 첫 홈 입력에서 같은 채팅창으로 전환, 일반 대화→견적 의도는 서버 AI 판단으로 전환; 키워드/브라우저 독단 판정 금지.
- ‘광주대학교 방송장비 1개 100만원’ → 실제 사용자 제공값만 반영. 빈 단가나 부가세는 추측하지 않고 질문/검토 표시.
- ‘견적 초안에 반영’ 클릭 후 기존 회사·양식/견적 상태 검증. 이미 작업 중인 다른 견적은 무단 덮어쓰지 않음.
- ‘PDF 생성·다운로드’는 기존 인증 PDF 생성 액션을 호출; 실제 파일을 받아야 성공. 후속 수정/재생성은 동일 견적 문맥을 유지하는 방향.
- 원본, 숫자, 사용자 권한, 승인되지 않은 4+품목 CGI 출력 경계 유지. 인증되지 않은 PDF를 대체 생성하지 않음.
- 별도 브라우저 QA·실사용 합격은 #4316, CLAW 고유 작업 검증은 #3936에서 각각 판정.

## 범위 제외
음성 입력, 신규 PDF 생성 엔진, 모델·fallback 재정책, 다른 회사 템플릿 자동 인증, PC·Drive 권한 자동 공유, 별도 로그인 및 거대한 테스트 프레임워크는 이번 첫 연결 범위가 아니다.

## 2026-10-15 개발 2차 — 후속 수정과 PDF 파일 결과
- 대화에서 확정한 견적 번호 및 실제 현재 Draft 스냅샷을 기억해, 후속 `quote_modify → confirm → approve_draft`가 **동일한 견적번호/발행일/회사 데이터**를 갱신한다. 다른 화면에서 스냅샷이 변경되었다면 무단 덮어쓰지 않고 명확한 충돌 메시지를 표시한다.
- 기존 B66 인증 렌더러가 발급한 실제 PDF Blob을 기존 다운로드 동작과 동일하게 사용한다. 모델 텍스트/가짜 PDF 카드 생성 금지; 실제 MIME/매직바이트와 서버/계정/템플릿 검증이 통과한 뒤에만 대화창 다운로드 링크를 제공한다.
- 다운로드 링크는 현재 인증된 화면에서만 유효한 `blob:` URL. 새 견적 시작이나 계정 변경 시 URL을 폐기하며 원본 파일을 공개 저장소에 업로드하지 않는다.
- CGI 4개 이상 품목·부가세 미확정·인증 템플릿 미준비 상황은 기존 PDF 출력 경로의 정직한 오류를 그대로 유지. 고객 계정의 실제 운영 마이그레이션·PDF E2E는 별도 수용 대상.
