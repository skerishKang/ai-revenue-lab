# B66 CGI template A/B decision - 2026-10-09

Decision: **Sol 6.1 is the preferred fixed CGI template candidate**, pending independent code/bundle review. GLM 5.3 is kept in the private vault as a benchmark and rollback source, not an authorized customer PDF renderer.

## Same-input evidence (not model opinion)

| Criterion | Sol 6.1 | GLM 5.3 Flash |
| --- | --- | --- |
| Builder attribution | Codex gpt-6.1-sol, verified session | GLM 5.3 workdir report |
| Raw source reproduction at 150dpi | 0 changed pixels | 0 changed pixels |
| Baseline PDF byte identical to source | No; reconstituted from certified source assets | Yes; source PDF byte copy |
| Pre-existing certification report | 15 mutation cases, outside-slot difference 0 | 12 mutation cases, outside-slot difference 0 |
| A/B single item | A4 1 page, correct values | A4 1 page, correct values |
| A/B two items | A4 1 page, correct values | A4 1 page, correct values |
| A/B three items | A4 1 page, correct values | A4 1 page, correct values |
| Prior quote amount present as extractable PDF text after mutation | NO (0 of 3) | YES (3 of 3) |
| Prior recipient/project present as extractable PDF text after mutation | NO (0 of 3) | YES (3 of 3) |
| Production integration verified | NO | NO |

Both produced correct calculated totals in the three controlled cases, including the same synthetic input data in each renderer. Both visually retained logo/stamp, geometry and source layout. GLM's existing approach overlays replacements on original PDF content, leaving historical text from the original quotation extractable by PDF parsers (old recipient/project and amounts). This is a concrete **confidentiality and downstream-data-correctness problem**, even when visually covered.

Sol rebuilds the certified source layout from extracted assets. In all three measured new PDF files, legacy source amount/project text was not found in extracted text. This is the decisive reason for preferring Sol. A later rewrite of GLM could remedy this; no blanket statement about GLM model capability is implied.

Scope caveats: These tests do not certify arbitrary fonts, 4+ rows, layout at arbitrary recipient name lengths, general XLSX conversion or B66 account integration. Certified one-page CGI profile and deterministic renderer are the only intended reuse.

## Safe next steps

2. Provision the approved immutable bundle to an access-controlled object store such as private R2 after owner approval and verify fingerprint at every render.
3. Connect the existing authenticated B66 Saved Quote Skill + QuoteCore to this fixed renderer, without an AI call in the rendering phase. Reject excess rows.
4. Verify logged-in B66 HTML preview totals vs downloaded PDF contents on changed client and line-items; check stamp/logo, invisible legacy text, clipping and independent E2E.
5. Require separate approval for Ready/merge, bundle publication and Production route activation. This PR is metadata-only.
