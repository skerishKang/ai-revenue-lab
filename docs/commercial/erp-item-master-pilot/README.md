## 공개 문서와 비공개 자료의 경계

이 폴더에는 **기술 정보만** 있다. 들어가지 않는 것은 다음과 같다.

| 항목 | 이유 | 위치 |
|---|---|---|
| 고객·담당자 식별 정보 | 개인정보 | 비공개 사업방침 |
| 해당 조직의 실제 품목 물량·사업 규모 | 고객 사업 정보 | 비공개 사업방침 |
| 실제 품목목록·가격표·거래처 자료 | 고객 자료 | 비공개 사업방침 |
| 영업·비용·수익 모델 | 사업방침 | 비공개 사업방침 |
| 가격 정의(부가세 포함 여부 등) | 고객의 가격 기준 | 비공개 사업방침 |

이 폴더의 샘플 10건은 전부 이 실증을 위해 만든 **합성 데이터**이며, 그 값은 어떤
실제 거래 자료와도 관계없다.

## 이번 실증에서 확인한 사실

- 이카운트에 **품목등록 입력 API**와 **품목 조회 API**가 존재한다. API 사용에 추가 비용은 없다.
- 이카운트의 엑셀 자료올리기는 품목정보를 한 번에 올리고, 실패 사유를 즉시 보여 주며,
  이미 등록된 자료도 같은 방식으로 갱신할 수 있다. ERP 자료를 엑셀로 내려받는 기능도 있다.
- 이카운트의 **품목등록 요청 필드 이름과 엑셀 품목 시트의 열 구성은 공개 자료로 확정되지 않았다.**
  공개 매뉴얼 URL은 로그인하지 않은 요청에 HTTP 410을 반환한다.
- 공급처 목록을 정규화해 ERP 임포트 파일로 만드는 흐름은 실제로 동작한다.
  익명 샘플 10건 중 3건이 자동 확정, 7건이 사람 확인으로 나뉘었다.
- 합성 20,000행은 16.3초, 30,000행은 39.7초였다. 가장 느린 단계는 Excel 기록이다.
- **실제 서식 파일이 도착하면 그 파일에서 열 이름을 읽어 프로파일을 확정할 수 있다.**
  서식 바인딩 도구가 구현되어 있고, 서식이 없으면 아무것도 확정하지 않는다.
- B71 작업계약으로 ERP 품목 정리를 위임하는 어댑터가 `apps/business-71-ai-operations/`
  에 있다. 정규화·중복·파일 기록은 전부 `apps/erp-item-master/` 구현을 재사용한다.

## 이번 실증에서 확인하지 못한 것

- 적용 대상 ERP가 이카운트인지 여부.
- 이카운트 공식 임포트 양식의 실제 열 이름과 필수 여부.
- 실데이터로 얻은 처리시간과 오류율.
- 실제 이카운트 계정에서의 업로드 성공 여부.
