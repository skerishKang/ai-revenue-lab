## 1. 조사 방법과 원칙

이카운트 공식 도메인(`www.ecount.com`)의 페이지를 직접 읽고, 확인된 사실과
확인되지 않은 것을 나눴다. 공식 자료에서 확인할 수 없는 필드 이름은
**임의로 확정하지 않았다.** 제3자가 이카운트가 제공한 예시 파일을 보고 적은
필드 이름은 "제3자 미검증"으로만 표시하고, 업로드 가능한 파일로 내보내지 않았다.

읽은 공식 페이지:

| URL | 읽은 내용 |
|---|---|
| https://www.ecount.com/kr/ecount/product/erp_open-api | 오픈 API 개요, 연동 가능 메뉴 표, API 테스트 기능, 세부 매뉴얼 로그인 필요 안내 |
| https://www.ecount.com/kr/ecount/product/erp_migration | 엑셀 자료올리기 기능, 실패 사유 즉시 확인, 기존 자료 엑셀 갱신, ERP 자료 엑셀 다운로드 |
| https://www.ecount.com/kr/ecount/product/inventory_item-management | 품목관리 기능, 품목 등록 항목(규격·단위·속성·수량·단가·원가·분류·제조사·모델·색상), ERP 자료 엑셀 다운로드 |

추가로 확인한 URL:

| URL | 결과 |
|---|---|
| `https://sboapi.ecount.com/ECERP/OAPI/OAPIView?lan_type=ko-KR` | `{"Data":"/","Status":"410", ...}` — 로그인 없이 요청하면 410으로 막힌다. 상세 매뉴얼이 공개되지 않음을 확인 |

## 2. 공식 페이지에서 확인된 기능

아래 표의 모든 항목은 위의 이카운트 공식 페이지에 그대로 적혀 있다.

### 2.1 품목등록·수정 (엑셀)

| 항목 | 확인 내용 |
|---|---|
| 대량 등록 | 엑셀 업로드로 **품목정보, 거래처정보, 판매/회계전표 등 다량의 자료를 한 번에** 올릴 수 있다 |
| 오류 확인 | 데이터 업로드에 실패한 자료는 **사유를 즉시 확인할 수 있다** |
| 기존 자료 수정 | ERP에 이미 등록된 자료를 수정하거나 정보를 추가할 때에도 **엑셀로 업데이트할 수 있다** |
| 자료 내보내기 | ERP 입력 자료를 엑셀로 내려받을 수 있다. 보고서·출력물도 엑셀로 변환할 수 있고, 기간을 지정해 백업할 수 있다 |
| 권한 | 엑셀 다운로드 권한을 사용자별로 지정해 정보 유출을 방지할 수 있다 |

### 2.2 품목등록·조회 (Open API)

공식 페이지의 "연동 가능한 메뉴" 표에 적힌 그대로다.

| 구분 | 제공 API | 입력/조회 |
|---|---|---|
| 거래처/품목 | 거래처등록 | 입력 |
| 거래처/품목 | **품목등록** | **입력** |
| 거래처/품목 | **품목** | **조회** |
| 영업 | 견적서 / 주문서 | 입력 |
| 판매 | 판매 | 입력 |
| 구매 | 발주서 / 구매 | 조회 / 입력 |
| 생산 | 작업지시서 / 생산불출 / 생산입고 | 입력 |
| 회계 | 매출/매입 | 입력 |
| 근태 | 출/퇴근 | 입력 |
| 쇼핑몰 | 주문서 | 입력 |
| 출력물 | 재고현황 / 창고별재고현황 | 조회 |
| 게시판 | 게시글 | 입력 |

확인된 accompanying 사실:

- 오픈 API는 타 시스템과 이카운트를 연동하기 위해 정보를 공개하는 서비스이며,
  **API 사용에 추가 비용이 발생하지 않는다.**
- API 테스트 기능이 있어 사전에 연동을 검증할 수 있고, **이카운트 가입 후**
  API 테스트와 연동을 진행할 수 있다.
- **이카운트에 로그인해야 API 세부 매뉴얼을 확인할 수 있다.**
- 활용 예로 "이카운트의 재고 현황, 품목 리스트 정보를 자사 웹사이트로 전송"이 적혀 있다.
  품목 목록 조회 API가 있다는 뜻이다.
- 연동 가능한 메뉴는 고객사 의견을 반영해 지속 추가된다.

### 2.3 품목 자체가 가질 수 있는 정보 (품목관리 페이지)

- 품목의 **규격, 단위, 속성** 등 다양한 정보를 등록하고 카테고리별로 그룹화한다.
- 품목 등록 시 **수량, 단가, 원가** 등 정보와 회사만의 품목관리 항목을 추가할 수 있다.
- **제조사, 모델, 색상** 등 하위그룹을 등록해 전표 입력·조회 시 그룹별로 검색한다.

이 항목들은 이번 실제의 정규화 필드(상품명·모델명·제조사·공급사·품목코드·규격·단위·
분류·매입가·판매가)와 대부분 대응한다.

## 3. 공식 자료로 확정되지 않은 것

| 항목 | 상태 | 비고 |
|---|---|---|
| 품목등록 API의 요청 필드 이름 | **미확정** | 공식 매뉴얼이 로그인 뒤에만 제공된다. 공개 URL은 비로그인 요청에 410을 반환한다 |
| API 엔드포인트 경로·인증 방식·요청/응답 구조 | **미확정** | 같은 이유로 공개되지 않는다 |
| 1회 등록 건수 상한 | **미확정** | 공식 페이지에 명시가 없다 |
| API 호출 속도 제한 | **미확정** | 공식 페이지에 명시가 없다 |
| 엑셀 품목 시트의 열 이름과 순서 | **미확정** | 고객 계정의 기본 탭 설정에 따라 달라지는 것으로 보인다 |
| 엑셀 업로드 1회 행 수 상한 | **미확정** | 공개 자료에 없다 |
| 신규 등록과 기존 수정 방식의 구분 | **부분 확인** | "기존 자료도 엑셀로 갱신할 수 있다"는 사실만 공식 확인 |
| 품목코드·품목명 외 필수 항목 | **미확정** | 양식에서 확인해야 한다 |

## 4. 제3자 자료로만 확인되는 것 (미검증)

이카운트 공식 자료가 아니라 **제3자博客가 이카운트가 제공한 예시 파일을 보고 적은
내용**이다. 구현에 참고용으로만 사용했고, 전부 `THIRD_PARTY_UNVERIFIED`로 표시했으며
업로드 가능한 파일로 내보내지 않았다.

| 항목 | 제3자 보고 내용 | 상태 |
|---|---|---|
| 품목등록 요청 본문 | `{"ProductList": [{"Line": ..., "BulkDatas": {...}}]}` 형태 | 미검증 |
| 필드 `PROD_CD` | 품목코드, 약 20자 | 미검증 |
| 필드 `PROD_DES` | 품목명 | 미검증 |
| 필드 `SIZE_DES` / `SIZE_FLAG` | 규격 / 규격 필수 플래그(`1` = 필수규격) | 미검증 |
| 필드 `UNIT` | 단위 | 미검증 |
| 필드 `IN_PRICE` / `OUT_PRICE` | 입고단가 / 출고단가 | 미검증 |
| 필드 `CUST` | 구매처 **코드** | 미검증 |
| 필드 `CLASS_CD` | 품목분류 **코드** | 미검증 |
| 필드 `BAR_CODE` | 바코드 | 미검증 |
| 필드 `REMARKS` | 비고 | 미검증 |
| 1회 등록 건수 | 300건 | 미검증 |
| 호출 제한 | 10초당 1회 | 미검증 |

이 정보는 `apps/erp-item-master/app/erp_profile.py`의 `ecount_api_candidate`
프로파일에 반영되어 있고, 근거 상태는 `erp_field_mapping_status.csv`에 행 단위로 남는다.

### 대응 필드를 찾지 못한 정규화 필드

| 정규화 필드 | 상태 | 이유 |
|---|---|---|
| 제조사 | `NOT_FOUND` | 예시 파일에 대응 필드가 확인되지 않았다 |
| 모델명 | `NOT_FOUND` | 예시 파일에 대응 필드가 확인되지 않았다 |
| 공급사 | `NOT_FOUND` | `CUST`는 **공급사 이름이 아니라 등록된 구매처 코드**를 요구한다. 이름 값을 그대로 옮길 수 없다 |
| 상품분류 | `NOT_FOUND` | `CLASS_CD`는 분류 **코드**를 요구한다. 이름 값을 그대로 옮길 수 없다 |

## 5. 이 조사가 만든 구현 결정

1. **범용 구조와 ERP 프로파일을 분리한다.** ERP 제품명이 확정되지 않았으므로
   정규화 레코드는 ERP 무관하게 유지하고, ERP별 임포트 열 구성만 교체 가능하게 했다.
2. **근거 상태를 열 단위로 기록한다.** 임포트 파일 하나에 어떤 열이 공식 확인됐는지,
   제3자 보고인지, 아직 고객 양식 대기인지가 함께 남는다.
3. **확정되지 않은 프로파일은 업로드 가능한 파일로 내보내지 않는다.**
   이카운트 프로파일의 파일 이름에는 `CANDIDATE`가 붙고, `upload_ready=False`다.
4. **공식 양식을 확인하지 못한 필드는 비워 둔다.** 제조사·모델명은 이카운트 이관
   파일에 실리지 않으며, 그 사실을 `erp_field_mapping_status.csv`가 밝힌다.
