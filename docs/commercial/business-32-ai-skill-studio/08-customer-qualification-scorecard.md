# 08 — Customer Qualification Scorecard

고객 우선순위를 평가하는 점수표입니다. 실제 고객 접촉 전 내부용입니다.

## 높은 우선순위 (우대)

```text
반복 업무가 주 1회 이상
현재 AI를 개인별로 사용
업무 품질이 사람마다 다름
검토·승인자가 존재
업무 하나를 파일럿으로 제한 가능
팀 책임자가 참여 가능
```

## 낮은 우선순위 (비적합)

```text
전사 자동화를 즉시 요구
사람 검토를 없애려 함
실제 개인정보 원문 입력을 요구
성과 보장을 요구
업무 범위를 한정하지 않음
담당 owner가 없음
```

## 점수 평가 예시 (합성)

| 기준 | 가중치 | 평가 방법 |
| --- | --- | --- |
| 반복 빈도 | 높음 | 주 1회 이상 여부 |
| AI 개인 사용 | 중간 | 개인별 AI 사용 여부 |
| 품질 편차 | 중간 | 사람마다 산출물 품질 차이 |
| 검토·승인자 | 높음 | 검토자가 존재하는지 |
| 파일럿 제한 가능 | 높음 | 업무 1개로 제한 동의 여부 |
| 팀 책임자 참여 | 높음 | 책임자 참여 가능 여부 |

- 비적합 기준 하나라도 해당 시 우선순위 하향 또는 보류.
- 모든 평가는 합성 기준이며 실제 고객 데이터는 사용하지 않습니다.

## 사용 규칙

```text
실제 고객 접촉·제안서 발송 금지 (이번 작업에서)
평가는 내부 검토용
```
