# 10 — Risk, Data, and Authority Boundary

## 금지 표현

```text
AI가 정확성을 보장
검증 완료이므로 오류 없음
직원을 대체
사람 검토 불필요
법적으로 안전
개인정보 문제 없음
모든 업무에 적용
즉시 자동화
```

## 허용 표현

```text
정해진 범위에서 반복 가능한 절차
사람 검토와 승인 포함
증거·예외·금지 기준 표시
고객별 정책·법률 검토 필요
파일럿 결과에 따라 확대 여부 결정
```

## 데이터 경계

```text
모든 예시·사례·스크립트는 합성
실제 고객, 실제 견적서, 실제 내부 문서 사용 금지
개인정보 원문 수집 금지
업무명·단계·소요시간·검토 구조만 확인 가능
```

## 권한 경계

```text
AI는 승인할 수 없음
누락 증거를 자동 추정하지 않음
최저가를 자동 최선으로 판정하지 않음
사람 승인 전 스킬 저장 금지
실제 구매 추천이라고 주장하지 않음
```

```text
SERVICE-LED FRONTEND PILOT
```

없는 기능을 제공한다고 판매하지 않습니다.
