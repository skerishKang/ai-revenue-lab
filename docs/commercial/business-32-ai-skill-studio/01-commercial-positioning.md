# 01 — Commercial Positioning

## 판매 문장 (고정)

```text
조직의 실제 반복 업무 하나를
입력자료·단계·증거·검토·예외·승인 기준이 포함된
재사용 가능한 AI 업무 스킬로 전환합니다.
```

Primary commercial result:

```text
VERIFIED ORGANIZATIONAL AI SKILL PACKAGE
검증된 조직 AI 업무 스킬 패키지
```

## 표현 금지 제품군

다음으로 제품을 표현하지 않습니다.

```text
일반 AI 교육
프롬프트 판매
챗봇
LMS
RPA
자율 에이전트
직원 감시
성과평가 시스템
AI가 자동 승인하는 시스템
```

## 가치 제안

- 반복 업무 1개를, 입력자료·단계·증거·검토·예외·승인 기준이 포함된 스킬로
  전환합니다.
- 스킬은 사람 검토와 승인을 포함하며 재사용 가능한 조직 자산이 됩니다.
- 분기별 검토·버전 갱신으로 업무·정책 변화를 반영합니다.


## 첫 파일럿 업무 후보 (합성 예시)

```text
행사 홍보물 초안
교육 프로그램 안내문
뉴스레터 제작
SNS 콘텐츠 변환
회의자료 요약
지원사업 공고 검토
공급업체 견적 비교
검토 체크리스트 작성
```

모든 예시는 합성입니다. 실제 고객, 실제 견적서, 실제 내부 문서를 사용하지
않습니다.

## 판매 단위

서비스가 판매하는 것은 "스킬 전환 과정과 검증된 스킬 패키지"입니다. AI
정확성 보장이나 자동화 결과 판매가 아닙니다.
