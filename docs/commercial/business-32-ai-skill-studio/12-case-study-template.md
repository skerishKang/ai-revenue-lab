# 12 — Case Study Template (합성)

실제 고객 사례가 아니라 **합성 사례 템플릿**입니다. 실제 고객·조직 이름을
사용하지 않습니다. 파일럿 결과를 확보한 뒤 승인된 단계에서만 사용합니다.

## 템플릿

```text
조직 (합성):
팀 (합성):
선택 업무 (합성):
업무 목적:
반복 빈도 (가상):
전환 전 문제 (가상):
전환 후 결과 (가상):
검토·승인 구조:
예외·금지 기준:
스킬 버전:
다음 검토일:
확대 가능성 (가상):
```

## 합성 예시

```text
조직 (합성): 지역 문화기관 (가상명 A)
팀 (합성): 홍보팀
선택 업무 (합성): 행사 홍보물 초안 작성
업무 목적: 행사 안내문 초안을 검토자 승인 후 배포
반복 빈도 (가상): 주 2회
전환 전 문제 (가상): 담당자별 문구 품질 차이
전환 후 결과 (가상): 초안 기준 통일, 검토 절차 고정
검토·승인 구조: 팀장 검토 → 승인
예외·금지 기준: 실데이터·실제 인물 사진 사용 금지
스킬 버전: 1.0
다음 검토일: 2026-11-01 (합성)
확대 가능성 (가상): 뉴스레터, SNS 콘텐츠로 확장 후보
```

## 사용 규칙

```text
사례는 합성이며 실제 고객 사례로 주장하지 않음
실제 고객 접촉·제안서 발송 금지
파일럿 결과 확보 전에는 사례 발표 금지
```
