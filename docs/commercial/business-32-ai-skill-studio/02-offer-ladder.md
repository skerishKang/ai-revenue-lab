# 02 — Offer Ladder

가격은 모두 **시장 검증 전 가설**입니다. 확정 가격이 아닙니다.

## Offer A — AI 업무 스킬 설계 워크숍

```text
기간:   1~2일
범위:   업무 1개
가격 가설: 300만~500만원
```

산출물:

```text
업무 범위
필요 입력자료
실행 단계
AI 보조 단계
사람 판단 단계
검토 기준
금지 업무
예외 목록
스킬 초안
```

## Offer B — AI 업무 스킬 전환 스프린트

```text
기간:   2~3주
범위:   업무 1개
가격 가설: 500만~800만원
```

산출물:

```text
업무 분석
합성 실행
증거 요구사항
누락·충돌 처리
실행자·검토자 역할
수정·재실행
최종 승인 기준
검증된 스킬 카드
운영 가이드
```

## Offer C — 팀 AI 스킬 라이브러리 파일럿

```text
기간:   4~6주
범위:   업무 3개 · 팀 1개
가격 가설: 1,200만~2,000만원
```

산출물:

```text
검증된 스킬 3개
역할·승인 기준
버전 관리 기준
금지 사용 기준
분기 검토 일정
팀 운영 플레이북
```

## Recurring review

```text
분기별 스킬 검토
업무 또는 정책 변화 반영
예외·금지 기준 갱신
다음 review date 설정
```

## 래더 원칙

- Offer A → B → C 순으로 고객이 커밋을 늘리는 경로입니다.
- 각 offer는 이전 offer의 산출물을 포함합니다.
- 구독 가격은 이번 작업에서 확정하지 않으며, 가설 범위와 산정 기준만
  `07-pricing-hypotheses.md`에 기록합니다.
