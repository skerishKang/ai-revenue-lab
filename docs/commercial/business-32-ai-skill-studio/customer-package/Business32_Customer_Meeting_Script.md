# Business32_Customer_Meeting_Script — 30분 상담 대본

첫 상담에서는 고객의 실제 비공개 파일을 요구하지 않습니다. 업무명·단계·소요시간·
검토 구조만 확인합니다.

## 5분 — 조직과 팀 확인

- 질문: "어떤 팀이, 어떤 업무를 반복적으로 수행하나요?"
- 확인: 팀 역할, 업무 담당자, 검토·승인자 존재
- 주의: 내부 문서 요구 금지

## 10분 — 반복 업무 1개 흐름 파악

- 질문: "가장 반복적이고 품질이 사람마다 다른 업무 하나를 소개해 주세요."
- 확인: 업무명, 실행 단계, 소요 시간, 검토 구조
- 주의: 실데이터·실제 파일 요구 금지

## 5분 — AI 사용과 위험 확인

- 질문: "현재 AI를 개인적으로 사용하나요? 어떤 위험을 우려하나요?"
- 확인: 개인별 AI 사용, 개인정보·법률 우려
- 주의: "법적으로 안전하다"고 말하지 않기

## 5분 — Offer A/B/C 설명

- 제안: Offer A(워크숍) → B(스프린트) → C(팀 파일럿)
- 강조: 사람 검토와 승인 포함, 합성 데이터 사용, 파일럿 후 확대 결정
- 주의: 가격은 가설로만 언급

## 5분 — 다음 단계와 담당자 확인

- 질문: "이 업무의 owner와 검토자는 누구인가요?"
- 다음 단계: 파일럿 후보 업무 1개, 담당자, 다음 미팅 일정
- 주의: 실제 고객 접촉·제안서 발송은 이번 단계에서 하지 않음

## 대화 금지 표현

```text
AI가 정확성을 보장 · 검증 완료이므로 오류 없음 · 직원을 대체
사람 검토 불필요 · 법적으로 안전 · 개인정보 문제 없음
모든 업무에 적용 · 즉시 자동화
```

## 허용 표현

```text
정해진 범위에서 반복 가능한 절차
사람 검토와 승인 포함
증거·예외·금지 기준 표시
고객별 정책·법률 검토 필요
파일럿 결과에 따라 확대 여부 결정
```
