# Business32_Followup_Email_Templates

후속 이메일 템플릿입니다. 모든 내용은 합성이며, 발송 전 `CUSTOMIZATION_CHECKLIST`
충족과 실제 고객 접촉 승인이 필요합니다.

## 1. 상담 후 다음 단계

```text
제목: 반복업무 하나를 AI 업무 스킬로 — 다음 단계

안녕하세요.
지난 상담에서 말씀드린 대로, 반복 업무 1개를 검증된 AI 업무 스킬로 전환하는
프로그램을 안내드립니다.

[고객·팀 정보 확인]
- 담당 업무: [업무명]
- 검토·승인자: [역할]

다음 단계는 'Skill Discovery Worksheet'로 업무 1개를 선정하는 것입니다.
첫 상담에서는 실제 파일이나 내부 문서가 필요하지 않습니다.

가격은 현재 가설 단계이며, 상세는 제안서를 참고하실 수 있습니다.
```

## 2. 워크시트 회신 안내

```text
제목: Skill Discovery Worksheet 작성 안내

작성한 워크시트를 회신해 주시면, 후보 업무 1개에 대해 스킬 전환 스프린트(Offer B)
가능 여부를 검토하겠습니다.

작성 시 개인정보나 실제 견적서·내부 문서는 넣지 않으셔도 됩니다.
업무명·단계·소요시간·검토 구조만 확인합니다.
```

## 3. 제안서 전달

```text
제목: Business 32 제안서 — 검증된 조직 AI 업무 스킬 패키지

첨부한 제안서를 확인해 주십시오.
- 제안 요약(10초 원페이지)
- 10페이지 마스터 제안서
- 검증된 스킬 카드 샘플(합성)

제안서의 모든 사례는 합성이며, 가격은 가설입니다. 사람 검토와 승인을 포함한
절차로 전환하는 서비스입니다.
```

## 4. 파일럿 확정 전

```text
제목: 파일럿 확정 전 확인 사항

다음을 확인해 주시면 파일럿을 준비하겠습니다.
- 후보 업무 1개 확정
- 실행자·검토자 지정
- 허용·금지 사용 합의
- 입력자료 목록

실제 고객 접촉·발송은 별도 승인 단계에서 진행됩니다.
```

## 공통 금지

```text
가격 확정 표현
정확성 보장 · 오류 없음 · 직원 대체 · 사람 검토 불필요 · 법적 안전 보장
실제 사례로 가장한 합성 사례
```
