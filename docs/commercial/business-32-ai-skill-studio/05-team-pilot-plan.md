# 05 — Team Pilot Plan

Offer C의 실행 계획입니다. 팀 1개에서 업무 3개를 검증된 스킬로 전환하는
4~6주 파일럿입니다.

## 대상

```text
업무 3개
팀 1개
```

## 파일럿 흐름

```text
1. 업무 3개 후보 선정 (반복·검토 구조 존재)
2. 업무별 스킬 전환 스프린트 (Offer B 방식)
3. 역할·승인 기준 확정
4. 버전 관리 기준 확정
5. 금지 사용 기준 확정
6. 분기 검토 일정 수립
7. 팀 운영 플레이북 작성
```

## 산출물 (Offer C)

```text
검증된 스킬 3개
역할·승인 기준
버전 관리 기준
금지 사용 기준
분기 검토 일정
팀 운영 플레이북
```

## 운영 원칙

```text
스킬은 사람 검토·승인 포함
예외·금지 기준은 카드에 유지
업무·정책 변화 시 분기 검토로 갱신
실제 고객 데이터 대신 합성 데이터
backend·자동화 구현 없음
```

## 파일럿 승인

파일럿 시작 전 `11-pilot-acceptance-checklist.md`를 충족해야 하며, 실제 고객·
조직은 승인 전에 삽입하지 않습니다.
