# 11 — Pilot Acceptance Checklist

파일럿 시작 전 확인 항목입니다. 실제 고객 또는 조직은 승인 전에 삽입하지
않습니다.

## 체크리스트

- [ ] 업무 1개 제한 — 파일럿 업무 범위 확정
- [ ] 실행자·검토자 지정 — operator/reviewer 역할 소유자
- [ ] 허용·금지 업무 합의 — allowed/prohibited use 확정
- [ ] 입력자료 목록 — 필수 입력과 확인 주체
- [ ] 증거 출처 정의 — SOURCE EVIDENCE 대상·합성 여부
- [ ] 누락·충돌 처리 — MISSING/CONFLICTING 처리 규칙
- [ ] 승인 책임 — HUMAN-APPROVED 담당 검토자
- [ ] 버전 owner — 스킬 버전 담당자
- [ ] 다음 검토일 — next review date 설정
- [ ] rollback — 이전 버전 복귀 절차
- [ ] 지원 연락 방식 — 문제 발생 시 채널

## 파일럿 경계

```text
합성 데이터만 사용
실제 구매·계약·조직 데이터 금지
브라우저 메모리만 사용 (서버 저장 금지)
실제 AI 모델 호출 금지
사람 검토·승인 필수
```

## 상태

```text
DO_NOT_SEND
```

이 체크리스트만으로 파일럿이 승인되는 것은 아니며, 실제 파일럿 승인은 별도
결정이 필요합니다.
