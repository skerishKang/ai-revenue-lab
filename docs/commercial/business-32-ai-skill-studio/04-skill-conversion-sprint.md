# 04 — Skill Conversion Sprint

Offer B의 실행 계획입니다. 업무 1개를 검증된 조직 스킬 패키지로 전환하는
2~3주 스프린트입니다. 모든 콘텐츠는 합성 데이터 기반입니다.

## 스프린트 단계

| 주차 | 단계 | 산출물 |
| --- | --- | --- |
| 1주차 | 업무 분석 | 업무 범위, 입력자료, 실행 단계, 검토 구조, 소요시간 |
| 1주차 | 합성 실행 | 검증된 frontend에서 합성 데이터로 전체 journey 실행 |
| 2주차 | 증거·예외 정의 | 증거 요구사항, 누락·충돌 처리 규칙 |
| 2주차 | 역할·승인 정의 | 실행자·검토자 역할, 최종 승인 기준 |
| 3주차 | 수정·재실행 | 사람 검토 후 수정 반영, 절차 재실행 |
| 3주차 | 검증·납품 | 검증된 스킬 카드 + 운영 가이드 |

## 실행 원칙

```text
실제 데이터 대신 합성 데이터 사용
사람 검토와 승인 포함
누락 증거를 자동 추정하지 않음
최저가·최선을 자동 판정하지 않음
승인 전 스킬 저장 금지
AI가 자동 승인하지 않음
```

## 산출물 (Offer B)

```text
업무 분석

검증된 스킬 카드
운영 가이드
```

## 파일럿 경계

스프린트는 서비스형 프론트엔드 파일럿이며 backend, 인증, 영구 저장, 실시간 AI
호출, 파일 업로드, 자동화를 포함하지 않습니다.
