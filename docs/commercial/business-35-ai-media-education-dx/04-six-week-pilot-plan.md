> **V3.1 product journey:** 현 미디어 업무 병목 이해 → 조직·결과물·병목·팀 규모·AI 사용 상태 입력 → 조직별 진단 + 새 업무 흐름 + 추천 파일럿 확인 → 운영체계 산출물 이해 → 진단 워크숍 또는 6주 파일럿 범위 판단 → 자기 조직용 전환 요약으로 상담 준비
> Week-by-week sequence below is **delivery detail**, not product identity. Product identity remains the V3.1 service-led interactive studio: `AI 교육을 듣는 데서 끝내지 않고, 팀의 실제 미디어 업무 한 흐름을 사람이 승인하는 운영체계로 바꾼다.`

Per-week fields: 목표 / 주요 활동 / 고객 참여자 / 제공자 활동 / 입력자료 / 산출물 / 검토 gate / 완료 기준 / 중단·위험 조건.

## Week 0 — 범위 합의 및 법률 검토 의뢰 (서명·결제 전)

```text
목표: 범위·가격·일정·위험 제외에 대한 합의 초안 확정 — 전문 법률/계약 검토 전 단계
주요 활동: SOW 초안(05) 합의 초안 작성 및 전문 법률/계약 검토 의뢰 준비, 파일럿 대상 업무 초안 확정, 위험업무 제외 목록 초안 확정, owner/customer-specific 최종 확정 필요 항목 식별
고객 참여자: 예산 승인자, 운영 책임자
제공자 활동: SOW 초안·부속서 초안 검토, 착수 준비 안내(법률 검토 완료 전 서명·결제 불가 고지)
입력자료: 진단 질문지(03) 기입 결과, 대상 업무 자료
산출물: SOW 초안 합의본(05) DRAFT, 위험·데이터 부속서 초안(06) DRAFT, 법률 검토 의뢰서 및 미해결 검토 항목 목록
검토 gate: 범위·가격 초안 합의 (고객), 법률 검토 라벨 유지 확인 (DRAFT · PROFESSIONAL LEGAL REVIEW REQUIRED) — 전문 법률 검토 완료 전 서명 불가
완료 기준: 초안 합의 및 법률 검토 의뢰/착수 확인 (서명·착수금 50% 수령·부속서 최종 확정은 전문 법률/계약 검토 + owner 승인 + 고객별 최종 확정 완료 후 별도 단계에서 수행)
중단·위험 조건: 예산 승인자 미확정, 위험업무 제외 초안 미합의 시 착수 보류; 법률 검토 없이 서명/결제 요구 시 진행 중단
```

## Week 1 — 기준선 진단

```text
목표: 현재 업무 흐름과 기준선 측정
주요 활동: 현황 인터뷰, 기준선 측정(생산시간·재작업률·검토 통과율), 위험업무 재확인
고객 참여자: 파일럿 팀 전원, 운영 책임자
제공자 활동: 인터뷰 진행, 기준선 측정표 작성
입력자료: 진단 질문지 답변, 실제 업무 프로세스 설명(원문 제출 불필요)
산출물: 기준선 진단 보고서, 기준선 KPI 표(07)
검토 gate: 기준선 확정 (운영 책임자)
완료 기준: 기준선 측정 완료·서명
중단·위험 조건: 기준선 데이터 전혀 미제공 시 계약 재검토
```

## Week 2 — 직무별 교육

```text
목표: 역할별 승인된 AI 도구·금지 업무 규칙 교육
주요 활동: 직무별 모듈(기획·제작·검토·운영) 교육, 승인 도구 목록·금지 규칙 설명
고객 참여자: 파일럿 팀 전원
제공자 활동: 교육 진행, 실습 준비
입력자료: 승인 도구 목록, 금지 업무 규칙
산출물: 교육 자료, 승인 도구·금지 업무 규칙 문서
검토 gate: 교육 이수 확인 (교육 완료 ≠ 역량 — 실습으로 확인)
완료 기준: 교육 이수 + 승인 도구 접근 확인
중단·위험 조건: 금지 업무에 AI를 쓰려는 시도 발견 시 중단·정정
```

## Week 3 — 실제 업무 실습

```text
목표: 실제 업무에 AI 적용 실습 (위험업무 제외)
주요 활동: 승인된 업무에 AI 실습, 사람 검토 gate 시뮬레이션
고객 참여자: 파일럿 팀 전원
제공자 활동: 실습 코칭, 오류·위험 관찰
입력자료: 실습용 업무 샘플 (개인정보·원문 미포함)
산출물: 실습 결과물, 실습 피드백
검토 gate: 실습 결과 사람 검토
완료 기준: 팀 실습 완료
중단·위험 조건: 개인정보 무단 입력, 무단 외부 공개 시 즉시 중단
```

## Week 4 — 워크플로 재설계

```text
목표: AI가 들어간 워크플로와 사람 검토 gate 확정
주요 활동: before/after 워크플로 설계, 검토 gate·예외 경로·거버넌스 확정
고객 참여자: 운영 책임자, 검토 담당자
제공자 활동: 워크플로 재설계안 작성
입력자료: Week 1–3 결과
산출물: 워크플로 재설계안 (before/after, gate 목록)
검토 gate: 재설계안 경영진 검토
완료 기준: 재설계안 승인
중단·위험 조건: 자동 게시 요구·사람 검토 삭제 요구 시 정정
```

## Week 5 — 제한 파일럿

```text
목표: 재설계된 워크플로로 제한된 실제 업무 실행
주요 활동: 승인 업무 1종에 재설계 워크플로 적용, 측정 수집
고객 참여자: 파일럿 팀, 검토 담당자
제공자 활동: 파일럿 운영 지원, 데이터 수집, 중간 리뷰
입력자료: 실제 업무 입력 (개인정보 제외)
산출물: 중간 성과·위험 보고
검토 gate: 주간 리뷰 (운영 책임자)
완료 기준: 파일럿 실행 완료
중단·위험 조건: 정책 위반 발생, 주간 참여율 50% 미만 지속 시 중단 검토
```

## Week 6 — 성과측정·플레이북 인도

```text
목표: 성과 측정, 위험 보고, 운영 플레이북 인도, 경영진 승인
주요 활동: KPI 비교, 성과·위험 보고, 운영 플레이북 작성, 경영진 발표
고객 참여자: 경영진, 운영 책임자
제공자 활동: 측정·보고·플레이북 인도
입력자료: Week 5 측정 데이터
산출물: 성과·위험 보고서, 운영 플레이북, KPI 결과표(07)
검토 gate: 경영진 승인, 플레이북 수용
완료 기준: 플레이북 승인 + 잔금 50% 수령
중단·위험 조건: 미해결 위험이 승인 불가 수준이면 플레이북 미승인 상태로 보고
```
