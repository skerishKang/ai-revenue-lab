## 한 줄 가치 제안

일반 AI 강의가 아니라, **실제 업무 진단·실습·워크플로 재설계·파일럿·측정·운영 플레이북까지 연결하는 기업·기관 맞춤형 AI 업무전환 서비스**.

## 고객의 현재 문제

```text
- 조직이 AI를 어디에, 어떻게 써야 하는지 판단하기 어렵다
- 개인별로 AI 도구를 쓰지만 정책·검토·프로세스가 없다
- 미디어·콘텐츠 생산 주기가 길고, 검토·승인이 수동이다
- 개인정보·저작권·투명성·사람 검토 등 거버넌스 요구가 강화되고 있다
- AI 강의만 듣고 돌아가면 실제 업무가 바뀌지 않는다
```

## Business 35의 7단계 방식

```text
현재 업무 진단
→ 직무별 교육
→ 실제 업무 실습
→ 업무 프로세스 재설계
→ 제한된 파일럿
→ 성과 측정
→ 조직 승인 운영 플레이북
```

## 상품 A/B/C

```text
A · 진단 워크숍      1–2일, 현황 인터뷰·적용 후보·위험업무 제외·직무 실습·경영진 보고
B · 디자인 파트너 파일럿  초기 도입 고객 대상 6주 파일럿 (가격 우대)
B · 표준 6주 유료 파일럿  1팀·1핵심업무, 기준선→교육→재설계→파일럿→측정→플레이북
C · 조직 운영 자문    월 단위, 승인 도구·금지 업무·프롬프트·워크플로·성과 리뷰·교육
```

## 주요 산출물

```text
현황 진단 보고서 / 기준선 측정표 / 직무별 교육 자료 / 워크플로 재설계안 /
사람 검토 gate / 성과·위험 보고서 / 조직 승인 운영 플레이북
```

## 가격 범위

```text
A 300만–800만원 (초기 제안 300만–500만원)
B 디자인 파트너 파일럿 1,000만–1,500만원
B 표준 6주 파일럿 1,500만–2,500만원
C 월 300만–600만원
```

```text
가격은 시장 검증 전 가설
실제 견적은 범위 확인 후 별도 승인
VAT 별도 여부는 최종 견적 시 명시
실제 계약·매출 발생 주장 아님
```

## 적합 고객

```text
지역 문화·교육·협회·미디어 기관 (담당자 접근 가능)
중견·중소기업 홍보·콘텐츠팀
공공기관 (조달 절차 확인 후)
대학 산학협력·평생교육 조직
```
