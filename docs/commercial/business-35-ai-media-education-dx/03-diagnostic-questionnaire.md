# Business 35 · AI Media Education & DX — 고객 진단 질문지

```
INTERNAL COMMERCIAL DRAFT
OWNER APPROVAL REQUIRED
NOT YET SENT TO A CUSTOMER
```

Respondents must be able to actually fill this in. Do **not** ask respondents to paste actual personal data or internal documents into the questionnaire.

Fields per question: 질문 / 답변 형식 / 필수·선택 / 확인 목적 / 민감정보 주의사항

---

## 1. 현재 콘텐츠 제작 흐름

```text
질문: 현재 홍보/콘텐츠 제작이 어떤 단계로 진행되나요? (기획→초안→검토→승인→게시 순으로)
답변 형식: 자유 텍스트 또는 단계 나열
필수/선택: 필수
확인 목적: 대상 업무와 현재 흐름 파악, 워크플로 재설계의 출발점
민감정보 주의사항: 특정 인물·기밀 콘텐츠 제목 등은 기재 금지
```

## 2. 업무별 소요시간

```text
질문: 콘텐츠 1건당 각 단계(기획·초안·검토·승인·게시)에 며칠/몇 시간이 걸리나요?
답변 형식: 단계별 시간 표 (예: 기획 1일, 초안 2일 ...)
필수/선택: 필수
확인 목적: 기준선 측정 (KPI "기준 생산시간")
민감정보 주의사항: 특정 업무자의 실명·개인 성과 노출 금지
```

## 3. 검토·승인 단계

```text
질문: 검토와 승인이 몇 단계이며, 누가 승인하나요?
답변 형식: 단계 목록 + 역할(직책만)
필수/선택: 필수
확인 목적: 사람 검토 gate 설계
민감정보 주의사항: 실명 대신 직책만 기재
```

## 4. 현재 사용하는 AI 도구

```text
질문: 조직원이 현재 사용하는 AI 도구는 무엇이며, 어떤 업무에 쓰나요?
답변 형식: 도구명 목록 + 용도
필수/선택: 필수
확인 목적: 승인 도구 목록·금지 사용 범위 확정
민감정보 주의사항: 조직이 승인하지 않은 도구 사용 여부도 솔직히 기재
```

## 5. 개인정보

```text
질문: 제작 콘텐츠에 개인정보(이름·연락처·주민등록번호 유사 정보 등)가 포함됩니까?
답변 형식: 예/아니오/일부 + 포함 위치(분류만)
필수/선택: 필수
확인 목적: 개인정보 입력 금지/허용 조건 설계
민감정보 주의사항: 실제 개인정보 값을 기재하지 말 것 — 포함 여부만 표시
```

## 6. 저작권 자료

```text
질문: 타인의 저작물(이미지·영상·음악·문서)을 사용하거나 외부 학습에 쓸 자료가 있습니까?
답변 형식: 예/아니오/일부 + 유형
필수/선택: 필수
확인 목적: 저작권 확인 대상과 외부 AI 입력 금지 자료 식별
민감정보 주의사항: 구체적 자료 원문 첨부 금지
```

## 7. 외부 공개 여부

```text
질문: 제작 콘텐츠 중 외부에 공개되는 것은 무엇인가요? (웹·SNS·언론 배포 등)
답변 형식: 채널 목록
필수/선택: 필수
확인 목적: 자동 게시 금지·사람 검토 gate 적용 범위
민감정보 주의사항: — 
```

## 8. 재작업·실패 유형

```text
질문: 콘텐츠가 자주 재작업되거나 실패하는 유형은 무엇인가요?
답변 형식: 빈도 높은 순서 나열
필수/선택: 필수
확인 목적: 재작업률 KPI·개선 포인트
민감정보 주의사항: 특정 직원 비판 대신 프로세스 관점으로 기재
```

## 9. 과거 교육 경험

```text
질문: 지난 1년간 AI 관련 교육을 받은 적이 있나요? 효과는 어땠나요?
답변 형식: 예/아니오 + 짧은 평가
필수/선택: 선택
확인 목적: 교육 경험과 실무 적용 간극 확인 (일반 강의의 한계 대비)
민감정보 주의사항: — 
```

## 10. 금지 업무

```text
질문: AI를 절대 쓰면 안 되는 업무가 있다면 무엇인가요?
답변 형식: 자유 텍스트
필수/선택: 필수
확인 목적: 위험업무 제외·금지 규칙 확정
민감정보 주의사항: 구체적 내부 지침 원문은 비공개 범위 확인 후 별도 제공
```

## 11. 파일럿 담당자

```text
질문: 6주 파일럿 동안 참여할 담당자(1팀 6–10명)와 운영 책임자 1인을 지정할 수 있나요?
답변 형식: 역할·인원·주당 투입 시간
필수/선택: 필수
확인 목적: 참여 가능성 판정 (적합성 판정표 "담당자 지정")
민감정보 주의사항: 실명 불필요 — 역할과 인원만
```

## 12. 예산 승인자

```text
질문: 파일럿 예산을 최종 승인할 수 있는 사람(직책)이 누구인가요?
답변 형식: 직책 + 승인 가능 범위(있으면)
필수/선택: 필수
확인 목적: 의사결정 경로 확인, 계약·결제 프로세스
민감정보 주의사항: 실명 대신 직책만 기재
```
