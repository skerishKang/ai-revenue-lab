# Business 35 · 파디엠 AI 미디어 업무전환 스튜디오 — 고객 진단 질문지

```
INTERNAL COMMERCIAL DRAFT
OWNER APPROVAL REQUIRED
NOT YET SENT TO A CUSTOMER
```

> **V3.1 product journey:** 현 미디어 업무 병목 이해 → 조직·결과물·병목·팀 규모·AI 사용 상태 입력 → 조직별 진단 + 새 업무 흐름 + 추천 파일럿 확인 → 운영체계 산출물 이해 → 진단 워크숍 또는 6주 파일럿 범위 판단 → 자기 조직용 전환 요약으로 상담 준비
> This questionnaire collects the five V3.1 input dimensions as fillable questions (조직 유형 / 결과물 유형 / 병목 지점 / 현재 팀 규모 / AI 사용 상태) plus detailed flow and governance checks. Inputs are synthetic/non-identifiable until contract allows otherwise.

Respondents must be able to actually fill this in. Do **not** ask respondents to paste actual personal data or internal documents into the questionnaire.

Fields per question: 질문 / 답변 형식 / 필수·선택 / 확인 목적 / 민감정보 주의사항

**V3.1 input mapping (fillable):** Q1 = 조직 유형, Q2 = 결과물 유형, Q3 = 병목 지점, Q4 = 현재 팀 규모, Q5 = AI 사용 상태. Q6–17 are flow/baseline/governance/readiness detail.

---

## 1. 조직 유형

```text
질문: 귀 조직의 조직 유형은 무엇인가요? (지역 문화기관 / 지역 교육기관 / 지역 협회·단체 / 지역 미디어·콘텐츠 기관 / 기업 홍보·콘텐츠팀 / 기타)
답변 형식: 단일 선택 + 기타 자유 기재
필수/선택: 필수
확인 목적: V3.1 입력 — 조직 유형 (현 미디어 업무 병목 → 조직 입력)
민감정보 주의사항: 조직명 약칭만, 실명·내부 기밀 기재 금지
```

## 2. 결과물 유형

```text
질문: 이번에 전환하고자 하는 대표 결과물 유형은 무엇인가요? (홍보물 / 교육자료 / 영상·이미지 / 캠페인 콘텐츠 / 보도자료 / 기타)
답변 형식: 1개 주 결과물 + 부 결과물 목록
필수/선택: 필수
확인 목적: V3.1 입력 — 결과물 유형 (대상 업무 특정)
민감정보 주의사항: 실제 결과물 원문 첨부 금지 — 유형만 표시
```

## 3. 병목 지점

```text
질문: 해당 결과물 제작에서 병목 지점은 어디인가요? (기획 / 초안 / 제작 / 검토 / 승인 / 배포 중 1–2개 선택 및 이유)
답변 형식: 복수 선택 + 짧은 이유
필수/선택: 필수
확인 목적: V3.1 입력 — 병목 지점 (진단 출발점)
민감정보 주의사항: 특정 인물 비판 대신 프로세스 관점 기재
```

## 4. 현재 팀 규모

```text
질문: 현재 해당 미디어 업무를 담당하는 현재 팀 규모는 어떻게 되나요? (상시 담당 인원 수, 역할 구성 — 예: 기획 1 / 제작 2 / 검토 1)
답변 형식: 인원 수 + 역할별 구성 표
필수/선택: 필수
확인 목적: V3.1 입력 — 현재 팀 규모 (리소스·병목·파일럿 운영 가능성 판단)
민감정보 주의사항: 실명 대신 역할·인원만 기재
```

## 5. AI 사용 상태

```text
질문: 현재 팀의 AI 사용 상태는 어느 단계인가요? (미사용 / 개인별 탐색 / 일부 업무 보조 / 승인 도구 운영 중 / 기타) 및 현재 사용 중인 승인/비승인 도구가 있다면 간단히
답변 형식: 단계 선택 + 도구명 간단 목록
필수/선택: 필수
확인 목적: V3.1 입력 — AI 사용 상태 (승인 도구·금지 범위 확정)
민감정보 주의사항: 승인되지 않은 도구 사용 여부도 솔직히 기재, 계정 정보 기재 금지
```

## 6. 현재 콘텐츠 제작 흐름

```text
질문: 현재 홍보/콘텐츠 제작이 어떤 단계로 진행되나요? (기획→초안→검토→승인→게시 순으로)
답변 형식: 자유 텍스트 또는 단계 나열
필수/선택: 필수
확인 목적: 대상 업무와 현재 흐름 파악, 워크플로 재설계의 출발점
민감정보 주의사항: 특정 인물·기밀 콘텐츠 제목 등은 기재 금지
```

## 7. 업무별 소요시간

```text
질문: 콘텐츠 1건당 각 단계(기획·초안·검토·승인·게시)에 며칠/몇 시간이 걸리나요?
답변 형식: 단계별 시간 표 (예: 기획 1일, 초안 2일 ...)
필수/선택: 필수
확인 목적: 기준선 측정 (KPI "기준 생산시간")
민감정보 주의사항: 특정 업무자의 실명·개인 성과 노출 금지
```

## 8. 검토·승인 단계

```text
질문: 검토와 승인이 몇 단계이며, 누가 승인하나요?
답변 형식: 단계 목록 + 역할(직책만)
필수/선택: 필수
확인 목적: 사람 검토 gate 설계
민감정보 주의사항: 실명 대신 직책만 기재
```

## 9. 현재 사용하는 AI 도구 상세

```text
질문: 조직원이 현재 사용하는 AI 도구는 무엇이며, 어떤 업무에 쓰나요? (Q5의 상태 요약과 별개로 도구별 상세)
답변 형식: 도구명 목록 + 용도 + 사용 빈도
필수/선택: 필수
확인 목적: 승인 도구 목록·금지 사용 범위 확정
민감정보 주의사항: 조직이 승인하지 않은 도구 사용 여부도 솔직히 기재
```

## 10. 개인정보

```text
질문: 제작 콘텐츠에 개인정보(이름·연락처·주민등록번호 유사 정보 등)가 포함됩니까?
답변 형식: 예/아니오/일부 + 포함 위치(분류만)
필수/선택: 필수
확인 목적: 개인정보 입력 금지/허용 조건 설계
민감정보 주의사항: 실제 개인정보 값을 기재하지 말 것 — 포함 여부만 표시
```

```text
민감정보 주의사항: 구체적 자료 원문 첨부 금지
```
