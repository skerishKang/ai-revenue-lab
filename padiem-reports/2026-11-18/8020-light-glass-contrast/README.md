# #8020 — light·glass Claw 사용자 말풍선 대비

기준: main `f5ac15c` (#8019·#8031 병합 뒤), 2026-11-18.
대상: `--claw-request-bubble-text` / `--claw-request-bubble-bg`.

## 합성 대비 측정

말풍선 내부 패딩의 스크린샷 픽셀을 **최종 합성 배경**으로 사용했다. 반투명 판의
`rgba`를 그 픽셀에 다시 합성하지 않았다(이중 합성 금지). 글자에 알파가 있으면
그 알파만 최종 배경 위에 합성한 뒤 WCAG 대비를 계산했다.

이전 #8030 보고의 glass 1.49는 배경 픽셀에 판의 `rgba(31,43,54,.74)`를 한 번 더
합성한 값이었다. 같은 방식의 cinematic 11.43도 이중 합성 값이다. 이번 측정의
정정 전 값은 glass 2.69, cinematic 14.59/15.01이며, home 15.96과 dark
11.45/11.29는 그대로다.

| 테마 | 1440 전 | 1440 후 | 390 전 | 390 후 |
|---|---:|---:|---:|---:|
| light | 3.42 | **5.14** | 3.42 | **5.14** |
| dark | 11.45 | 11.45 | 11.29 | 11.29 |
| cinematic | 14.59 | 14.59 | 15.01 | 15.01 |
| padiem-home | 15.96 | 15.96 | 15.96 | 15.96 |
| padiem-glass | 2.69 | **6.52** | 2.69 | **6.52** |

## 변경과 근거

- light: 기본 글자 `#111a22` → `var(--user-bubble-text)`(흰색). 보라 판
  `#6557e8`은 그대로 두고 글자만 밝게 했다. 검정으로 내려도 4.08이라 4.5에
  못 미치므로, 이미 light 사용자 말풍선이 쓰는 흰 글자를 그대로 쓴다.
- glass: 기본 글자 `#111a22` → `var(--user-bubble-text)`(흰색). 판
  `rgba(31,43,54,.74)`은 그대로 둔다. glass 일반 말풍선도 이미 흰 글자를 쓰고
  있어, 어두운 반투명 판의 톤을 유지하면서 대비를 올리는 쪽이 테마에 맞다.
- 테마별 글자 덮개를 없애고 루트 토큰이 `--user-bubble-text`를 읽게 했다.
  dark는 기존 dark-contrast 규칙이 더 높은 특이성으로 이기므로 계산색이 바뀌지
  않는다. home·cinematic도 기존 `--user-bubble-text`를 그대로 쓴다.
