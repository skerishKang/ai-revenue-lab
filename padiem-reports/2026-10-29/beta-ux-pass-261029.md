## 오류 코드 → 사용자 문구 대응표 (한 곳: `static/util-menu.js` GEN_ERROR_COPY + 각 COPY 블록)

### 생성 실패 — GEN_ERROR_COPY (이번 PR에서 신설, 4개 도구 공통)
| 상태 | 화면 문구 |
| --- | --- |
| 서버가 한국어 message를 줌 | 그대로 통과 (예: "생성 실패: 관리자 인증을 확인해 주세요.") |
| 401 | 생성 실패: 로그인이 필요합니다. 다시 로그인해 주세요. |
| 403 | 생성 실패: 이 계정에서는 할 수 없는 요청입니다. 로그인 상태를 확인해 주세요. |
| 429 | 생성 실패: 요청이 잠시 많습니다. 조금 뒤에 다시 시도해 주세요. |
| 500 | 생성 실패: 만드는 중 문제가 생겼습니다. 잠시 후 다시 시도해 주세요. |
| 502 | 생성 실패: 서버 연결이 잠시 끊겼습니다. 잠시 후 다시 시도해 주세요. |
| 503 | 생성 실패: 서버가 잠시 과부하 상태입니다. 잠시 후 다시 시도해 주세요. |
| 504 | 생성 실패: 서버 응답이 늦어집니다. 잠시 후 다시 시도해 주세요. |
| 네트워크 오프라인 | 생성 실패: 인터넷 연결을 확인해 주세요. |
| 그 외 | 생성 실패: 생성에 실패했습니다. 잠시 후 다시 시도해 주세요. |

실패 줄은 `생성 실패: ` 접두어를 유지한다 — 세션 복원 코드가 이 접두어로 실패 초안과
실제 저장 초안을 구분한다(_5785_util_harness.js).
