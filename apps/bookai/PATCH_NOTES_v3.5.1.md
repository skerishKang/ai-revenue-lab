# BookAI v3.5.1

- AI 질문의 패킷 준비를 8초로 제한하고 시간 초과 시 재시도 안내를 표시합니다. (#7032)
- 이전 페이지 근거 로딩을 6초로 제한합니다. 로딩이 지연되거나 실패하면 이전 근거를 비우고 기존 읽기 경계 판정으로 진행합니다. 부분 로딩 실패도 전체 이전 근거를 비웁니다. (#7033)
- 분리된 근거 어댑터는 독자 화면의 메모리 캐시를 공유하지 않으며 브라우저 HTTP 캐시를 사용합니다. 뒤쪽 장에서는 장 요청이 늘어날 수 있어 운영 측정 후 캐시 공유를 다시 검토합니다. (#7033)
- 장 본문의 정적 로딩이 실패하면 한 번 재시도해 일시적 오류 뒤에도 본문을 표시할 수 있도록 했습니다. 두 번 모두 실패하면 기존 폴백을 유지합니다. (#7039)
- AI 질문 응답에 `Server-Timing` 진단값을 추가했습니다. `packet`은 브라우저 준비, `upstream`은 상류 왕복, `worker`는 상류 시간을 포함한 Pages 처리 시간입니다. 응답 본문은 유지합니다. (#7049)
- 로그인 안내 버튼 터치 크기 시험에 0.01px의 서브픽셀 반올림 허용 오차를 적용했습니다. 버튼 CSS는 변경하지 않았습니다. (#7051)
- Pages 배포 및 실제 응답 시간 측정은 별도로 진행합니다.
