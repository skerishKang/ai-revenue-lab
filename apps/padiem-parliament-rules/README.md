# padiem-parliament-rules

`#6014`의 4개국 조사가 남긴 결론을 **실행 가능한 계약**으로 고정한 워크스페이스입니다. 여기 있는 것은 판정 함수와 선언형 데이터뿐이고, 어떤 실행 경로도 아직 이 모듈을 lambda m: m.group(0)하지 않습니다.

## 왜 필요한가

국가 코드로 법령의 정확성·승인 절차·문서 양식이 보장되지 않습니다. 조사에서 확인된 사실은 다음과 같습니다.

- 같은 한국 안에서도 광역과 기초의 발의 정족수·비용추계 요건이 다릅니다(경상남도의회 회의규칙에는 정족수가 없고 조례로 위임, 강진군의회 회의규칙 제21조는 재적 5분의 1 연서이고 비용추계 생략을 명시).
- 영국은 `Parliamentary Standards Act 2009` s.2가 상원을 IPSA 체계 밖으로 두어 상원 직원 경비가 하원과 다른 규칙을 따릅니다.
- 미국 상원에는 의원실 정원 상한이 없고 배정액 상한만 있으며(CRS R44399), council-manager 도시에서는 법령상 의원 개인 보좌 조직이 없습니다(RCW 35A.13.010).
- 프랑스 코뮌의 직원 근거는 CGCT가 아니라 CGFP `L. 333-1`부터 `L. 333-12`이고, groupe d'élus 수단은 CGCT `L. 2121-28`(인구 10만 이상, 상한 30%)입니다.

이 값들을 화면 코드나 프롬프트 문자열에 흩어 놓으면 조사 결론과 구현이 갈라집니다. 그래서 한 곳에 두고, 출처를 싣고, 모르는 것은 모른다고 표시합니다.

## 세 가지 속성

1. **fail-closed** — 등록되지 않은 (국가, 기관 단계, 문서 유형) 조합은 `UNVERIFIED`와 빈 값을 돌려줍니다. 조사하지 않은 조합에 그럴듯한 기본값을 만들지 않습니다. 범위 밖 국가 코드(`de` 등)는 `KeyError`로 거부되어 "조사했으나 미확인"과 "입력 오류"가 섞이지 않습니다.
2. **승인자 강제 없음** — 승인 요구는 문서에 대한 규칙이지, 두 번째 사람이 반드시 존재한다는 뜻이 아닙니다. 의원 1인 사용에서는 검토 단계가 워크플로에 생기지 않습니다(`workflow_steps(..., staffed=False)`).
3. **출처 또는 표기** — `VERIFIED` 레코드는 최소 하나의 1차 출처(URL·조문 또는 판·조회일)를 가지며, 확인하지 못한 필드는 `gaps`에 사유가 적힙니다. `is_safe_to_use_as_fact()`가 그 구분을 호출하는 쪽에 넘깁니다.

## 면적

| 함수 | 역할 |
|---|---|
| `rule_for(country, tier, kind)` | 좌표 하나의 행동 계약 조회 |
| `rules_for_country(country)` | 국가 전체 관점 |
| `staffing_for(country, tier)` | 지원 인력의 법적 단위·정원 규칙 |
| `approver_required(rule)` | 실제 승인자가 규칙에 있는지 |
| `workflow_steps(rule, staffed=…)` | 6단계 파이프라인(검토 단계는 사람 있을 때만) |
| `registered_keys()` / `unresolved_keys()` | 커버리지와 미해결 목록 |

## 이 워크스페이스가 하지 않는 일

- `/api/chat`·council 앱·저장 경로·모델 라우터·마이그레이션을 변경하지 않습니다.
- AI 엔진, RAG, 검색 인덱스, 법령 API 클라이언트, 민원 기능을 추가하지 않습니다.
- Memory/RAG 계층(`apps/padiem-ai-engine`)의 fail-closed 상태를 건드리지 않습니다.
- 값을 확정하지 않습니다. `UNVERIFIED`와 `PARTIAL`은 테스트를 통과시키기 위해 지우지 않습니다.

## 테스트

```bash
python -m pip install -e 'apps/padiem-parliament-rules[dev]'
python -m pytest apps/padiem-parliament-rules/tests -q
```

`tests/test_parliament_rule_mapping.py`는 법 조문의 옳고름이 아니라 **권위의 모양**을 검증합니다: 레코드 완전성, 출처·조회일 존재, 미확인 필드 표기, fail-closed, 승인자 강제 없음, 좌표 체계의 국가 분리.
