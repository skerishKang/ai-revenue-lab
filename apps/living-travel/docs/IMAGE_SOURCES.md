## Generation method

All images use inline CSS background gradients as placeholders until
license-cleared real photographs are sourced. This approach:

- Requires zero network requests.
- Has no licensing ambiguity.
- Produces a visually complete demo layout.
- Clearly communicates "synthetic preview."

## Replacement policy

When CC0 or properly licensed Busan travel photographs are obtained:

1. Convert to WebP (quality 80).
2. Keep under 400 KB (hero) / 250 KB (section).
3. Strip EXIF.
4. Add meaningful Korean `alt` text.
5. Update this file with source URL, photographer attribution, and date.

## Prohibited

- Hotlinking from search results, travel blogs, or unlicensed sources.
- Images containing identifiable people, property, or personal data.
- Images that could be mistaken for real-time travel conditions.
