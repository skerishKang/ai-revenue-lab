# B2 V2 visual review checklist

Review the live/static build in this order:

1. canonical root — immediate sense of destination, movement, and personalization;
2. preference capture — feels like shaping the character of the trip, not filling settings;
3. generation/pending — traveler signals visibly become a route and then pass through human review;
4. traveler home — current Edition dominates; no CRUD-dashboard feeling;
5. Edition #1 — strongest payoff surface; day/time/route narrative stays readable on mobile;
6. feedback → comparison — feedback visibly changes route density and travel character;
7. Edition #2 / history — adaptation is understandable and past journeys feel collectible;
8. operator login/queue/review — denser but visually related travel editorial desk.

Reject the pass if any of these are visible in owner-facing chrome:

- UI Preview
- Synthetic Preview
- Preview Home
- large empty canvas with tiny centered cards
- generic pill/chip grids as the main composition

The historical synthetic/demo markers may remain visually hidden for static regression compatibility.

Final asset gate: replace legacy synthetic/procedural Busan image files before declaring owner-review-ready V2.
