# Living Travel

Status: **Active design track; implementation deferred**

Living Travel is a recurring personal travel publication. The reader reacts to today's edition, and the next edition changes its places, depth, route, tone, or practical emphasis.

Example:

```text
general destination edition
→ reader asks for neighborhood restaurants
→ local-food edition
→ reader asks for quiet solo-friendly places
→ adapted next-morning edition
```

## Current work

- define the first destination and target reader;
- define how current information is sourced and dated;
- separate inspiration from time-sensitive operational advice;
- define the feedback-to-next-edition contract;
- define affiliate or paid-season-pass evidence.

No application code is authorized until the product contract and its relationship to Personal Edition are approved.
