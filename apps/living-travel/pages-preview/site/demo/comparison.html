여행판이 어떻게 달라졌나요?

의견을 반영해 두 번째 여행판이 새롭게 구성되었습니다.

반영한 피드백
더 천천히 · 유명 관광지 줄이기 · 조용한 장소 늘리기 · "더 조용하고 느린 동네 중심으로 바꿔 주세요."

1판 Before

1일차
초량동 168계단 → 자갈치 시장 → 용두산 공원 → 광복동 쇼핑 거리 → 남포동 저녁
2일차
감천문화마을 → 해운대 해변 → 동백섬 → 센텀시트 → 해운대 야시장
3일차
송도 해안 → 송도 케이블카 → 송도 구름산책로 → 서면 쇼핑 → 부산역
하루 평균 4~5개 장소 · 이동 많음

2판 After (피드백 반영)

1일차
초량동 골목 카페 → 168계단 산책 → 동네 밥집 → 자갈치 해질녘 산책
2일차
감천마을 아침 산책 → 동네 식당 → 이기대 바다 산책로 → 송정 조용한 카페
3일차
송도 해안 산책로 → 찻집 휴식 → 남포동 골목 마지막 산책
하루 평균 2~3개 장소 · 머무는 시간 증가

무엇이 달라졌나요?

✓ 장소 수 감소 — 하루 4~5곳에서 2~3곳으로 줄었습니다.
✓ 유명 관광지 제외 — 용두산 공원, 광복동 쇼핑 거리, 서면, 송도 케이블카가 빠졌습니다.
✓ 골목과 생활권 중심 — 동네 식당, 골목 카페, 조용한 찻집이 늘었습니다.
✓ 이동 감소, 머무는 시간 증가 — 촉박한 일정 대신 여유로운 산책과 휴식.
