개념 1 · 변수

변수는 값을 담아 두는 이름입니다

프로그램은 값을 어딘가에 담아 두고 다시 사용합니다. 그때 값에 붙여 주는 이름이 바로 변수입니다.

1. 먼저 개념부터

변수는 값에 붙인 이름표입니다. “지민”이라는 이름을 한 번 담아 두면, 그 뒤로는 name이라고 부르기만 하면 됩니다. 값을 매번 다시 쓰지 않아도 되니 실수가 줄고, 나중에 값을 한 곳에서만 바꾸면 됩니다.

값을 담을 때는 = 기호를 씁니다. 수학의 ‘같다’가 아니라, 오른쪽 값을 왼쪽 이름에 담는다는 뜻입니다.

개념 카드

변수 = 이름표를 붙인 상자. 상자 안에는 값이 들어 있습니다.

이름 (변수)name
→
담긴 값"지민"

2. 코드로 보기

이름 두 개에 값을 담고, 화면에 출력합니다.

lesson_01.py PYTHON · 실행 결과만 표시 
name = "지민"study_minutes = 10 print(name)print(study_minutes)
예상 실행 결과
지민
10
1행name이라는 이름에 문자열 "지민"을 담습니다. 문자열은 따옴표로 감쌉니다.
2행study_minutes에 숫자 10을 담습니다. 숫자는 따옴표 없이 씁니다.
4–5행print()는 괄호 안의 값을 화면에 출력합니다.
초보자 주의 — "10"(따옴표 있음)은 글자이고, 10(따옴표 없음)은 숫자입니다. 지금은 둘을 다른 종류로 기억해 두면 충분합니다.

도움말: = 기호가 헷갈려요

=는 ‘같다’가 아니라 ‘오른쪽 값을 왼쪽에 담는다’는 뜻입니다. name = "지민"은 “지민을 name에 담기”라고 읽으면 편합니다.

왜 print를 쓰나요?

값이 잘 담겼는지 눈으로 확인하는 가장 빠른 방법이 출력입니다. print(이름)으로 담은 값을 꺼내 볼 수 있습니다.
