AI가 이렇게 바꾼 이유

코드 먼저첫 수업 이해도 문제에서 코드 실행 순서를 한 번 헷갈려 하셨습니다. 설명보다 코드를 먼저 보면 ‘어떤 순서로 실행되는지’가 눈에 먼저 익습니다.
예제 +2“예시를 늘려 달라”고 직접 답하셨습니다. 같은 ‘변수’ 개념을 이름·나이·시간처럼 서로 다른 예제 3개로 반복합니다.
복습 +2변수 숙련도가 72%입니다. 한 번 더 확인하면 안정권(85% 이상)에 들어가므로 복습 문제를 3개로 늘립니다.
용어 해설“어려운 용어를 쉽게” 피드백에 따라 ‘문자열’, ‘출력’ 같은 낯선 말 옆에 바로 한 줄 정의를 붙입니다.
속도진단에서 자신감이 ‘조금 불안’으로 나와, 단계를 더 잘게 나누고 한 번에 한 가지만 다룹니다.
이 변경은 이해도 결과 + 학습자 피드백이라는 근거에서 만들어집니다. “AI가 알아서”가 아니라, 어떤 입력이 어떤 변화로 이어졌는지 항상 확인할 수 있습니다.
