# Visual System

## Color tokens

| Token | Value | Usage |
|-------|-------|-------|
| --paper | #f4f0e8 | Page background |
| --surface | #fffdf9 | Card/surface background |
| --ink | #24231f | Primary text |
| --muted | #716b62 | Secondary text |
| --forest | #203c32 | Links, accents |
| --forest-soft | #dfe8e2 | Subtle accents |
| --oxblood | #8c302d | Error, destructive |
| --oxblood-soft | #f1e2df | Subtle error |
| --border | #d7cec0 | Borders, dividers |

## Typography

- Editorial body: ui-serif, Georgia, Cambria, serif
- Interface: ui-sans-serif, system sans
- Korean-first: system Korean fonts via font-family chain

## Layout

- Max width: 680px (desktop)
- Editorial grid: 4-column on desktop, 1-column on mobile
- Hairline borders (1px) instead of card shadows
- Generous vertical rhythm: 1.5x line height

## Image treatment

- Full-bleed hero images
- Tight crop editorial style
- No decorative frames or drop shadows
- Alt text: informative for content images, empty for decorative

## State differentiation

| State | Visual language |
|-------|----------------|
| Source fragments | Collaged, overlapping, muted |
| AI draft | Soft background, draft watermark |
| Editorial review | Annotation marks, margin notes |
| Published edition | Clean, confident, cover-led |
| Feedback | Form-focused, structured |
