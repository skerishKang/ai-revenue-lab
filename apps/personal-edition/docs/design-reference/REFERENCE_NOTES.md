# Reference Notes

## Structural inspiration (not visual replication)

### Substack
- Strong cover-led publication hierarchy
- Clear issue number / date / theme metadata
- Reading-first layout with generous margins

### MUBI Notebook
- Image-centered editorial rhythm
- Tight crop, high contrast
- Text as editorial annotation, not wall copy

### The Gentlewoman
- Strong cover identity with issue number
- Library/archive as navigational surface
- Editorial grid with consistent vertical rhythm

### Are.na
- Fragmented records assembled into collections
- Block-based, non-linear progression
- Visual weight through repetition, not decoration

## Personal Edition adaptation

- Korean-first typography
- Private archive as library metaphor
- Source fragments → draft → final edition transformation
- No blog/journal/newsletter aesthetic
- No AI SaaS illustration
