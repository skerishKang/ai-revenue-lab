# Living Fiction

Status: **Active design track; implementation deferred**

Living Fiction tests whether AI can create a shared narrative world while reacting to reader feedback fast enough to produce new episodes, viewpoints, branches, or personal editions while reader interest is still active.

## Product principle

A common canon preserves shared discussion and fandom. Optional reader-responsive branches provide personalization without turning every reader's experience into an unrelated work.

## Current work

- define the boundary between canon and personal branch;
- define reader voting, comments, and explicit choice inputs;
- define world-state and continuity contracts;
- define acceptable response time for a next episode;
- define payment evidence for episodes, branches, character passes, or completed personal editions;
- define authorship, disclosure, and intellectual-property rules.

No story-generation application code is authorized until the narrative contract and quality benchmark are approved.
