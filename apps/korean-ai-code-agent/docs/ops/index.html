Product thesis

대표가 반복 입력·전달을 하는 대신, Claw가 중간 실무를 처리하고 사람은 중요한 결정을 승인한다.

이 문장은 통화에서 나온 요구를 제품 언어로 정규화한 것입니다. 자동 계약·자동 결제까지 허용한다는 뜻은 아닙니다.
