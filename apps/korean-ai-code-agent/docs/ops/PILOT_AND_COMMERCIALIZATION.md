# Padiem Claw Ops — Design-Partner Pilot and Commercialization

Issue: #1414  
Parent: #1407

## Pilot thesis

The discovery counterpart proposed using their own company first, learning from real use, reviewing results after roughly six months, and then using the resulting evidence in wider SME sales/study-group activity and potentially in a public support/R&D proposal.

This document converts that idea into an evidence-driven pilot plan.

## Phase 0 — Baseline

Before automation, record:
- monthly number of commercial requests/RFQs;
- time from request arrival to supplier RFQ;
- time spent preparing/comparing quotes;
- time to purchase-order issue;
- manual re-entry count;
- supplier response turnaround;
- error/rework rate;
- owner/staff minutes per workflow;
- current communication/document/accounting tools.

## Phase 1 — Shadow mode

Claw Ops performs:
- extraction;
- structuring;
- supplier candidate resolution;
- comparison;
- recommendation;
- document draft generation.

Humans continue the current process. No external side effects are required. Compare Claw outputs against actual human outcomes.

## Phase 2 — Approval-gated live mode

Enable selected live actions only after shadow reliability is acceptable:
- approved RFQ delivery;
- approved negotiation messages;
- approved purchase orders;
- delivery reminders/status updates.

## Phase 3 — Finance augmentation

Add payment-term and cash-timing recommendation only after Quote-to-Order data is reliable.

## KPI framework

### Time/efficiency
- minutes saved per completed workflow;
- manual re-entry eliminated;
- quote comparison preparation time;
- PO preparation time;
- approval turnaround.

### Commercial outcome
- supplier response cycle time;
- measured price improvement where comparable;
- delivery exception rate;
- payment-term usage.

### Quality/safety
- extraction correction rate;
- user override rate;
- stale-approval blocks;
- duplicate/retry incidents;
- connector failures;
- workflow completion rate.

### Economics
- infrastructure/model cost per completed workflow;
- cost per accepted business outcome;
- owner/staff labor-time value saved, reported separately from direct cash savings.

## Six-month review

At the six-month target, answer:

1. Which workflow steps reliably save time?
2. Which steps still require frequent correction?
3. Which approvals are truly necessary versus noisy?
4. Does the owner use the executive inbox regularly?
5. Are price/cash-flow recommendations trusted and evidence-backed?
6. What is the actual cost per completed workflow?
7. Which integrations are necessary for repeatable onboarding?
8. Is this a repeatable SME product or a company-specific customization?

## Commercialization package

If pilot evidence is positive:
- anonymized before/after case study;
- repeatable SMB onboarding checklist;
- Quote-to-Order workflow template;
- demo dataset with no private customer data;
- pricing/cost model;
- sales deck/workshop material;
- SME study-group demonstration script;
- public-program/R&D problem statement with measured baseline and targets.

## Evidence discipline

- measured vs estimated must be labeled;
- no invented ROI;
- no public customer name/data without permission;
- public-program claims cite pilot evidence;
- source data definitions remain stable between baseline and after measurement.

## Commercial direction hypothesis

This is a hypothesis to test, not source-derived fact:

```text
Managed Cloud subscription
+ usage/automation credits
+ optional onboarding/integration package
+ later Team/Enterprise/Self-Hosted plans
```

No pricing is locked by this document.
