From intention to verified work.

01 / DELEGATE

Describe the outcome.

Select a repository and tell Claw what needs to be done. Product intent stays separate from model/provider routing authority.

02 / EXECUTE

Work in isolation.

Cloud runs use bounded sandbox leases. A reserved workspace never pretends the Agent has started before canonical P01 evidence exists.

03 / VERIFY

Review evidence, not promises.

Diffs, tests and bounded evidence become the output. GitHub automation will default to branch + Draft PR, never silent merge.

SAFE BY BOUNDARY

The Agent doesn't get unlimited authority.

Secrets, provider routing, account entitlements, reusable approval semantics and sandbox permissions stay in their own authority planes. Claw coordinates product work without becoming a second AI Core or a second model router.

Early cloud policy: network off by default · bounded TTL/resources · exact run/trace correlation · no auto-merge/deploy.
