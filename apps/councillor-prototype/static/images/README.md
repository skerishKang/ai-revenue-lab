## 2. 형식

- **히어로 배경·인물 사진은 WebP**입니다. 같은 그림의 JPG/PNG(387KB / 394KB)는
  WebP(176KB / 39KB)로 바꾸면서 삭제했습니다. 되돌릴 때는 이 표의 파일명 그대로
  같은 위치에 넣으면 되고, 코드는 경로만 봅니다.
- 인물 사진은 휴대폰(≤760px)에서 `profile-portrait-390.webp`, 넓은 화면에서
  `profile-portrait.webp`를 받도록 `srcset`/`sizes`로 나눠 두었습니다.
- 의정활동 사진(`activity-0*.jpg`, `media-0*.jpg`)은 원본(약 5.5K)을 표시 크기의
  2~3배로 다시 줄인 것입니다. 사이트 목록의 350×232 썸네일(`…t.jpg`)을 확대해 쓰지
  않습니다. 이 8장은 아직 JPEG이며, 사진 자체를 갱신할 일이 없어 이번에 건드리지
  않았습니다.
