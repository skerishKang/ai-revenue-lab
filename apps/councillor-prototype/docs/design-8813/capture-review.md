# #8813 사진 보기 창 초점·어둡게 테두리 수리 검증

## CTO 판정과 수리 범위

- D6 사진 보기 창의 닫기(×)·이전·다음·원문 보기 키보드 초점에 공통 `#7cc0ea` 색, 2px 선과 2px 간격 적용. 검은 창 안에서만 적용하고, 창 밖 `:focus-visible` 규칙은 변경하지 않음.
- #8821 마지막 항목(D3): 어둡게에서만 테두리형 단추·칩에 공통 `--outlined-control-contrast` 색을 사용. 머리줄 밝게 보기·글씨 크게, 의정활동 상세의 공식 페이지 보기·공유하기, 홈 바로가기·검색, 정책자료 칩, 기타 테두리형 단추에 동일 규칙 적용. 밝게 테마의 테두리·단추 글자색 변경 없음.
- 제품 파일은 `static/styles.css` 하나만 변경. 새 `!important`·별도 CSS 파일·문구 변경 없음.

## 픽셀 영향 감사

`pixel-audit.json`에 전후 원본 이미지 차이와 허용 예외 마스크를 **별도로** 기록함.

- 1440 어둡게 사진 창: 실제 차이 1,162픽셀. 닫기 초점·검은 창을 4% 투과해 보이는 뒤쪽 어둡게 단추·이미지 렌더링 영역을 제외한 고정 부분 **0픽셀**.
- 390 밝게 사진 창: 실제 차이 613픽셀. 닫기 초점과 원본이 같은 사진 렌더링 범위(1픽셀 안티앨리어싱 변화)를 제외한 고정 부분 **0픽셀**.
- 390 어둡게 홈: 실제 차이 3,178픽셀. 머리줄·주요 바로가기·검색 단추 테두리 영역을 제외하면 **0픽셀**.
- 1440 어둡게 머리줄+상세 단추: 사진이 아닌 비교 이미지 구분선 2px은 검사에서 제외함. 실제 차이 1,550픽셀, 테두리 영역 밖 **0픽셀**.
- 사진 보기 창은 원래 배경 불투명도가 96%라 뒤쪽 테두리가 희미하게 비치는 부분도 의도된 2번 변경의 예외로 분리함.
- 밝게 일반 버튼의 기존 테두리 계산값은 각 페이지 회귀시험에서 변경 없음을 확인함.

사진·영상·HTML·JSON·머리줄·바닥글 문구 및 제품 파일은 변경하지 않았음.
