## 브라우저 수치 (전 → 후)

- 바깥 링크 표시: 2 → 1.
- 빈 칸 경고 `aria-invalid`: 없음 → true, 입력 시 삭제.
- 경고 테두리: 반투명 밝은색 → rgb(255, 182, 107); 바탕 rgb(0,24,60). 색상 대비는 신규 시험에서 3:1 이상으로 검증.
- 경고 안내의 입력 아래 간격: 별도 안내 없음 → 390 밝게 8px, 1440 어둡게 19.5px.
- 휴대폰 바닥글 아래 안쪽 여백: 20 → 69px (하단 탭 45px + 24px).
- 390 실패 상태 안내와 탭 간격: 18.8 → 67.8px.
- 390 실패 상태 보내기와 탭 간격: 68.8 → 117.8px.

## 픽셀 검증

`pixel-audit.json`에 직접 비교 결과를 남겼습니다. 390 화면에서는 비교가 가능한 바닥글 위 영역이 일치합니다. 1440 화면 바닥글 위에서 미디어·목록 표시 영역에 차이가 관찰되어 전체 바깥 영역의 0픽셀을 주장하지 않습니다. 수정 파일은 바닥글 데이터·동작·스타일뿐이며, 정책자료 화면의 코드는 수정하지 않았습니다.
