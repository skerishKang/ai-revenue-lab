# #8808 전후 화면 확인과 픽셀 비교

| 화면 | 확인한 내용 |
|---|---|
| 390 밝게 첫 화면 | 수리 전 용어 풀이가 먼저 표시되어 첫 카드가 밀렸고, 수리 후 첫 카드 제목과 자세히가 먼저 나타남. 머리줄·검색 줄 그대로 |

## 픽셀 비교 범위와 한계

- 위 네 장의 머리줄 및 검색 영역처럼 수리 대상 밖 고정 구간을 전후 동일 좌표로 비교한 결과 **4/4 구간 차이 0픽셀**.
- 나머지 여섯 HTML 페이지의 첫 화면(390·1440, 밝게·어둡게) 24쌍 비교에서 **20쌍 전체 화면 차이 0픽셀**.
- 나머지 네 쌍은 소개 영상 또는 미디어 이미지 안에서 시점에 따른 픽셀 차이 발생. 동일한 수정 전 빌드를 두 번 촬영한 대조에서도 소개 영상과 미디어에서 차이가 재현됨. 이는 변경 파일의 밖에 있는 동적 자산이므로 정적 화면 수리 회귀로 판단하지 않으며, **이 네 쌍의 전체 화면 픽셀 일치를 주장하지 않음**.
- 원본 HTML 변경은 용어 풀이 한 줄의 위치 이동뿐이며, CSS 수정 대상은 `.activity-legend`와 720px 이하 `.activity-item`으로 한정. 다른 쪽 HTML·이미지·영상·머리줄은 변경하지 않음.

개별 화소 비교 결과는 `pixel-audit.json`에 기록. 동적 외부 자료를 차단한 보조 정적 비교는 `pixel-audit-static.json`에 기록.
