## 2. 미세 오차의 원인 (숨기지 않고 기록)

- **카드 높이 356 vs 190, 전체 문서 1925 vs 1086**: 원본 목업의 카드는 장식적 이미지 + 한 줄 제목이지만, 구현 카드는 실제 의정활동 제목(최대 3행)·요약·상세 링크를 담는다. CENTRAL 지시(“가상 활동을 추가하지 말 것”)에 따라 카드 내용을 줄이는 대신 높이 차이를 남겼다.
- **4번째 카드**: 원본은 서로 다른 4건이지만 검증된 활동은 3건이므로, 4번째는 임의 활동이 아니라 “전체 기록 5건” 요약 카드로 처리했다.
- **푸터 높이**: 원본은 한 줄짜리 목업 푸터, 구현은 시제품 고지 + 자료 출처 2행을 포함한다.
- **히어로 배경**: 원본은 도시·강 파노라마, 구현은 하늘 그라디언트 자리표시자다(§4 참조).
- **원문 대비 누락**: 원본의 인용문 박스와 “모든 정책 보기” 링크는 검증된 문구가 없어 넣지 않았다.

## 4. 이미지 자산 처리 (지시 준수)

지시대로 **이미지 생성·임의 장면 구성은 하지 않았다.**

- **인물**: 현 의회 공식 컷아웃 `assem.jeonnam-gwangju.go.kr/.../남구1_민주당_임미란.png` (**500×641**).
  - 구현 배율: 1440 데스크톱 **282px 폭(0.56× 축소)**, 390 모바일 137px 폭(0.27×). **확대 없음.**
  - 알파 검증: 모서리 alpha=0, 불투명 63.9% / 완전투명 35.1% → 정상 컷아웃. 원본 프로필(311×399)은 대체 이미지로만 사용.
- **밴드 배경**: 인물과 **분리된 레이어**(`.hero-bg`)로 구현했다. 교체는 `styles.css`의 **한 줄**:
  ```css
  :root { --hero-image: url("./hero-panorama.jpg"); }
  ```
  레이아웃·텍스트 위치·인물 배치는 배경 이미지 유무와 무관하게 동일하다. 도시·강·하늘 배경 자산을 확보하면 CSS 수정 없이 교체된다.
- 보정 레이어(스크림)는 배경 위에만 적용되어, 어떤 사진을 넣어도 좌측 텍스트 대비가 유지된다.

## 5. 기능 테스트와 시각적 충실도 (분리 판정)

- 독립 페이지 5개 모두 200 응답, JS 페이지 오류 0 (favicon 404 1건은 기존 사항)
