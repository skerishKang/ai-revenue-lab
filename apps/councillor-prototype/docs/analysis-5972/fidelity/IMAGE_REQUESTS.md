## 2. 촬영·선정 기준

| # | 조건 |
|---|---|
| ① | 밝은 낮의 도시·강·하늘 장면. **글자·로고·방송 자막이 찍혀 있지 않은 것.** 왼쪽 1/3은 제목이 올라가므로 하늘이나 단순한 배경이 좋고, 오른쪽에 인물을 합성할 여유가 있는 구도 |
| ② | 단색 배경 상반신. **배경 제거 전 원본도 함께** 주시면 가장자리를 더 깨끗하게 만들 수 있습니다 |
| ③ | 본회의·위원회·기념식 현장의 **가로 와이드 원본**. 현재는 세로의 약 46%가 잘려 나갑니다 |
| ④ | 의회 공개 사진의 **원본 해상도** 파일이면 충분합니다(같은 사진이면 교체 불필요) |
| ⑤ | 현재와 같은 구도의 스튜디오 프로필, 고해상도 |
