## 1. 히어로 배경 파노라마 — **없음 (최우선)**

| 항목 | 내용 |
|---|---|
| 필요한 것 | 도시·강·하늘이 함께 담긴 **가로로 넓은 실제 장면 사진** |
| 사용 위치 | 홈 상단 히어로 밴드 **전체 배경** (텍스트·버튼 뒤). `static/styles.css`의 `--hero-image` 한 줄로 교체 |
| 표시 크기 | 1440×361px (화면 폭 전체) |
| 권장 원본 | **2880×720 이상 (4:1)**, 가능하면 3840×960. Retina 2배 기준 |
| 촬영 조건 | 밝은 낮, 하늘/물/녹지가 보이는 장면. **글자·로고·방송 자막이 찍혀 있지 않은 것**. 왼쪽 1/3은 텍스트가 올라가므로 단순한 하늘이나 넓은 배경이 좋고, 오른쪽에 인물을 합성할 여유가 있는 구도 |
| 현재 대체 가능? | **불가.** 보유 자료에 전폭 장면 사진이 없고 이미지 생성이 금지되어 있어, 지금은 단색 그라데이션으로 대체 중입니다 |
| 새로 받을 사진 종류 | 광주 도심·영산강·남구 일대 전경(해질녘 또는 맑은 낮), 또는 의원실이 보유한 도시 홍보용 와이드 컷 |

## 3. 활동 카드 썸네일 — **비율 불일치(과 cropping)**

|---|---|
| 사용 위치 | 홈 「주요 의정활동」 카드 3장 |
| 표시 크기 | 306×115px (약 2.67:1) |
| 권장 원본 | **920×345 이상 (2.67:1)** |
