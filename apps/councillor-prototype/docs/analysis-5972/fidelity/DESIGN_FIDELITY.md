## 4. 남은 차이와 이유

### A. 히어로 — 해결 (영산강 파노라마 적용)
원본: **화면 전체를 덮는 도시·강 파노라마 사진** 위에 인물을 **누끼 합성**하고, 오른쪽에 손글씨 인용문 + 서명을 배치.
구현: **영산강(광주) 파노라마 3840×960** 위에 공식 누끼 인물을 합성했습니다. 배경과 인물은
서로 다른 레이어(`--hero-image` / `.hero-portrait`)라 사진만 교체해도 레이아웃은 그대로입니다.

- 배경: `Yeongsan_River_in_Gwangju.JPG`(6016×4000)에서 4:1로 크롭 → 3840×960.
  촬영 Saigen Jiro, Wikimedia Commons, **CC0**. 바닥글에 출처를 표기했습니다.
- 인물: 통합특별시의회 공식 누끼(500×641). 히어로 표시 높이 361px보다 크므로 축소 사용(선명).
- 가독성: 라이트 테마는 흰색 스크림(0.94→0), 다크 테마는 남색 스크림을 배경 위에 덮어
  두 테마 모두 본문 대비를 유지합니다.

남은 차이는 **손글씨 인용문(문구 대기)** 뿐입니다.

### B. 카드·3열 밴드 밀도 (+24 / +132)
원본 카드는 사진 + 제목 + 2줄 설명뿐인 마케팅 카드입니다. 구현 카드는 **공개 자료로 확인한 날짜·회의 구분·원문 링크**를 함께 싣습니다(이 페이지의 목적). 아이콘·여백·행간을 원본 쪽으로 조여 카드를 249.1 → **207.3px**까지 줄였고(원본 183px), 남은 차이는 **제거하면 기록이 사라지는 정보 행**입니다. 같은 이유로 3열 밴드의 요약문 1줄과 출처 표기도 유지합니다.

### C. 아이콘 표현
원본은 분야별 색상 아이콘을 쓰고, 구현은 의미 아이콘을 **파랑 계열 한 색**으로 통일했습니다. 원본의 항목별 색상(초록·빨강 등)은 현재 확정된 파랑 강조 체계를 벗어나므로 임의로 도입하지 않았습니다.

### D. 남색 밴드가 원본보다 36px 낮음
원본 밴드에는 배경 사진이 깔려 있어 여백이 더 큽니다. 구현은 텍스트+수치만으로 92.8px이며 정보 손실이 없습니다.

### E. 인용문 블록(원본 오른쪽 손글씨)
원본의 인용문은 **시안용 예시 문구**입니다. 확인되지 않은 1인칭 발언을 의원 발언처럼 게시할 수 없어 넣지 않았습니다.
CTO 결정(2026-10-28): **확인된 문구가 없으면 블록을 생략**합니다. 현재 상태가 그 결정대로입니다.
문구가 확인되면 그때 추가합니다.
