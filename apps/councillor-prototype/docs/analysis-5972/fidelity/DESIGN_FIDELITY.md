## 4. 남은 차이와 이유

### A. 히어로 — 가장 큰 차이 (이미지 필요)
원본: **화면 전체를 덮는 도시·강 파노라마 사진** 위에 인물을 **누끼 합성**하고, 오른쪽에 손글씨 인용문 + 서명을 배치.
구현: 흰 바탕 위 좌측 텍스트 + 우측 **스튜디오 프로필 사진**(프레임 박스). 배경 레이어는 `--hero-image: none` 상태로 자리만 준비되어 있습니다.

합성 불가 사유: 보유 자산에 **전폭 장면(파노라마) 사진이 없고**, 이미지 생성은 금지되어 있습니다. 별도 요청: `IMAGE_REQUESTS.md`.

### B. 카드·3열 밴드 밀도 (+47 / +132)
원본 카드는 사진 + 제목 + 2줄 설명뿐인 마케팅 카드입니다. 구현 카드는 **공개 자료로 확인한 날짜·회의 구분·원문 링크**를 함께 싣습니다(이 페이지의 목적). 이 정보를 빼면 원본 밀도에 가까워지지만 **기록 정보가 삭제**되므로 유지했습니다. 같은 이유로 3열 밴드의 소식 목록도 요약문 1줄과 출처 표기를 유지합니다.

### C. 아이콘 표현
원본 스트립·카드는 색상 원형 **분야 아이콘**(사람/잎/하트 등)을 쓰고, 구현은 숫자 배지(1·2·3)입니다. 기능·정보는 동일하며 아이콘 세트 도입은 새 디자인이므로 대표 지시 없이 바꾸지 않았습니다.

### D. 남색 밴드가 원본보다 36px 낮음
원본 밴드에는 배경 사진이 깔려 있어 여백이 더 큽니다. 구현은 텍스트+수치만으로 92.8px이며 정보 손실이 없습니다.

### E. 인용문 블록(원본 오른쪽 손글씨)
원본의 인용문은 **시안용 예시 문구**입니다. 확인되지 않은 1인칭 발언을 의원 발언처럼 게시할 수 없어 넣지 않았습니다.
필요한 것: 대표(의원)가 실제로 쓴 **확인된 한두 문장** + 서명 이미지 사용 여부 결정.

## 5. 유지 확인

- 5개 페이지(홈·의원 소개·의정활동·정책자료·미디어) 모두 유지, 섹션·기능 삭제 없음.
- 파란색 강조 체계(`#004884` / `#00609c`), 히어로·카드·스트립·남색 밴드 구조 유지.
- 기능 회귀 42/42 통과(검색·분류·상세 이동·뒤로가기 포함).
- 폰트: `@font-face` 93개, 페이지당 로컬 폰트 파일 9~12건 200, **외부 폰트 호스트 0건**, 실렌더 MaruBuri / Pretendard Variable.
