단계별 튜토리얼

화면을 따라가며 익히는 안내입니다. 모든 문서는 시나리오 대본에서 자동으로 만들어지고, 로그인이 필요한 단계는 화면 자리만 비워 두었습니다.

  • ① 처음 온 사람

    첫 화면에서 로그인 경로를 찾고 첫 질문과 답변까지 확인합니다. · 로그인 없이 1–3단계, 4–6단계는 화면 준비 중

  • ② PC 연결

    설치 안내에서 PC 연결 승인 뒤 자연어 파일 검색까지 확인합니다. · 로그인 없이 1–2단계, 3–5단계는 화면 준비 중

  • ③ 문서 작업

    민감정보가 없는 합성 문서를 올리고 요약한 뒤 내려받습니다. · 계정 준비 중 — 화면 자리만 있습니다

  • ④ 북AI

    게스트 기기 저장과 로그인 뒤 다른 기기에서 이어 보기를 확인합니다. · 로그인 없이 1, 3단계, 2, 4단계는 화면 준비 중

  • ⑤ 계정 탈퇴

    탈퇴 기능이 병합된 뒤 확인 단계와 안내 범위를 대본화합니다. · 계정 준비 중 — 화면 자리만 있습니다
