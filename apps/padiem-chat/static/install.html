컴퓨터 연결 프로그램 설치 안내

PADIEM Chat과 Claw에서 내 PC로 작업하려면 그 PC에 연결 프로그램을 한 번 설치합니다. 설치 파일은 Chat의 내 컴퓨터 카드에서 이 PC 연결하기를 눌러 내려받고, 받은 파일을 두 번 눌러 실행하면 됩니다. 이 페이지는 실제로 동작하는 순서만 적었습니다.

설치하면 이렇게 동작해요

설치를 마치면 그 PC는 이 계정에 자동으로 연결됩니다. 코드를 입력하거나 다시 로그인하지 않습니다. 연결된 PC에서는 사전에 맡긴 범위(이 PC의 드라이브와 등록한 폴더) 안의 작업이 바로 진행됩니다.

끄기·일시중지·연결 해제는 언제든 할 수 있습니다. 연결 목록의 잠시 멈춤과 연결 끊기가 웹에 있고, PADIEM Connector 트레이를 설치한 PC에서는 트레이에서도 같은 제어를 합니다. 프로그램 제거는 트레이와 웹에 버튼이 없어, 아래 제거 순서로 합니다.

덮어쓰기·이동·삭제 앞에서는 원본을 먼저 백업하고, 메일·메시지 보내기는 보내기 전에 한 번 확인합니다. 비밀번호·쿠키 같은 비밀 정보는 입력하지 않습니다.

시작하기 전에

  • Windows 10 또는 11 PC에서 진행하세요.
  • 설치 중 관리자 권한 승인을 한 번 요청합니다. 승인은 PC에 연결 프로그램을 두고 Windows 서비스로 등록하기 위해서입니다.
  • 실행할 때 인터넷 연결이 필요합니다. 프로그램이 PADIEM이 지정한 서버에서 연결 에이전트를 내려받기 때문입니다.
  • 내려받는 파일 이름은 padiem-pc-connect.exe입니다. 이 파일에는 전자 서명이 없어 Windows가 게시자를 확인하지 못합니다. 설치 순서에서 이 경고를 넘기는 방법을 그대로 안내합니다.
  • 이미 연결된 PC가 있으면 그 PC는 목록에 이름으로 나옵니다. 여러 PC를 쓸 때는 요청에서 PC 이름을 말하면 대상이 정해집니다.

설치 순서

  1. 1. 카드에서 설치 파일 받기

    Chat 또는 Claw의 내 컴퓨터 카드에서 이 PC 연결하기를 누릅니다. 화면에 PC 연결 파일을 준비하고 있습니다가 잠깐 보인 뒤 파일이 내려받아지고, 그 아래에 이렇게 실행하세요 순서가 나타납니다.

    화면에 PC 설치 파일은 아직 준비 중이라고 나오면, 이 배포에 설치 파일이 아직 연결되지 않은 상태입니다. 파일이 준비된 뒤 같은 버튼으로 다시 받으면 됩니다.

  2. 2. 받은 파일 실행

    내려받은 padiem-pc-connect.exe를 두 번 눌러 실행합니다. 검은 콘솔 창이 열리고 진행 문장이 한 줄씩 표시됩니다. 창은 결과를 읽을 수 있도록 끝에서 닫히지 않고 기다립니다.

  3. 3. 게시자 경고 넘기기

    Windows가 알 수 없는 게시자 창을 보여 주면 [추가 정보]를 누른 뒤 [실행]을 누릅니다. 창에는 파일 이름 대신 제품 이름 PADIEM과 PADIEM PC 연결이 표시됩니다.

    주의: 이 경고는 오류가 아니라 서명이 없다는 안내입니다. SmartScreen 설정이나 회사 보안 정책에 따라 이 창이 아예 뜨지 않는 PC도 있고, 반대로 [추가 정보]를 눌러도 [실행]이 나타나지 않는 PC도 있습니다. [실행]이 나타나지 않으면 카드의 다른 설치 방법 → 설치 파일로 받기 (.ps1)을 사용하세요.

  4. 4. 관리자 권한 승인

    프로그램이 관리자 권한을 요청하면 [예]를 누릅니다. 승인 창에서 [아니요]를 누르면 아무것도 설치되지 않고 창이 닫힙니다. 그때는 카드에서 같은 파일을 다시 받아 실행하면 됩니다.

  5. 5. 설치와 연결이 한 번에 진행

    프로그램이 PADIEM이 지정한 서버에서 연결 에이전트를 내려받아 %ProgramFiles%\PADIEM\MeshAgent.exe에 놓고, Mesh Agent라는 Windows 서비스를 등록한 뒤 시작합니다. 콘솔 창에 연결 진행 중 - 서버가 이 PC를 확인하면 PADIEM의 '내 PC 연결'에 자동으로 나타납니다가 표시됩니다.

    이 PC에 이미 설치되어 있으면 같은 서비스를 갱신 설치합니다. 서비스는 하나이고 중복으로 만들어지지 않습니다. 진행 중에는 창을 닫지 마세요.

  6. 6. 카드에서 연결 확인

    설치하는 동안 카드가 몇 초마다 서버에 다시 물어봅니다. 서버가 이 PC를 확인하면 카드가 연결됨 ✓ (PC 이름)으로 바뀝니다. 새로 고치지 않아도 됩니다.

PC에 남는 것

  • 연결 프로그램 파일 하나 — %ProgramFiles%\PADIEM\MeshAgent.exe와 이를 실행하는 Mesh Agent Windows 서비스입니다.
  • 내려받는 데 쓴 임시 파일은 실행 직후 삭제됩니다. 연결 표식과 설치 주소는 실행 중인 프로그램 안에만 있고, PC의 파일이나 레지스트리에 코드로 저장되지 않습니다.
  • PC 작업의 백업 — PC의 파일을 덮어쓰기·이동·삭제할 때 원본을 같은 드라이브의 숨김 폴더에 먼저 복사합니다. 위치는 <드라이브>:\.padiem-backup\<날짜>\<시각>-<GUID 8자>-<원래 이름> 이고, 답변에도 그 경로가 적힙니다. 백업이 실패하면 그 변경은 일어나지 않습니다.
  • 백업 폴더는 연결 프로그램을 제거해도 지워지지 않습니다. 원본이 들어 있으니 필요한 동안은 직접 보관하세요.

설치 뒤 제어

웹의 내 컴퓨터 목록

  • 이름 바꾸기 — 요청에서 부를 PC 이름을 정합니다.
  • 잠시 멈춤 / 다시 시작 — 멈춘 동안에는 이 PC로 작업이 전달되지 않습니다.
  • 연결 끊기 — 이 계정에서 이 PC의 연결 권한이 사라지고, 함께 등록한 폴더 범위도 사라집니다. 다시 연결하려면 그 PC에서 설치 파일을 다시 실행합니다.

PADIEM Connector 트레이 (별도 데스크톱 프로그램)

PADIEM Connector를 설치한 PC에서는 트레이 메뉴에서 다음을 쓸 수 있습니다: 연결 상태와 버전, PADIEM Chat 열기, 상태 보기, 로그 폴더 열기, 일시중지 / 다시 시작, 다시 연결, Windows 자동 시작 켜기 / 끄기, 연결 해제, 종료. 등록이 끝나면 Windows 자동 시작이 기본으로 켜지고, 트레이에서 끄면 다시 켜지 않는 한 유지됩니다.

주의: 트레이에는 제거 항목이 없습니다. PADIEM Connector의 설치·등록은 아직 정식 공개 전이며, 제거는 아래 제거 절차로 합니다.

자주 막히는 곳

연결이 안 될 때

카드가 연결됨으로 바뀌지 않으면 순서대로 확인하세요. ① 콘솔 창에 오류 문장이 있었는지 봅니다. ② 관리자 권한 승인 창에서 [예]를 눌렀는지 확인합니다. ③ 인터넷이 되는지 확인합니다(에이전트를 내려받는 단계입니다). ④ Windows 서비스 목록(services.msc)에 Mesh Agent가 있는지 봅니다. ⑤ 카드를 닫았다 다시 열어 목록을 새로 읽습니다. 그래도 안 되면 서비스를 다시 시작한 뒤 카드를 새로 고칩니다.

여러 PC를 쓸 때

PC마다 그 PC에서 설치 파일을 한 번씩 실행합니다. 연결되면 카드에 PC 이름이 나오고, 요청에서는 시험PC-A의 파일 목록 보여줘처럼 PC 이름을 말해 대상을 정합니다. 이름은 목록의 더 보기 → 이름 바꾸기로 바꿀 수 있습니다. 설치 프로그램은 이 PC의 드라이브 문자를 연결 이름에 함께 보내므로, 연결되면 그 PC의 드라이브가 기본 범위로 잡힙니다.

회사 보안이 실행을 막을 때

.exe 실행이 차단되면 카드의 다른 설치 방법에서 설치 파일로 받기 (.ps1)를 내려받아, 그 파일을 우클릭 → PowerShell로 실행으로 진행합니다. 설치 순서와 결과는 같습니다.

업데이트·다시 설치

업데이트도 같은 방법입니다. 카드에서 이 PC 연결하기를 다시 눌러 새 파일을 받고 실행하면, 기존 서비스를 멈추고 같은 Mesh Agent 서비스로 갱신 설치합니다. 중복 서비스는 생기지 않습니다. 다시 설치해도 폴더 범위와 PC 이름은 그대로 남습니다.

내려받은 파일은 받은 뒤 오래 두지 말고 바로 실행하세요. 파일에 담긴 연결 표식은 짧은 시간이 지나면 만료되어, 실행해도 연결이 완료되지 않을 수 있습니다. 그때는 카드에서 새 파일을 다시 받으면 됩니다. 내려받기만 하고 실행하지 않은 것은 실패가 아닙니다.

제거

제거는 두 단계입니다. 먼저 웹에서 이 계정과의 연결을 끊고, 다음으로 PC에서 프로그램을 지웁니다. 웹의 연결 끊기만으로는 PC에 설치된 프로그램 파일이 남습니다.

  1. 1. 웹에서 연결 끊기

    내 컴퓨터 목록에서 그 PC의 더 보기 → 연결 끊기를 누릅니다. 서버 쪽 연결 권한과 폴더 범위가 사라집니다.

  2. 2. PC에서 프로그램 제거

    그 PC에서 관리자 권한 PowerShell을 열고 아래 두 줄을 실행합니다. 

    & "$env:ProgramFiles\PADIEM\MeshAgent.exe" -uninstall
Remove-Item -LiteralPath "$env:ProgramFiles\PADIEM" -Recurse -Force

    예전에 다른 방법으로 설치한 PC라면 서비스 기록이 다른 폴더를 가리킬 수 있습니다. Get-CimInstance Win32_Service -Filter "Name='Mesh Agent'" | Select-Object -ExpandProperty PathName 으로 실제 파일 위치를 확인한 뒤 그 폴더를 지웁니다.

  3. PADIEM Connector를 설치한 경우

    Connector는 설치에 쓴 파일을 -Uninstall 옵션으로 다시 실행해 제거합니다. Windows 설정의 앱 목록에는 등록되지 않습니다. 제거해도 등록 정보와 사용자가 직접 끈 자동 시작 설정은 지워지지 않습니다.

주의: .padiem-backup 폴더는 PC 작업이 만든 백업이라 제거와 함께 지우지 않습니다. 지우기 전에 필요한 원본이 없는지 확인하세요.

보안·개인정보

  • 설치 파일에는 전자 서명이 없습니다. 서명 도입은 대표 결정으로 미뤄졌고, 그래서 Windows가 게시자 경고를 띄울 수 있습니다. 경고를 넘기는 방법은 위 3단계와 같습니다.
  • 연결 코드를 직접 입력하지 않습니다. 계정의 연결 표식이 내려받은 파일 뒤에 붙어 있고, 설치 뒤에는 PC 이름과 드라이브 문자, 연결 표식만 서버가 확인합니다.
  • 연결 표식은 비밀번호가 아닙니다. 다른 사람에게 파일을 그대로 전달하지 마세요. 표식은 짧은 시간이 지나면 만료됩니다.
  • 설치 프로그램은 PADIEM이 지정한 서버에서만 에이전트를 내려받습니다. 주소는 파일을 내려줄 때 서버가 정하며, 브라우저나 사용자가 바꿀 수 없습니다.
