화면 사용법

B14에서 조회 가능한 모델을 선택하고, 변경할 제품·회원 등급·허용 방식을 고른 뒤 변경안을 검토합니다.

등급별 실행 경로

제품·등급별 기본 모델과 자동 폴백을 지정합니다. 저장된 경로는 Chat · Claw · B66의 다음 요청부터 서버 실행 경로에 적용됩니다. 경로를 사용하지 않음으로 저장하면 해당 등급은 모델을 실행하지 않습니다.

허용·차단 규칙과의 차이

허용·차단 규칙은 D1 저장 원장이며 아직 제품 실행 경로에 연결되지 않았습니다. 실제 실행 모델은 위의 등급별 실행 경로가 결정합니다.

상태 아이콘

● 조회됨: 해당 정책을 확인함. ◌ 미연결: 아직 정보 소스가 연결되지 않음. ⊘ 차단: 실제 조회된 정책이 해당 모델을 차단함.

모델 목록 기준

B14 등록 모델은 ON·OFF·선택 제외를 포함합니다. ON은 B14 활성 목록에 있다는 뜻이며 실제 API 응답이나 제품별 권한을 보장하지 않습니다. 등록 목록 연결이 안 되면 선택 가능한 일부 모델만 표시합니다.
