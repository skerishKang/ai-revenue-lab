## Phase B — plain deterministic Korean OCR comparison

| Field | RapidOCR v3.9.2 + Korean PP-OCRv5 ONNX | PaddleOCR v3.7.0 + Korean PP-OCRv5 |
|---|---|---|
| KOREAN_SUPPORT | YES | YES |
| CPU_RUNTIME | ONNX Runtime default | PaddlePaddle/PaddleX |
| RAM | UNRESOLVED | UNRESOLVED |
| STARTUP | UNRESOLVED | UNRESOLVED |
| DEPENDENCY_WEIGHT | Smaller direct surface | PaddleX/PaddlePaddle stack |
| WINDOWS | Claimed by upstream; not independently reproduced | Claimed by upstream; not independently reproduced |
| LINUX | Claimed by upstream; not independently reproduced | Claimed by upstream; not independently reproduced |
| LOCAL_OFFLINE | POSSIBLE after complete local provisioning | POSSIBLE after complete local provisioning |
| MODEL_PINNING | Explicit model manifest; exact artifact blocked | Local model directories supported; complete artifact set not yet assembled |
| HASHABILITY | YES for pinned Rapid model manifest | YES for official HF files; complete set unresolved |
| LICENSE | Apache-2.0 software | Apache-2.0 software |
| MODEL_ARTIFACT_LICENSE | UNRESOLVED | Apache-2.0 official Korean model card |
| RUNTIME_NETWORK | 0 only if fully provisioned | 0 only if fully provisioned |
| OUTPUT_BOX/TEXT/CONFIDENCE | YES | YES |
| SIDECAR_FIT | HIGH | MEDIUM |

PaddleOCR v3.7.0 has immutable-tag support for korean_PP-OCRv5_mobile_rec and local text_recognition_model_name/text_recognition_model_dir admission. It is technically viable for the plain deterministic tier, but a complete Padiem adoption authority still requires a pinned detector, recognizer, dictionary/orientation model, exact runtime dependencies, and hashes.
